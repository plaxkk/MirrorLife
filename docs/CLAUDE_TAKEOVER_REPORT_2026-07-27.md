### 2. 地面色调（`b543028`）

水磨石底色 `#bcb8b2` → `#96938e`（等比 ×0.80）。

原来**画面最亮的地方是无遮挡的近景地板**，而房间的光来自远端门洞——这是物理上反的。量化后，画面下部两条带比参考图高 +0.07~0.08 亮度，其余各带都在 0.04 以内匹配。

等比缩放而非等量下压，是因为饱和度公式 `(max-min)/max` 是尺度不变的——等量下压会引入色偏，等比不会。扫描 1.00 / 0.86 / 0.83 / 0.80：

- 达标轴 **3/7 → 5/7**
- 全帧亮度 0.552 → **0.514**（参考 0.524）
- 垂直光照落差 0.094 → **0.039**（从超标 3.7× 进入容差）

附带收获：地面上本来就有的门洞树影斑驳终于看得见了，之前被过亮的底色洗掉。yaw 90° 视角最明显。

### 3. 量化对照工具（`b543028`）

`scripts/measure-reference-gap.mjs`，输出七根轴对参考图的有符号差值。

建它的原因是 v1–v146 全靠肉眼判断，所以同样三条 P1 被换了 20 种说法，而曝光/主光在固定区间里来回游走从未收敛。

它自己头两版输出就暴露了两个陷阱，都已修正，值得记住：
- **降采样太狠会把要测的细节平均掉**，于是把明显可见的材质改动报成"无变化"；
- **网格大于任一源图的有效采样区会把最近邻块状放大成假边缘**，而且两图放大倍数不同时结论会反转。

现在色调轴用 320×180，细节轴用 1024×428（低于两图有效区）。

## 下一步最该做什么

**draw call 预算是所有剩余视觉工作的硬瓶颈，而瓶颈在角色材质数。**

```
opening 177 / 180   room 70 | models 8 | actors 99 | other 0
四角色 GLB 材质合计 70 个（17/17/19/17）
```

材质数基本等于 draw call 数。当前两根未达标的轴——细节密度低 3.8×、局部对比低 2.1×——都需要**加实体几何**才能补，而余量只有 3 个。

把角色材质图集化到每角色约 6 个，四角色可从 ~76 降到 ~24，**释放约 50 个 draw call**。那才是让前景桌、小物件密度、木质层级这些工作真正做得动的前提。在此之前，任何"加东西"的方案都会撞预算。

角色本身的结构问题也在这里：**204 个 mesh 只有 2 个是蒙皮的**，头、手、鞋、服装面片全是刚性小块拴在骨骼上——所以它看起来像拼装玩具，因为它就是。这不是面数不够（三角面还有 55% 余量），是结构方式。

## 关于总目标

我在动手前已经说过、这里再记一次：**"对标这个图片的实现水准"没有二值验收条件**，任何美术差距永远可以描述成"仍有可见差距"，所以这个目标不存在不动点。这就是 124/126 次闸门是 blocked、同样三条 P1 被换 20 种说法的结构性原因。

我这轮的做法是给它装上可量化的轴，把"像不像"变成七个有符号差值。这不能让目标变成可完成的，但至少让每次改动可以被判定为改善或回归——而不是又一次换说法。

真正能被判定完成的，是上面那些有数字的条目：draw call 从 99 降到 50 以下、陈列柜木框亮度差从 +0.163 收进 ±0.02、细节密度从低 3.8× 进入容差。建议把目标换成这些。
