# 天井人物比例与面部续作

## 玩家结果与设计边界

目标玩家仍是首次进入共享生活馆、希望接近居民并完成一次共同决策的玩家。本轮调整七名人物的头身比例和眉眼造型，让正常探索距离中的人物更接近参考图的成年青年；保留原有身份、发型差异、服装色彩、骨架和交互。玩家仍按“交流 → 探索 → 决策 → 自由回游”完成示例。

验收预算继续是整处双层试点合计 180 draw calls、500,000 triangles、220 geometries；桌面 1080p 接近稳定 60fps、移动档 30fps 是实测目标。人物缩小不能成为削减交互距离或改变路线的理由。鼻梁、眼睛和颈部必须在侧面成立；若只改善正面而出现悬浮、断颈或眨眼错位，就是失败信号。

## 制作与交付

- 七人头部缩放从原始角色比例的 0.76 调至 0.62；保留原头部中心，让较小下巴与既有颈部重叠，并露出少量颈部。
- 整组眼部横向、厚度、纵向分别调整为原来的 0.82、0.4、0.72；眉宽缩至 0.84，并降低到与眼睛更接近的位置。运行时眨眼保存并复用模型初始缩放。
- 鼻梁和鼻尖通过脸部顶点位移形成；同一位移写入可编辑表情键。移除原来独立的三件鼻部小球，用贴合实际表面的细小鼻翼色差补充正面辨识。正面光照下鼻部体积仍偏弱。
- Blender 源文件、master GLB、桌面/移动 LOD 和九段动作源同步导出。来源与许可仍为项目原创制作及既有 civic 骨架衍生，无新增外部资产。
- 导出过程中发现局部循环覆盖人物名称，导致样本错误写成 `NoseWingShadow`。修正循环变量并添加导出身份断言；误命名样本移入忽略的临时目录，没有进入资产清单。

`evidence/atrium/faces/review.html` 提供同镜头前后对照；`cameras.json` 记录相机、画幅、资产哈希。截图来自真实运行场景，保留待机和眨眼，所以动作相位不一致，不据此比较表情优劣。旧版玩家仅在诊断页面通过请求替换用于对照，不参与完整回游或性能测试。

`scripts/verify-atrium-faces.mjs` 已加入完整验收流程。默认检查当前玩家；提供 `ATRIUM_FACE_BASELINE` 时额外生成旧资产对照。七人的正常距离正侧面仍由 garments 检查覆盖。

## 尚未通过

参考图中的自然面部光影、连续发束、日常服装轮廓与褶皱仍未达到。当前基础照明偏均匀，鼻部和衣物体积较弱；脸部复杂表情仍未接入运行时 morph。真实手机、长时间稳定性、主世界居民身份与剧情关系的完整集成、人工 3–5 分钟体验和最终美术验收仍待完成。不得将本轮文档或测试通过解释为整体任务完成。

当时逐人截图暴露了具体问题：何川的帽檐与刘海连接不自然，部分发束穿到帽体前方；唐乐的前袋像凸起的椭圆块；开衫人物的衣领过高。后续修正见 `ATRIUM_CONTROLS_REVIEW.md`，本文件中的数字和结论保留为当时的候选记录。
