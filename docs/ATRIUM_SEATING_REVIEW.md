# 天井生活馆 · 坐姿与离座交谈续作

## 玩家目标与边界

首次玩家走到桌边后，居民能离开椅子、面向玩家交流，再回到座位；玩家在二层坐下时，小腿不切进坐垫，鞋底不明显悬空。保留原探索、决定、存档和两层路线，不改变原 180 calls / 500k triangles / 220 geometries 预算。本轮不是楼梯脚底 IK 或人物整体美术完成声明。

## 修正

- 林晓与陈屿使用各自椅旁的离座位置。移出椅子范围后才允许大幅转身，返回时先恢复椅子朝向，再回位坐下。位移按速度限制连续推进，快速取消也可恢复。
- 位移会检查玩家占位；玩家挡住通路时暂停位移，不能直接推穿玩家。取消对话后仍可移动，让出空间。该检测针对玩家，不是通用 NPC 寻路器。
- 根据角色原始髋部、大小腿长度和脚部中立偏移求解坐姿角度。髋部留出坐垫厚度，坐姿前移 20cm，使膝盖越过坐垫前缘，再让小腿落向地面。去掉坐姿中的站立摆动和侧倾，避免残余角度抬起鞋底。
- 同步更新 `motion.json`、Blender 动作源及九段动作 GLB，坐下/起身参考保留相同髋部偏移和前移量。离座的世界路径由运行时驱动，不伪称已烘焙进所有原地动作。
- 增加异步 WebGL2 GPU 计时，每十帧尝试一个查询；最多四个在途查询，最多保留 1,800 个结果，断续计时样本丢弃。硬件不支持时报告 `supported:false` 和 null，不能当作 GPU 耗时为零。

## 五视角自审

| 视角 | 具体反对意见 | 验证与裁决 |
|---|---|---|
| 玩家 | 起身太慢，或取消后居民永远站着，打断对话节奏 | 实际 E、Esc、快速取消与回位检查；对话文本即时可读，居民动作连续进行。真实玩家节奏评价仍未取得。 |
| 关卡 | 椅旁新位置挡住玩家穿过桌后，或者动画直接穿人 | 限速移动、玩家占位等待、两居民离座/返回测试及完整输入驱动回游。不是全场景通用避障或精确衣服碰撞。 |
| 美术 | 鞋底公式正确，但膝盖仍切入座面 | 第一轮近景确实发现此问题，增加前移与膝盖净空检查后重新截图。接受残余反对意见：肩部和衣服形体仍简化，转移脚步也不是专业动捕，整体美术门禁仍未通过。 |
| 性能 | 新动作和 GPU 查询反而增加卡顿 | 缓存固定椅高的坐姿解，GPU 查询异步限流，不等待结果；正式构建重测两档帧时间，不能以脚本耗时代替真实帧时间。 |
| QA | 换角度和位置夹具会掩盖真实路线问题 | 坐姿专测使用明确标注的位置夹具；完整录像单独使用真实输入，不传送。两种证据用途分开。 |

## 验收入口

`npm run verify:atrium:release` 包含本轮新增 `verify-atrium-seating.mjs`。坐姿专测通过真实 E/Esc 操作覆盖两名桌边居民与二层玩家，输出 `evidence/atrium/seating/report.json` 和近景。鞋底指标是中立脚部偏移推算，膝盖指标是骨骼相对椅子方向的净空；二者必须结合模型截图，不是完整三角网格穿透证明。

当前版本的构建、运行指纹、性能和回游状态以 `evidence/atrium/acceptance.json` 为准；性能解释见 `evidence/atrium/PERFORMANCE.md`。原主室内 `src/interior-three.js` 和 `.workbuddy/` 修改继续保留，不纳入本轮提交。

## 完成边界与后续

本轮修正桌边交谈与坐姿，不宣称完成原始全部提示词。上下楼物理路线沿用已验证系统；楼梯逐脚贴地 IK、走路脚滑审查、完整转向步伐、专业肩部/织物变形、参考图空间比例与光照仍待制作。没有真实手机、长时实际玩家、弱网或生产上线验收，也没有可报告的真人反馈。
