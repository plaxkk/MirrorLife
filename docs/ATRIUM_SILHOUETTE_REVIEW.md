# 人物轮廓与楼梯结构续作

目标玩家沿入口观察人物，接近交流，再从共享桌走上二层。此次以正常步行距离下的人物比例和楼梯轻重关系为目标；保留已有交互提示、探索→交流→共同决策→继续探索的循环，不增加等待流程。

保真约束：真实三维、相同踏步顶面和楼层、既有身份与骨架接口。渲染预算仍为双层合计 180 draw calls / 500,000 triangles / 220 geometries；桌面与移动结果需实测，不先宣称达标。

## 设计反方意见

## 制作方向

原先额外放大肩关节间距 1.28 倍；现调整为 1.08 倍，衣身宽度同步收至原来的 .88，颈部横向与深度同步调整并平滑法线。眼睑保留内缘与眼球关系，将外缘和两端贴合脸部真实曲面。各居民沿用自身脸型、服装和身体差异，非统一缩放整个人物。

主楼梯原来每级踏步都是一直到地面的实心块。改为保留全部踏步顶面的薄踏步和封闭的倾斜承重梯体，采用约 28cm 的竖向结构深度（并非垂直斜面的测量厚度）。梯底设计是对单图未显示部分的结构补全，不能声称精确还原。侧扶墙、扶手与回廊仍为可环绕的三维资产。

来源：项目原创 Blender 模型和既有 civic 骨架。无新增第三方资产或费用。


## 调整中发现的问题

眼睑第一版只投影外缘，仍出现跨眼窝的平面折痕，已改成分段曲面并将边界略埋入脸部。保留内缘、眼球和原注视/眨眼控制；近景仍需检查，不能等同于完整表情制作。

重新导出时发现原流程把全部碰撞 JSON 作为 scene extras 再塞入视觉 GLB，桌面 GLB 临时从约 2.86MB 膨胀至 6.48MB。修正为只保留独立碰撞文件，Blender 源继续保留可编辑碰撞清单；不删减碰撞三角面。新增资产检查防止视觉 LOD 再次复制碰撞数组。

减少环境半球光与背侧填充、增加西侧窗边暖色点光作为间接反弹近似，并重烘焙两层地面短距离接触遮蔽。没有宣称完整 GI 或真实窗光光线追踪。

新增物理检查：高净高梯下可穿行、低净高处被倾斜实体挡住、22 个踏步顶面不变、套件碰撞顶点由世界坐标正确移到局部坐标。完整录像新增梯下往返，区别于检查相机截图。

## 美术与体验结论

改进可从运行图辨认：楼梯后的门窗与侧区显露，斜梯底有真实封闭表面；人物肩宽和颈部收敛，鼻颊在窗侧暖光下更可读。参考图仍不是精确重建：主梯线形偏直，前景共享桌、连续墙面转折、植被疏密和暖日光层次仍不同。人物侧脸、发型体块、服装轮廓与完整表情仍显简化，本轮不标记精品人物美术完成。眼睑分段贴合解决先前平面补片问题，但极近距离轮廓仍需精修。

近墙镜头策略本轮未改：极窄窗角仍会缩短镜头并淡出人物；窗墙胶囊回归通过不能代替所有衣物/手指的接触认证。真实手机、长期稳定性及完整主世界集成仍未验收。
