# 发型分辨率与浮起发片研究

2026-09-23，正式基线 `e3fcdea`。上轮分层衣装已接入，本轮针对顶部块状轮廓与边缘碎片继续制作。完整七人生产美术目标保持未完成。

首次玩家在中庭探索、近看交谈并环绕角色，短发应有自然分组与连续轮廓。此次保留深色短发身份、真实三维和原动作，不增加交互步骤或等待。性能预算不放宽：180 calls / 500,000 triangles / 220 geometries，桌面严格 60fps；上一版本尚有尾部延迟且面数余量很小。

## 判断路线与五视角反证

代码确认当前 authored hair 跳过通用 LOD 减面。源图 2048²，运行桌面 512²、移动 256²，MASK 阈值 .4。先对比 1024²/512²，隔离分辨率因素，再检验独立发片轮廓。

| 视角 | 反对意见 | 验证方法与判断 |
| --- | --- | --- |
| 玩家/产品 | 更大贴图在正常距离看不出收益 | 双档同镜头全身/近景/俯视，收益很小，未采用高分辨率 |
| 游戏设计 | 正面改善却在环绕中露出缺口 | 前后左右、四分之三、俯视均保留，固定表情不是完整动作验收 |
| 美术 | 收束发片会变成头盔 | 主底层完全保留，独立发片回收后检查体积和侧后层次；若帽状感加重则不安装 |
| 工程性能 | 加大图占用资源却不解决几何 | 实际 PNG 和 GLB 统计，不凭源图尺寸推断；几何研究不增面 |
| 质量验收 | 对照混入脸型/UV/材质变动 | 源审计逐项比较发型拓扑、UV、变换、父级、阈值、粗糙度和面部全部形变；只允许对应研究变量变化 |

## 分辨率结果

正式/候选同模型四向与俯视显示，高分辨率略增加细发流，但顶部块状轮廓和碎边仍在，收益不足。桌面 GLB 从 2,428,124 B 增到 3,118,284 B（+690,160 B），移动从 952,472 B 到 1,168,596 B（+216,124 B）。实际头发 PNG 从 308,569/93,287 B 增到 998,699/309,389 B；实际尺寸 512/256→1024/512，阈值仍 .4，面数完全相同。否决作为当前默认方案。

`ATRIUM_HAIR_TEXTURE_STUDY=1024` 强制 `tmp/` 输出。源审计 `source.json` 证明除图片尺寸外发型几何、UV、变换、材质参数和脸部形变一致。运行对照 `desktop/`、`mobile/` 绑定真实请求文件 SHA；相机固定但 idle 相位未锁定，不作像素差分。

## 发片结构研究

原始网格有 2,984 顶点、1,839 面，最大连续底层含 1,138 顶点，其余为独立小发片。`ATRIUM_HAIR_CARD_STUDY=1` 保留底层，只有离底层超过 .004 且朝外的发片顶点向底层收束，收回超出距离的 65%、最多 .012（父级缩放前）。不新增几何或贴图，不移动皮肤或脸部，不把真实三维替换为固定朝向图。

构建复现：`ATRIUM_RESIDENT_IDS=you ATRIUM_HAIR_CARD_STUDY=1 ATRIUM_BUILD_ROOT=$PWD/tmp/portrait-study/hair-card-v1`，Blender 执行 `scripts/build-atrium-residents.py`。源验证用 `ATRIUM_HAIR_CARD_AUDIT=1` 调用 `scripts/verify-atrium-hair-texture-source.py`，要求底层不动、拓扑/UV/材质/表情不变，变化顶点更靠近底层且仍有间距。

本轮研究未替换正式源、双档或九动作，未作完整玩法、真机性能或发布签收。全员造型、衣装、发型和稳定性能仍待完成。

## 发片结果与后续方向

`card-source.json`：848 个独立发片顶点改变，最大位移 .0110718；1,138 个底层顶点逐项不变，所有变化点更靠近底层且保留大于 .0039 的间距。拓扑、UV、图片尺寸、阈值、材质粗糙度、物体变换和脸部形变均不变。

`card-desktop/` 与 `card-mobile/` 的四向/俯视实拍显示部分碎边收敛，但整体仍是块状发帽，发际线与主要发束分组没有改善。当前不安装收束版，不继续用更强的全局压低试图替代发型设计。下一步应重做主要发束的走向与发际线节奏，保留贴合、源 UV 和当前已验证的淡出策略。

收束候选桌面 2,428,048 B / 26,532 面，移动 952,384 B / 24,469 面，与正式版面数一致。双档实际纹理 UV 检查另保存；本轮截图是固定表情与相机的研究，没有连续动作或新性能测量。以上五视角是执行者自审，不是外部用户签收。
