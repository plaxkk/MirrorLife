# 主角短发与肩颈修整

基线 fd031d8。目标玩家仍是首次进入共享馆、需要在行走和交流中看清人物的玩家。本轮改善主角短发的块面组织和外露颈部比例；进入→探索→交流→共同决策→继续探索的循环、人物身份、接触点和存档保持原逻辑。原图人物没有脸部特写，发型细部是依据可见短发轮廓的设计补全，不是精确复刻。

原来将所有发束顶点投射回头骨的做法压扁了发束，使底壳占据侧面。现在直接在头骨表面梳理 8 组顶部、10 组两侧、3 组冠部发束；根部与底层重叠，独立控制中段蓬度和末端收束。删除过长的鬓角尖条，修整耳侧发际线。头部控制点下移 18mm，原生颈部的底边仍延伸到领口内。Blender 源文件、双档 GLB 和九段动作一起重新导出。未增加材质类型或提高 180 calls / 500,000 triangles / 220 geometries 的全双层预算。

## 五视角自审

| 视角 | 可证伪的反对意见 | 检查与裁决 |
| --- | --- | --- |
| 玩家/产品 | 改动只在极近肖像可见，正常探索无改善 | 保留全身正常距离和连续游玩画面；本轮不以头发细节判定整体人物完成 |
| 游戏设计 | 降低头部后坐姿、说话和生活动作穿插 | 同候选重跑坐姿、握持、楼梯、交流和决策 |
| 美术 | 新发束是浮在头壳外的整齐硬条，耳边穿插 | 增加背面与另一侧镜头，检查蓬度、露耳和分缝；整齐感仍是残余问题 |
| 工程性能 | 更多发束推高预算或移动档 LOD 破形 | 双档实际资源统计、渲染峰值与帧时间；不以面数变化直接推断帧率 |
| QA/发布 | 动画或缓存仍引用旧人物，静态照片掩盖动作退化 | 重烘焙九动作，检查形变与候选指纹，实际输入录像及资源失败/重入回归 |

这是同一执行者的五视角自审，不是独立人工评审。最强反方结论：当前眼睑仍厚、面部亲近感不足，衣服、手脚依然粗糙；修整短发不能代替完整角色美术验收。六位居民尚未同步重制。
