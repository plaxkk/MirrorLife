# 眉形贴合制作

2026-09-22，基线 ac459bf。上一轮有代码与视觉证据进展；七人生产美术目标保持未完成。本轮处理近景圆管眉的机械感，沿用肤色与眼形隔离候选 v7，不能与已安装版本混淆。

玩家旅程：首次玩家进入中庭、靠近居民交谈，从神态辨识角色并继续探索。眉形修改应在正常对话距离可辨、侧面贴合，不改变交流输入、等待反馈或下一步流程。完整 3D 环绕、身份、原动作和 180 calls / 500000 triangles / 220 geometries 预算保留。

五视角自审：玩家视角反对只在放大特写看出收益，因此保留全身画幅；设计视角反对眉形改变导致持续惊讶神态，因此保留正面和闭眼比较；美术视角反对毛束变成锯齿与悬浮，需正侧背与移动档；工程视角反对增加过多小几何，记录双档三角面和导出分批；QA 视角反对沿用上一候选的覆盖和动作证明，本轮截图绑定实际样稿 SHA，未做检查的项目保持未验收。

眉形由贴合前额曲面的收尖实体和少量顺向细束组成，完全不透明，可编辑源保留 BrowPivot 控制层级，运行导出沿用现有 HeadPivot 合批。源输出与双档 GLB 强制在 tmp/ 下；默认模型不改变。

复现：ATRIUM_RESIDENT_IDS=you ATRIUM_BROW_STUDY=1 ATRIUM_FACE_PAINT_STUDY=1 ATRIUM_PORTRAIT_EYES_STUDY=1 ATRIUM_BUILD_ROOT=$PWD/tmp/portrait-study/brow-v4，使用 Blender 执行 scripts/build-atrium-residents.py。

首版 v1 的同镜头图显示眉体过细、眉峰偏高，未达到自然青年气质；不采用。随后统一封闭实体外侧法线，v3 扩大眉体并降低眉峰。新增材质名字明确归入 hair 家族，避免误入 cloth 烘焙。

## 结果与局限

v3 移动近景暴露眉头方形截面；v4 以渐入宽度替代齐切端面。已检查的 v4 近景中方形截面消除，眉尾收尖、眉体粗细变化比原圆管清楚，侧面没有看到明显悬空。仍偏图形化，细束没有形成足够自然的毛流；不能宣布眉毛已达到生产美术。整体鼻口/眼睑和皮肤人偶感未解决，本候选不接入运行模型。

v4 源左右眉各 420 顶点，非流形边 0，带符号实体体积均为正；Basis/Blink/Talk 全部源坐标与 v7 逐项相等。复现脚本和绑定源 SHA 的结果在 evidence/atrium/brow-form/verify-source.py 与 v4-source-audit.json。三个 GLB 导出均通过贴图 UV 检查。

桌面 25,770 面、2,626,088 字节，移动 22,968 面、1,013,704 字节；相比 v7 增加 674 / 339 面，均仍为 7 个图元。没有把单角色图元数当作全场景 draw calls，也没有声称性能通过。本轮无运行源/资产替换，不重跑与本次隔离实验无关的全量发布测试。

桌面部分闭眼、闭眼、说话及移动固定表情截图分别绑定实际请求文件指纹；这不是连续动作或手机真机验收。下一步优先重做眼睑边缘与自然睁眼体积，眉毛仍需与这些变化共同审查。七人完整范围、预算、游戏流程和用户反馈验收继续保持未完成。

工具收尾异常：v4 两项截图均已输出完整报告和成功标记，且无页面错误，但 Node 在 Chrome 子进程消失后仍未退出。确认具体 PID 后终止了本轮两个进程；因此仅认定截图/固定权重核对完成，不记录为命令正常退出。未据此重启或重复制作。
