# 人物生产质量复查与连续裤身修整

基线：e61abd6。目标玩家是在双层生活馆自由行走、近距离交谈的首次和回访玩家。玩家应能通过神态、服装和动作辨认居民，并自然进入探索→交流→共同决策→继续探索的循环。正常探索与对话近景都必须成立；不以一张特写或三角面数量代替精品游戏美术。全场景预算仍为 180 draw calls / 500,000 triangles / 220 geometries。

## 原图与当前模型的实际差距

重新打开 `design/references/atrium-visual-target.png` 和上轮运行图后，确认当前仍是需要精修的风格化角色，未达到用户要求的生产级美术：

- 原图的青年神态自然，当前鼻口偏突出、眼周和嘴角生硬，眼睑曲面不够干净。原图没有面部特写，新增面部细节属于设计补全。
- 发束过于整齐，侧发像整块发帽；居民之间的面部区分仍主要依赖基础头型、发型和配色。
- 肩胸、袖子和衣摆缺少自然裁剪与受力关系；连续表面解决开裂不等于布料质感成立。
- 旧裤身由独立臀部壳体和双腿组成，裤腰凸出，裆部边缘像护甲短裤。
- 手指体块、鞋面比例与分件仍简单；落脚指标只验证相应采样，不代表所有动画帧的网格接触无误。
- 材质以顶点色为主，缺少完整制作的皮肤、织物、鞋面、发丝纹理与法线；现有 UV 和粗糙度贴图并不等同于完整 PBR 制作。

## 本次实际修改

1. 七人脸部在原有 CC0 基础上收回鼻口、柔化下颌及嘴角，局部平滑脸颊；保留连接式眼睑、眨眼和说话形变。肤色与脸颊顶点色调整仍是原有实时材质的一部分。
2. 主角顶部发束改为不等宽、不等长的分组，改变分缝、冠部起伏和发梢节奏，保留真实背面与侧面。
3. 裤臀与双腿在 Blender 中连接、平滑并重新分配髋膝权重，消除独立裆部壳体边缘。保持原始控制器、人物身份和存档接口；移动档仍是实体蒙皮网格。
4. 全员衣摆改为从实际衣身横截面取样的连续针织收边；重做袖口交界，移除主角重复领口线与唐乐悬空衣摆装饰。删除穿出椭圆裤身的旧矩形腰带，裤脚回到裤料配色。手部增加局部表面平滑；整双鞋在鞋骨局部缩短、收窄，保留最低 Z 和骨骼接触基准。
5. 在原绑定完成后统一收窄身体与整个骨架的横向尺度，头部做宽度补偿；保留原始袖腰间隙、控制器与蒙皮关系。该方式与被否决的移动肩部绑定位置有实质区别，仍需动作与接触回归。
6. 布面检查从五种肩肘姿态扩展到肩肘、迈步、抬腿、坐姿共八种姿态，检查所有长于 5mm 的网格边。它是拉伸回归门槛，不是布料模拟或人工美术认证。

## 被否决的候选

- 将主角肩宽、胸宽和袖宽同比收窄 6% 后，大幅抬臂边长拉伸达到 4.288 倍，超过已有 4 倍门槛，撤回该比例改动；未提高阈值。
- 整脸细分再减面改变眼眶边界，虽通过 4,252 个闭眼深度采样，实际运行图仍出现眼角尖折。撤回全局细分，改为眼眶下方的局部脸颊平滑。这说明几何测试通过不能代替画面审查。
- 候选均在 `tmp/production-candidate/` 隔离导出与截图；临时资料不是最终验收证据。

## 生产级门禁

可编辑源、GLB、双档 LOD、可运行骨架只是资产进入制作管线的条件。美术验收仍要求：原图方向下完成统一角色造型、脸部表情精修、发型根梢与分组、衣装缝线/褶皱/内层、手脚接触与关节修形、完整材质绘制、多角度及动作复核。真实手机性能与长时游戏稳定性也不能由桌面模拟替代。本次没有收费服务、外部生成资产或人工美术审核，不宣称这些工作已经完成。

最终运行数据及本轮证据将在回归完成后附于下方；之前的统计仍可从上一提交和 `ATRIUM_CHARACTER_FINISH_REVIEW.md` 查阅。

## 首次运行图复核与追加修正

已查看首候选七人正面、主角侧面/背面/另一侧及表情图。鼻口投影、肤色和裤裆连接比基线柔和；但这不是生产级通过。主要反方结论仍成立：陈屿等居民的肩顶和袖面偏硬，林晓等角色袖口存在锯齿状交界，唐乐旧衣摆装饰与衣身有分离感，手掌指节、眼睑外缘及发际线仍需精修。全体面部的相似性也没有靠这次局部雕形解决。这些截图保留在对比页中，不裁掉问题区域。

首候选完成 17 阶段后主动停止本轮录像子进程，转入衣摆、袖口和整体体型修正；原报告与缺陷图保留在 `evidence/atrium/character-production/first-pass/`，不是最终构建。其桌面 16.7/17.5/17.7ms、99 calls / 484,582 triangles / 80 geometries；移动模拟同为 16.7/17.5/17.7ms、81 / 319,350 / 76。它没有完整录像验收，不能混入最终结果。隔离候选的主角与唐乐八姿态检查均通过，最大边长拉伸 3.664 倍；新截图确认唐乐衣摆悬空已修正，随后进一步删除旧矩形腰带角部。

整骨架缩放后的候选在持物回归真实失败：水壶世界尺度约 0.999646，未满足原 1e-5 容差。原因是非均匀缩放与子关节旋转形成剪切，矩阵分解得到的四元数并非单位长度，重新组合时仍引入缩放。运行代码现在归一化旋转后再构造刚性握持变换；新增横向缩放 1、0.88、0.7 下共 120 个运动姿态的回归，修复前重现失败、修复后通过。原失败与 13 阶段报告保留在 `character-production/grip-pre-fix/`，没有降低容差或伪报完整通过。

转头层级检查随后重现了另一项问题：将宽度补偿放在会旋转的头骨自身，只能在正视时抵消身体缩放；转头会引入剪切。现改为在头骨上方增加独立补偿父节点，保持原头骨比例及转向控制。新增七人双 LOD、左右转头与俯仰组合的轴向正交/尺度不变检查，旧资产明确失败。握持修复后的候选已通过实际持物与坐姿检查，但其楼梯子进程主动停止，记录保留在 `character-production/head-frame-pre-fix/`，不作为最终整体验收。
