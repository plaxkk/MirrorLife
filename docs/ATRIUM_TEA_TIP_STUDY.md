# 卷指末端体积研究（2026-09-24）

## 目标与结论
七名人物生产美术目标继续。上一轮提供有效接触改善，本轮进一步定位硬折面的来源。目标玩家在泡茶近景应看到有体积的手指；本轮修改隔离源候选，不安装、不发布。真实交互、1 秒闭合预算及可环绕 3D 约束不变。

原卷指公式在 length/radius 超过 2.35 后固定角度，却丢掉超出弧长的纵向位移。固定 x 下，末端位置仅依赖 depth，丢失一个体积自由度。新增可选 `ATRIUM_GRIP_TIP_STUDY=1`，把超出弧长沿末端切线延伸。该修复不改变运行时，只重新生成姿态。

- `tea-phases-study/detail/trajectory.json` 定位原残余：第 28、29 帧，导出顶点 1825/1826 为同一 Basis 位置，杯柄最近面 81。重复顶点不等于两个独立接触区域，但负向距离仍有效，不能忽略。
- `verify-atrium-hand-folds.py` 筛查相邻面夹角 >90° 且较 Basis 增加 >30° 的边；不是自交或解剖验收。
- 修复前后异常边数：GripRight 34→33，Quarter 3→1，Half 11→9，Late 41→38，GripTea 58→57。
- Late 最小三角面面积/Basis 面积从 0.0353→0.1238。最终握姿仍有显著折边，掌根/拇指问题未解决。

- 生成成功，脚本语法检查通过；源作用域检查验证中立 Basis 精确不变，各 key 的右手外顶点精确不变。运行时代码未改动；本轮未重新跑完整交互、移动性能或发布套件。

## 交叉评审与裁决
- 玩家/产品：公式修复是否可感知？近景有局部变化，但不足以显著提升整只手质感。保留候选。
- 游戏设计：是否改动操作节奏？运行时不变，轨迹释放状态正常；本轮未复验完整真实游玩。
- 美术：接触变好是否掩盖折面？新增源折角检查揭示强反例，最终 57 条异常折边，禁止以距离通过代替美术通过。
- 工程/性能：是否额外增加运行时姿态？未新增 key，仅修正已有姿态坐标；资源及手机性能仍需最终集成测量。
- QA/发布：改动是否污染其他身体区域？源作用域检查；新公式默认关闭，正式资产不变。
