# 眉眼整体神态制作

2026-09-23，正式资产基线为 `5393df1`，眉形实验脚本基线为 `409ffa4`。上轮产生了可复现制作与视觉反证，属于进展；完整七人生产美术目标不变。

玩家在中庭移动、靠近交谈，需要从面部辨认居民的自然神态，随后继续探索。此次面部修改不引入新输入或等待，不改变真实 3D 环绕。预算沿用桌面严格 60fps、180 calls / 500,000 triangles / 220 geometries；仅源检查和特写不能证明全场景可玩性。

## 制作与五视角反证

新 `ATRIUM_GAZE_STUDY=1|2` 强制隔离目录，在现有连续眼窝网格中调整睁眼口径、内外眼角倾斜和闭合线。搭配 `ATRIUM_BROW_STUDY=2` 略降低眉头，保留原眼球、虹膜和讲话位移，不把静态贴片替代为脸部。

| 视角 | 可证伪意见 | 验证与决定 |
| --- | --- | --- |
| 玩家/产品 | 收眼会从呆滞变为困倦 | 首版实际出现，否决；第二版减弱幅度 |
| 游戏设计 | 中性可看但眨眼或讲话破坏神态 | 桌面固定 0/25/50/75/100% 闭眼与讲话，移动另做连续自动眨眼和触控对话 |
| 美术 | 眉眼各自优化却不协调 | 同时比较正式版与当前眉形+眼口，正侧背及正常对话画幅；没有参考脸部特写，不虚报像素还原率 |
| 工程性能 | 眼睑增面、形变影响口鼻或动作 | 头部拓扑不变，变动限定眼窝；讲话相对位移不变，双档实际资产统计与 UV 检查 |
| 质量验收 | 闭眼样本通过就被当作美术通过 | 实际眼球表面射线覆盖与运行视觉分开记录，首版即使全覆盖仍因困倦神态否决 |

首版：上/下睑高度从 .016/.009 改为 .0125/.0075，眼角最大倾斜 .0015，眉头降低 .0025（头局部单位）。`v1-desktop/` 显示过度收眼，未采用。闭眼覆盖 4,961/4,961，最小间隙 .001817；修改局限眼窝，中性最大位移 .004142，闭眼 .0015，讲话位移差 0。

第二版：上/下睑 .0145/.008，倾斜 .0008，眉头降低 .0015，减轻首版的困倦神态。复现为 `ATRIUM_RESIDENT_IDS=you ATRIUM_BROW_STUDY=2 ATRIUM_GAZE_STUDY=2 ATRIUM_BUILD_ROOT=$PWD/tmp/portrait-study/gaze-v2`，Blender 执行 `scripts/build-atrium-residents.py`。

证据保存在 `evidence/atrium/gaze-study/`，各运行对照报告绑定实际请求资产 SHA。固定镜头但 idle 相位未锁定，不进行像素差分。所有移动结果是桌面 GPU 视口/触控模拟，不是真机性能。本轮候选未安装，未跑完整发布套件，不能宣称全七人完成。

## 第二版实拍结论

第二版比首版少了困倦感，正面和移动近景的上睑遮盖较温和，闭眼未见露白。但眼睑边缘和眼窝层次仍弱，眉体仍偏硬，整体人偶感没有解决。保留为后续眼形制作基线，不替换正式资产。下一步应提高睑缘和眼窝的可读结构，避免继续通过缩小眼睛掩盖神态问题。

当前候选源拓扑不变，变动局限于眼窝：中性/讲话各 334 点，最大位移 .001976；闭眼 332 点，最大 .0008（头局部单位）。讲话相对位移差为 0。源闭眼覆盖 4,961/4,961，最小间隙 .0018065。第二版双档 UV 通过；移动模拟连续表情 578 次及触控对话通过。首版同样完成 578 次采样，但因视觉原因否决。桌面对照包括 25/50/75% 闭眼、中性、完全闭眼和讲话。

第二版桌面 2,492,476 B / 26,558 三角面，移动 966,608 B / 24,525 面，均 7 图元。新增面数来自上轮眉体毛束；头部眼窝拓扑未增加。没有据此宣称全场景性能达标，当前正式版桌面严格 60fps 问题仍未解决。
