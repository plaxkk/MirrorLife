# 手指分离与图集缺陷定位

## 目标和结果

从短袖口候选的近景发现主角手指像粘连的拳块。首次玩家在交流、抬手与近距离环绕时应能辨认自然的手形。本轮保留真实三维、掌根连接、既有腕部控制和接触锚点，继续遵守既定场景性能预算，不改变探索与交流流程。七人目标不缩减为单次手部实验。

原源模型四指中心间距 .022，半径 .0162–.0182，融合前就广泛重叠。v1 在生成融合手之前将四指横向截面乘 .58，保留长度和原姿态；沿用 .0025 体素融合及每手 900 面预算。`ATRIUM_HAND_DIGITS_STUDY=1` 只对主角生效，构建必须在 tmp。对照基线为未安装的 cuff-v1，不包含鼻唇等未安装候选。

**手指分离有可见收益，但两个候选均未达到接入条件。** v1 手指能分辨，指根和拇指处却有尖锐暗斑；v2 处理图集背景后部分暗斑消失，但出现衣料颜色污染，不能作为修复安装。两版默认关闭，正式模型不变。

## 证据链

证据目录：`evidence/atrium/hand-digits-study/`。

1. `v1-gaps.json` 使用实际源合并网格、手骨权重筛选三角面，在手局部 z=-.060/-.065/-.070/-.075 做沿 Y 的离散射线横截面。原两手四层均只有一个投影连通段；候选左手 2/3/4/4、右手 3/4/4/4。只计宽于 .0025 的段。掌根网格仍为单连通、无非流形边。此检查证明所测截面的分离，不能证明所有指缝拓扑、解剖美术或接触。
2. `v1-mobile/` 实际导出移动模型四组肩肘腕姿态近景，在正常材质下可见分指和暗斑。
3. `v1-no-normal/` 仅本地请求注入关闭核心身体法线贴图，暗斑仍在。
4. `v1-no-shadow/` 仅关闭核心身体接收阴影，暗斑仍在。
5. `v1-flat-color/` 将核心身体替换为无颜色/法线/粗糙度贴图的纯色诊断材质，暗斑消失。结合前三项，优先定位到颜色图集，不能据此声称查明了每个坏纹素。诊断材质不进入游戏源或默认资产。
6. v2 增加身体 COVERAGE 烘焙，用同一有效覆盖区扩展颜色、粗糙度、法线背景，并断言有效覆盖像素逐项不变。`ATRIUM_BODY_ATLAS_STUDY=1` 为隔离研究开关。`v2-mobile/` 正常材质下部分黑斑转为浅色或蓝色，说明混合图集的邻域扩展会取到无关衣料颜色；明确否决其作为完整解决方案。
7. `v2-geometry.json` 的规范化顶点和有向面多重集逐项均相同。报告中列出的不同只有数组存储顺序，v1/v2 物理几何没有改变。此检查不覆盖所有材质/UV/形态键数据。

## 五视角自审

| 视角 | 反对意见与裁决 |
| --- | --- |
| 玩家/产品 | 近景分指会不会在游玩距离显得像细线？本轮只验证近景；需要全身和运动对照，不提前推广。 |
| 游戏设计 | 手指变窄会不会破坏持物？控制点和长度在制作中未改，但实际接触面积已变；持物、握持及九动作验收仍缺。 |
| 美术 | 分开了仍是僵硬块状手，是否只是指标改善？接受该反对意见，掌指比例与关节仍需精修，暗斑/串色必须先修。 |
| 工程性能 | 提高纹理分辨率是否只是掩盖图集分配错误？本轮没有涨面或涨分辨率，诊断转向手部专用纹理区域与材质边界。 |
| QA/发布 | 连通和 UV 检查通过是否能放行？不能；本轮视觉明确失败，两个候选均不安装。 |

## 复现与下一步

构建设置 `ATRIUM_RESIDENT_IDS=you ATRIUM_CUFF_STUDY=1 ATRIUM_HAND_DIGITS_STUDY=1`，以 `ATRIUM_BUILD_ROOT` 指向 tmp 下候选目录；第二版另设置 `ATRIUM_BODY_ATLAS_STUDY=1`。Blender 执行 `scripts/build-atrium-residents.py`。指缝检查脚本 `scripts/verify-atrium-finger-gaps.py` 接收 `ATRIUM_HAND_BASELINE`、`ATRIUM_HAND_SOURCE`、`ATRIUM_HAND_REPORT`。

`scripts/review-atrium-cuff-motion.mjs` 的 `ATRIUM_REVIEW_HAND_SURFACE` 可选 no-normal、no-shadow、flat-color，报告记录诊断模式、模块 SHA 和候选 SHA；不设置时使用原材质。全部图像来自桌面 Chrome 移动视口模拟，不是实体手机。

下一步给手部安排独立且足够的图集区域或保持清晰的材质边界，避免窄三角形缺少有效纹素以及跨材质扩色；保留分指方向，继续处理掌指比例与过硬关节。未运行本轮完整探索/对话回归、性能基准或九动作同步；没有新增用户反馈或上线证据。正式资产和运行指纹不变，远端推送仍受此前自动审批限制。整体生产美术目标保持未完成。
