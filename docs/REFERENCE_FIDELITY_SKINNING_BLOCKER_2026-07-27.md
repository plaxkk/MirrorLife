  以及“蒙皮 mesh 数越多越好”的阶段四计数。

## 为什么不能把尝试 3 当成阶段通过

阶段一表格要求 actors ≤55、opening ≤145，尝试 3 刚好满足。文档内嵌命令原来却写成
≤50 / ≤140；本次已统一到较晚、带“2026-07-27 修正”说明的表格口径 55 / 145，
没有放宽表格。

阶段四同时要求：

- 每角色蒙皮 mesh ≥8；
- 每角色刚性小块 ≤60。

这与阶段一的实际优化方向冲突。把同骨架、同材质的变形表面拆成 8 个蒙皮 mesh，
会直接增加 draw call；合成 2 个蒙皮批才能同时保留桌面和移动 LOD。尝试 3 虽将
167–211 个 GLB mesh 降到 95–135，并把运行时 actor draw call 降到 55，但仍不满足
上述两个阶段四数字。不得通过改写指标把它宣称为成功。

## 物理阻塞与建议

阻塞点不是 collider 或骨骼能力，而是验收模型：

1. “蒙皮 mesh ≥8”奖励拆批，和“actor draw call ≤55”直接反向。
2. “真实 GLB mesh ≤60”统计了会在运行时安全合批的头发、面部和服装静态源件，
   不能代表玩家看到的刚性拼装数量。
3. 移动端必须能整批删除手指/褶皱细节；把所有表面焊成一个蒙皮 mesh 会超过 250k。

若后续重新开启，应先修改目标定义，而不是第四次改实现。建议用“受骨骼驱动的
articulation bone 数”和“运行时刚性 articulation draw call 数”取代
“蒙皮 mesh 越多越好”，然后重新批准一个不与 draw call 目标反向的阶段四门槛。
