# 全体人物结构与动作综合修整

基线 b7713e6。目标仍是首次或回访玩家在行走、交流和生活活动中看到可信的成年青年，能顺畅完成进入→探索→交流→共同决策→继续探索的循环。本轮覆盖眼眶、手脚、服装松量、主角站姿以及六位居民的适配；不以局部截图或测试通过宣称精品角色美术完成。原图没有面部特写，脸部细节属于设计补全。全双层预算保持 180 calls / 500,000 triangles / 220 geometries。

## 实际制作与被否决的方案

- 旧眼皮是叠在原生眼眶上的独立面，闭眼鼓起。逐点投射眼球会在边缘产生不连续的命中结果：早期三维覆盖分别发现 110、10 个穿透采样点。停止继续调整该方法，改为包含眼白、虹膜、瞳孔及高光网格的连续凸曲面约束。
- 单独包络仍存在双层表面，最终移除原生眼眶局部并重新布线，眼皮与脸部共用边界顶点。最初边界参数产生折叠尖片，改为按完整连通边界与弧长连接；增加原生面部拓扑分配，保留鼻、耳、嘴、颧及下颌。眼球退入眼眶，闭眼不缩放眼球，沿原接缝制作 Blink/Talk。
- 七名人物继续使用原有身份、骨架、体型、衣装和发型；分别调整下颌比例，头部基础来自已记录的 MakeHuman CC0 子集。居民长发、发髻、帽子保持原类型，未替换成同款短发。
- 手掌及原始五指在 Blender 合成连续网格，检查单连通与非流形边。许禾持物手势曾出现一个 3 顶点、不到 1mm 的退化碎片；仅清理这类小于 1mm 且不超过 4 顶点的碎片，大部件分离仍会让导出失败。保持腕骨与接触锚点，持有的生活道具不并入手部。
- 鞋底从矩形板与方形护头改为沿鞋楦的曲面橡胶底，保留最低落地高度；去掉独立方形侧片，保留鞋面、鞋舌和现有衣装类型。
- 主角上衣增加腰部松量，待机减少双肘过度弯曲，让手掌转向身体；行走保留摆臂。姿势修正在 `src/atrium-pose.js`，与便携动作导出共用，对话、生活动作与坐姿不套用放松站姿。
- 新发束、手部及鞋底保存可编辑 UV；依旧以实体造型和顶点色为主，没有宣称制作了扫描皮肤、发丝贴图或布料模拟。

## 运行画面的美术判定

再次打开原始参考图及七人运行截图比较，参考人物以宽松分层日常服装、自然肩线、小体块五官及灵活站姿为主。本轮改善了旧眼皮叠面、手掌拼接和矩形鞋底，主角放松站姿也增加了手臂与衣服的间距；这些是结构和动作改善，不能等同于整体风格已经接近原图。

仍明确不通过最终精品美术验收的部分：居民肩颈较硬，衣服褶皱和层次不足；短发居民的侧发块仍像整齐发帽；脸部光照和表情偏平、部分角度显得严肃；主角鞋体比例仍偏大。原图的人脸并非近景，因此没有可测量的“相似度百分比”。首轮整套测试失败原因为旧测试仍要求逐根手指的独立网格名称；改为核对导出的连续手部、双手接触锚点和源网格连通/非流形审计，不以保留无用空网格绕过检查。该审计不能证明每个指尖的审美与握持接触，需要运行近景一起判断。

## 运行验收追加发现与修复

持物截图发现腋下尖折，不能以手掌接触锚点通过为依据放行。Blender 检查表明，旧静止姿态让前臂和腰侧体积在 voxel union 时相连，肩/肘一动便将局部边拉长约 16.22 倍。修正各角色袖子与腰侧的实际间隙，保留原 20 个控制绑定，重新生成与新肩位对应的骨架绑定矩阵；将肩部权重过渡限制在缝合区域，并沿连通布面平滑权重，独立腰部和前臂保持各自控制。主角同一持物角度的最大边长拉伸降至 2.43 倍，更大抬臂角度为 3.63 倍。新增七人五种抬臂姿态的边长回归，禁止再用权重总和为 1 代替变形检查。它仍不是布料模拟，局部压缩、褶皱审美必须看运行图。

首候选录像压缩在原 120 秒进程期限内未完成，流水线据实失败；该次日志与 150.2 秒录制元数据保留于首候选目录。改用 H.264 fast CRF22、300 秒压缩期限，保持源帧时间与画幅，完整解码和帧数校验仍必需。该调整只影响交付视频编码，不更改游戏速度或性能采样。

随后全身运行图发现袖子分离后的肩顶仍有凹口，未把这一版本当作最终交付。先在临时目录重塑上端三圈袖面向领口的收拢曲线，审查正侧面和五姿态变形后才应用全员；没有用独立肩甲遮盖接缝。中间候选 `f69862045f81fdaabe82797f94ab3bdc73d970d96f4e7a09dd8339704d17a451` 的桌面帧时间为 16.8/83.8/133.6ms、99/479,012/80 峰值，移动模拟为 16.7/17.6/66.5ms、81/313,576/76 峰值，原始数据保留在 `character-finish-shoulder-pass/`。该候选在楼梯验收阶段主动终止以替换肩线，不宣称整体验收通过。
