# 主角眼神、发束与肩袖修整

基线 `09ef669`。目标玩家是在天井生活馆首次探索、接近居民并交谈的玩家。本轮改善主角近景的紧张眉眼、头发厚重感与肩袖硬边，保持探索→交流→共同决策→继续探索的真实 3D 流程。先完成主角样板，不批量改变居民身份。预算继续为全场景 180 calls / 500,000 triangles / 220 geometries；不以截图或资产面数代替实际游玩及性能。

## 设计与交叉审查

以下是同一执行者按五个视角自审，不是外部人工美术验收。

| 视角 | 可证伪的反对意见 | 验证方式 |
| --- | --- | --- |
| 玩家/产品 | 降眉和增大虹膜可能让人物显凶，而非自然 | 相同运行镜头对比正面、侧面、全身和说话表情 |
| 游戏设计 | 静态肩形改善却在持物和坐下时折叠 | 八姿态衣装检查、持物、坐立、两梯与实际输入回游 |
| 美术 | 降低发束厚度可能暴露头皮、失去侧分轮廓 | 正侧背四向、头顶斜视与运动截图 |
| 工程性能 | 导出后的 LOD 或形变成本增加 | 双档资源统计、同候选桌面及移动模拟测量 |
| QA/发布 | 虹膜修改破坏闭眼覆盖，动作源与运行资产不一致 | 闭眼深度检查、运行眨眼/说话、重烘九段动作与完整回归 |

## 实际修改

- 仅主角：降低眉毛位置、压低眉形高度；加宽虹膜及瞳孔，减少高光面积。眼球位置与眼睑锚点保持，闭眼包络由修改后的真实眼部网格重算。
- 仅主角：减小顶部发束抬升和截面厚度，保留侧分、连续发底、真实侧背面。
- 仅主角：在已有连续蒙皮衣身上局部松弛肩袖表面，不移动绑定关节，不改变肩部权重或提高局部面数预算。

## 验收与残余风险

实际查看主角正面、侧面、背面、全身、闭眼与浇水近景。眉眼间距收敛、顶部发束隆起减少，肩袖顶端过渡更圆顺。最强反方意见仍成立：背面发底仍有发帽感，眼角、嘴唇和皮肤材质粗糙；正常距离的整体质感仍未达到精品人物目标。完整材质制作、居民差异化、精细手脚、真实手机和长期稳定性未完成。

主角桌面 GLB 从 279,668 降至 278,272 字节，22,917 降至 22,893 三角面；移动 GLB 从 245,484 降至 244,416 字节，19,665 降至 19,641 面。九段动作同步重烘，其他六位居民模型未修改。成本差异见 `evidence/atrium/hero-expression/assets-comparison.json`。

首次验收在表情测试的对话输入阶段超时：脚本恢复 UI、放置诊断人物后只等待固定 400ms 即按 E，未等待真实交互提示。修改测试为等待“聊聊”提示并将窗口前置，保留按键前状态；随后对话与嘴部形变检查通过。由于初次失败没有按键时状态，不能断言固定等待是唯一根因。原失败及已完成十阶段记录保存在 `hero-expression/initial-run/`；续跑校验运行指纹与 dist 资产散列不变，未重选性能样本。造型前后对比固定中性表情，自动眨眼另测，避免偶然闭眼混淆形体对比。

首次同候选生产测量：桌面 P50/P95/P99 为 16.7/33.3/133.2ms，移动模拟为 16.7/66.9/183.3ms；两档帧时间目标均不通过。资源预算仍须与最终验收记录对照。这些样本保留，不能因模型面数下降而宣称性能优化。补充旧/新资产交替对照用于调查，不能替换上述结果。

发布范围为项目分支提交与本机预览，不是外网生产部署。未获得用户美术反馈；下一轮重点仍是眼角与嘴部表面、自然发根/发梢、完整材质，以及独立的帧时间根因调查。


最终运行指纹 `4dd2f56b171994d2294831095c7bf5167009e1bc7bd356fef517ffa5d64046ce`。含恢复资产检查在内共 22 个阶段完成，保留首次十阶段结果。28 项室内回归、构建、全员闭眼覆盖与八姿态变形、控制、接触、持物、坐立、楼梯、异常恢复及连续输入回游通过。录像 101.27 秒、1519 帧，完整解码通过；实际查看八格抽帧，涵盖入口、对话、一层、主梯、回廊、回程梯与退出。不是人工逐帧动画审核。

桌面峰值 99 calls / 488,720 triangles / 80 geometries；移动模拟 81 / 322,560 / 76，均在原预算内。两档帧时间不通过，资源预算通过不能替代性能通过。

## 同环境性能对照

在同一生产构建、同一桌面画幅下只替换主角 GLB，按旧→新→新→旧顺序分别进行六次输入环绕、30 秒以上测量。P95 分别为 17.5 / 17.5 / 17.4 / 17.5ms。该组结果没有显示可重复的主角资产退化；它不能解释首次两档长尾的完整根因，不能替换首次验收、证明严格稳定 60fps 或推断手机性能。完整样本、设备、资源与资产 SHA 见 `hero-expression/performance-comparison.json`，可用 `scripts/diagnose-atrium-hero-performance.mjs` 复测。
