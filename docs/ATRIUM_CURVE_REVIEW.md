# 还原度复核与楼梯曲面续作

## 本轮设计

首次玩家从入口辨认共享桌，再走近主楼梯、绕过梯脚、登楼并返回社交中心。目标是让正常探索距离的楼梯轮廓更接近参考图里的厚实曲面，并保留此前已打通的探索→交流→决策→继续探索循环。无新增操作或等待步骤。双层预算保持 180 calls / 500,000 triangles / 220 geometries，不为曲面提高上限。

## 还原度与完成度复核

基线为 637c10b。比较原参考图与同版本 `gallery-reference.png`：中庭、采光口、共享桌、右侧主梯、回廊和主配色已存在，但不是高还原度最终美术。

| 项目 | 判断与差距 |
| --- | --- |
| 空间、构图 | 有双层可走布局；参考中更紧凑的空间、右侧正向梯段及前景层次未还原 |
| 建筑轮廓 | 厚窗框与贯通门洞成立；立面重复、梯段过直，连续墙面层次不足 |
| 配色 | 五种主色已应用；参考中的暖白光照和深色对比尚不充分 |
| 光照、材质 | 有日光、阴影、接触 AO 与分材质；地面和墙面仍偏平，缺丰富间接光与植物投影 |
| 人物 | 七名真实 3D 角色与动作流程存在；脸、发型、服装和整体精细度尚未达到精品人物要求 |
| 玩法 | 此前已验证完整回游、七项发现、三位交流、一次决策和重入；不能由此推断人类游玩时长或趣味性达标 |
| 系统完成度 | 原居民身份未全面映射主世界，关系不是完整双向联动；真实手机、长期性能和外部人工验收未完成 |

试拍正向与偏左相机后，桌梯相对关系更容易检查，但镜头无法修正实际建筑比例。因此保留原校准相机用于连续前后比较，新增 `front-composition` 辅助视角，不把重新取景当作模型提升。相机位置、目标及截图文件记录在 `gallery-cameras.json`。

## 实施

将两侧细长的旧曲面构件替换为更饱满的封闭圆角侧墙：32cm 宽、梯脚向外舒展、腰部增厚，顶部过渡至平台。同步移动扶手和立柱的平面位置；新增与可见侧墙同顶点的三角网格碰撞。22 个踏步、斜梯底及回游布局保持。源文件为 `models/atrium/atrium-master.blend`，制作脚本为 `scripts/refine-atrium-stair-returns.py`，导出场景双档 GLB 与可复用楼梯套件。

这是依据参考轮廓的原创近似细化，精确曲率、后侧和底部均为推断。没有使用付费服务或新增第三方素材。它仍不是参考图中完整的弯曲建筑体与更陡主梯。

## 五视角反对意见与验证

以下为本轮自评，不冒充独立人员审查。

| 视角 | 可证伪的反对意见 | 验证 |
| --- | --- | --- |
| 玩家/产品 | 梯脚外扩会卡住绕行 | 实际按键主梯上下、两层回游与梯下往返 |
| 游戏设计 | 侧墙侵入梯面或挡住另一条路线 | 踏步顶面回归、主梯及回程梯运行检查 |
| 美术 | 曲面法线朝内、接缝或扶手悬空 | 封闭网格方向检查、同相机前后图、梯脚近景与背面 |
| 工程性能 | 增加曲面超过 500k 预算 | 冻结候选后顺序采集桌面和移动模拟渲染峰值 |
| QA | 只有渲染墙，没有物理阻挡 | 实际碰撞网格及梯脚横向接触回归、原窗墙与完整流程复测 |

初次候选虽然自动验收全通过，但梯脚近景发现旧版 flowing shell、冠条和底座仍与新侧墙重叠。因此该候选被美术检查否决，保留截图及自动结果于 `evidence/atrium/curves/rejected/`。修正为完整替换旧装配，冠条并入同一封闭表面的材质区域，旧分段近似碰撞也由新精确网格替代。此例明确说明自动通过不等于美术通过。另发现旧导出器把所有面材质归零；修正为按材质身份合并槽位，在清空/重建槽位之后恢复逐面索引，并新增桌面/移动 GLB 材质回归。最终候选重新完成验证，结果如下。


## 已检查的视觉证据与残余差距

已查看最终运行的原校准镜头、梯脚近景、梯底和背向视角。新旧侧墙、冠条与底座重叠已经消除，暖黄/薄荷色顶边在运行 GLB 中保留；仍可辨认长直梯段、简化的端面和低细节周边门廊。整体构图变化有限，不能把装配修正描述为大幅提高参考还原度。

人物本轮没有改动。人物的脸、发型、服装、步态自然度，建筑比例及侧窗层次，真实间接光和植物投影，仍是后续主要工作。近墙极窄处镜头收缩并淡出人物的问题仍在；专项回归通过不等于所有衣物和所有接近方向都不会穿插。

桌面场景 GLB 从 2,822,236 降为 2,778,184 bytes，三角面从 201,415 降为 196,655；移动场景从 1,999,500 降为 1,959,972 bytes，三角面从 121,209 降为 118,377。完整 public 资产清单从 14,115,033 增至 14,444,502 bytes，新增精确碰撞/套件数据也有成本，不能宣称整个交付包变小。相较旧版，多材质保留增加两个渲染批次，需在原预算内实测。
