# 主角短收口袖口

## 目标与裁决

上一轮唇部调色对照收益有限，转回参考图支持的正常游玩尺度与日常衣装轮廓。现有主角袖口高 0.075 源局部单位，中间鼓起，正面全身读成厚护腕。首次玩家在行走、靠近交流时应看见连贯的衣袖与手腕，而非分离的硬圈。保持原探索→交流→继续探索流程、人物身份、真实三维和 180 calls / 500,000 triangles / 220 geometries 预算。

`ATRIUM_CUFF_STUDY=1` 仅为 `you` 启用：保留底端 z=-.301、半径 .047/.043，将顶端 -.226 下移到 -.253，收口高度减少 36%；中段半径从 .061/.057 降到 .055/.051，顶端保留 .058/.054 与袖身重叠。沿用实际三维闭合壳、原肘关节绑定，不添加贴片或运行时替代。输出强制 tmp，默认关闭。基线是当前已安装主角，未叠加未安装的下颌、鼻唇或唇色研究。

**保留进入接入准备阶段，尚未安装。** 全身正面对照中厚护腕感明显减轻，行走背面也有收益；近景仍缺少罗纹/布料表现，不能判定整体生产美术完成。四组诊断姿态的左腕近景没有看到明显裂口，但这不是完整运动范围或连续碰撞证明。手指块状粘连、肩胸硬壳与鞋形仍是明确剩余问题。

## 复现与交付边界

构建使用 `ATRIUM_RESIDENT_IDS=you ATRIUM_CUFF_STUDY=1 ATRIUM_BUILD_ROOT=$PWD/tmp/portrait-study/cuff-v1`，Blender 后台执行 `scripts/build-atrium-residents.py`。源范围检查执行 `scripts/verify-atrium-cuff-scope.py`，环境变量 `ATRIUM_CUFF_BASELINE`、`ATRIUM_CUFF_SOURCE` 指向两份 blend，`ATRIUM_CUFF_REPORT` 指定 JSON。

运行姿态检查执行 `scripts/review-atrium-cuff-motion.mjs`，使用 `MIRRORLIFE_BASE_URL`、`ATRIUM_REVIEW_CANDIDATE`、`ATRIUM_REVIEW_OUTPUT`，移动档另加 `ATRIUM_REVIEW_PROFILE=mobile`。必须使用本地开发服务器；报告保存原运行模块与注入模块 SHA。
