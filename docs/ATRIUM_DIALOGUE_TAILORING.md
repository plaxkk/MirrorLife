# 对话人物肩袖与图集漏色修复

## 目标与边界

首次玩家靠近林晓并交谈时，肩袖轮廓更自然，动作中不出现黑色破片；退出后仍可连续探索。保留完整实时 3D、环绕、碰撞、坐立和人物身份。此次修改林晓正式衣装与共用烘焙保护流程，不宣称全员、手部、发型或生产美术已经完成。

预算沿用 180 calls / 500000 triangles / 220 geometries，桌面 P95 16.67ms、移动 P95 33.33ms。桌面触摸模拟不能替代真实手机。

## 合并状态核实

GitHub PR #28 确已合并，合并提交为 `ff869de4db84d211aa22169e682aa8d0ea11ee96`，但实际合入的分支头是首批上传的 `3d93211`。此前网络中断留下的后续 59 个本地提交没有随该 PR 进入 main。它们已保留在 `codex/dialogue-tailoring`，并合入最新 main；没有重置、丢弃或假称已上线。

## 改动与根因

- 林晓每侧肩位向内收 20mm，袖山提高 30mm，收敛上臂截面。骨架与衣装同配方生成，没有单独挪动展示网格。
- 连续对话帧发现右袖细黑缝。源网格静态检查没有发现对应胸前交叉或反向可见面；进一步解码正式 GLB，发现 4 个上身三角面中心采样为纯黑，其中两个位于右袖。
- UV 证据显示这些小面在图集里过窄，部分在解码后已退化成线，无法可靠采样烘焙像素。不能用调光或填几何解释这个缺陷。
- 在手部保护区与主体 UV 之间的空白间隔，为移动分辨率下小于一个像素宽、源颜色及粗糙度一致的衣料三角面分配保护采样。采用常量调色板坐标，保持原色、粗糙度与中性切线法线；不跨材质扩色，不修改蒙皮。原有可分辨的织物区域继续正常烘焙。
- 增加导出后黑色采样回归检查，并为实际网站验收增加三张连续对话动作近景，避免仅用有利单帧判断。

## 五个视角的反对意见

- 玩家/产品：局部修形是否只在开发近景看得见？同时保留普通对话镜头和实际进出路线，不能用近景替代玩家体验。
- 游戏设计：收窄肩位是否破坏动作与坐立？检查源文件八姿势、站起交流、回复、退出与重新就座。
- 美术：保护区会不会抹掉全部织物细节？仅作用于移动档无法分辨宽度的统一材质小面；仍需在连续动作和四周视角人工检查。手指、掌部、发束和腋下形体仍不合格。
- 工程：增加 UV 接缝会不会增加解码顶点？会；核心解码顶点由本轮仅修形版的 11813 增至 12943，面数不因此增加。最终林晓桌面 1665112 B / 23789 面，移动 687024 B / 21393 面。必须保留这个代价，并以实测判断。
- QA/发布：会不会把部分上传当完整合并？已明确记录 PR #28 的实际合并头；最终网页响应 SHA 必须匹配正式 GLB，不能用候选请求覆盖来验收。

最强反方结论：修复可证实的图集缺陷，不等于人物具备生产美术质量；正常镜头仍有前景椅背遮挡，肩腋、手部、头发和环境需要整体提升。

## 完成层级

本轮目标是可复现的肩袖修形与漏色修复，生产美术目标保持未完成。真实手机、长时间游玩、公网部署与真实玩家反馈仍未验证。后续应继续处理完整人物的掌指、肩腋、发束和场景构图，不通过更多分辨率或更多脚本通过率代替视觉判断。

## 最终网站验收
