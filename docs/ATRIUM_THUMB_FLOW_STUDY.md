# 拇指过渡区变形研究（2026-09-24）

## 目标对齐
继续七名角色生产美术目标。上一轮修复末端弧长并发现掌根异常，本轮针对泡茶近景中拇指根部折痕。玩家应看到有体积、过渡自然的握持；仍保持真实 3D、1 秒闭合预算、取消与释放。候选未安装，不改变正式资产。

## 原因与修复
原拇指 x 位移为 22 mm × smoothstep((-x-42 mm)/25 mm)，其映射导数最低为 1-1.32=-0.32，过渡区发生顶点顺序反转。可选 `ATRIUM_THUMB_FLOW_STUDY=1` 使用相同速度场的 32 次小步积分，每步重新按当前位置计算权重，单步 x 映射导数下界为 1-1.32/32=0.95875。生成时执行，运行时仍使用已有形状键。

这一单轴单步性质不证明整个三维变形无自交；它改变了最终拇指位置，必须重新检查接触和外形。未放宽折角或穿插阈值。
