# 玩家人物造型续作

历史记录：对应 c400168 衣装阶段。后续头部结构重制见 `ATRIUM_CHARACTER_STRUCTURE_REVIEW.md`；本文旧样件未采用结论不代表后续修正后的模型。

基线 43cf103。首次玩家会长时间从背后观察自己，并在交流时看到正侧脸；本轮集中改进可操控人物的日常夹克与发型体块，保持原移动、探索、居民交流与共同决策循环。用户反馈人物模型仍粗糙，不能继续用构建通过或场景远景当作人物完成证据。

制作：连续蒙皮衣身分出浅色插肩袖，取代整身近黑的视觉合并；真实立领、拉链带、拉片和斜向袋口替代隆起的胸口块件。发型改为不等宽的偏分发束与少量冠顶挑束，保留头皮覆盖，检查根部与头部连接。本轮仅更新玩家，未把居民或整体人物美术标记完成。所有几何为项目原创 Blender 制作，沿用现有许可，无付费资产。

预算仍为整个双层 180 draw calls / 500,000 triangles / 220 geometries。保持七人身份、原骨架与动画接口、真实三维环绕和通行碰撞。

| 美术 | 发束悬空或衣领穿颈，袖部像硬甲 | 正侧面近景及运动图，保留粗糙处记录 |

| QA | 旧动画 GLB 或移动 LOD 未同步 | 动作重新导出，双档及完整流程检查 |

以下为自评与自动运行证据，不是独立人工美术验收。最终候选运行结果见下方。

第一版直接按面中心分色产生锯齿，已改为四个平面切割真实接缝。玩家连续衣身由 1,700 增至 2,368 三角面，局部分配明确改为上限 2,400；其他居民仍为 1,700，整个双层 500,000 上限不变。新增 668 面用于精确接缝而非增加独立覆盖模型，需以最终运行峰值确认总预算。切缝后重新检查封闭性与蒙皮权重，不能沿用切缝前报告。


## 头部试制未采用

另以 MakeHuman 的 CC0 图形基础网格试制真实鼻颧、下颌和耳部，未引入其 AGPL 程序代码。官方许可：https://github.com/makehumancommunity/makehuman/blob/master/LICENSE.md 。此样件只保存在本机 `tmp/human-head/head-prototype.blend`、`tmp/human-head/review/`；没有混入正式 GLB 或覆盖现有头部。

运行正侧面检查否决了当前样件：头皮与现有发壳不贴合，原嘴部控制件与新嘴唇重复，颈部裁口外露，原眨眼方法也不能关闭新眼眶。下一次应先统一头皮/头发轮廓、修补颈口、完成上下眼睑闭合与嘴部驱动，再重做减面，不可仅替换头部网格便宣称人物完成。

## 性能诊断与异常修正

第一次衣装候选完整回归通过，但桌面帧时间 P50/P95/P99 为 16.7/32.9/50 ms，不能宣布稳定 60fps。其指纹为 `ae5fd87f3cdfc40ff1a6c287426670813515fea46d314ce6aec3aff762274a93`。随后新旧 GLB 交替四轮都有慢帧，且真实关闭页面触发 Rapier 已释放对象访问；原始失败数据保存在 `evidence/atrium/hero/performance-abba-initial.json`。该次诊断不是通过报告，也不足以把慢帧归因于模型。

已给销毁后的存档回调加守卫，并在异常回归中增加真实进入后关闭页面、收集未捕获错误的测试。最终生产候选重新完整测试，不用挑选的诊断帧率替换生产测量。


## 与参考图仍有的具体差距

对照 `design/references/atrium-visual-target.png`：参考人物肩颈衔接、头身比例和衣服轮廓自然，服装有松量与肘膝褶皱；当前人物躯干收束过直、头部近景仍尖窄、手掌与手指像分段件、鞋体偏厚，衣服虽连续蒙皮但缺乏可信褶皱和织物层次。新插肩配色与日常夹克结构只改善了局部可读性，不能算完成参考人物的还原。六位居民本轮没有重制。建筑光照、植物密度与窗洞变化也未因本轮衣装修改而解决。


## 最终候选测量

指纹 `0ba2b62028502a428e93ddbc60da3cc4d75c40f9716d07e708bade49e374b164`。本机 Chrome 152 / Radeon Pro 5300M。桌面 1920×1080、DPR 1：帧时间 P50/P95/P99 16.7/17.5/17.7 ms，峰值 118 calls / 495,114 triangles / 94 geometries。移动适配为同一桌面 GPU 模拟 390×844、页面 DPR 3、渲染 DPR 1.25：16.7/17.5/17.6 ms，峰值 96 / 311,178 / 90。桌面严格 60fps 门槛未通过，移动真机未验证。

玩家桌面 GLB 为 222,524 字节、24,190 三角面；相对基线增加 1,338 面，计入人物阴影通道后的双层峰值增加 2,676 面，未提高全场景预算。移动 GLB 为 177,280 字节、19,213 面。模型源文件和九段动作已同步导出。完整运行回归状态以 `evidence/atrium/acceptance.json` 为准。


最终 18 个候选验证阶段通过，含 26 项试点测试、21 个控制检查、窗边接触、坐姿、两梯、异常流程和连续探索。录像 102.933 秒 / 1,544 帧，完整解码成功。已抽看八格路线画面及离开时的末段帧：正常移动、侧区与楼梯可见，但窄梯墙体仍明显挤占视野；末段处于离开后的页面淡入。不是完整人工逐帧验收，也不是参考图美术通过。
