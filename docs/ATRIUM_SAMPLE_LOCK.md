## 4. 验收标准（可证伪）

样板重建后，以下每一条都必须有当前指纹的证据，且允许被否证：

1. **肩袖**：正/侧/背三向近景中，肩点到上臂外侧为单一连续曲面；对同一轮廓做切线，不得出现斜率突变超过阈值的台阶。反方：窄化肩宽是否牺牲了动作自由度与坐立？
2. **领口**：颈根任意环绕角度下无可见背景/内部面透过；皮肤颈在领口上方连续露出。
3. **发**：四向 + 俯视下，发际线与发束分组可辨；不得存在仅靠某一固定朝向才能成立的后脑壳。
4. **衣料**：近景可辨缝线与褶皱；抬臂、坐立、转身三种动作下褶皱位置随形变移动而非贴图固定。
5. **手与鞋**：指部分组、掌部宽度、鞋底接触在近景与连续动作中成立。
6. **场景**：正常游玩画幅下人物与家具在地面有可辨接触阴影；木/布/玻璃材质在单一光向下可区分。
7. **性能**：不得突破 180 calls / 500,000 triangles / 220 geometries 预算；桌面 P95 目标 16.67 ms（当前 18.1 ms 未过，需如实标注）。
8. **反方**：以上任一项若只在评审近景成立、在普通游玩距离不可辨，则判为不通过。
