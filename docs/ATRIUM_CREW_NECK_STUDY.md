# 前领口与颈部衔接 · 2026-09-23

上一轮实际网格内搭与开口已形成，截图仍显示高领围兜；本轮基于 neck-v2 同步下移前领口和延长颈部下端，不改变头部与骨骼。完整七人生产美术目标保留，本轮只是制作进展。

首次玩家看到自然的日常衣装，靠近交流，再继续探索；角色身份、真实 3D 环绕、交互反馈和等待逻辑不变。预算仍 180 calls / 500000 triangles / 220 geometries，衣装 2400 面。假设：圆弧前领口最多下降 30mm，颈部下端延长 35mm 并渐变扩宽，移除遮挡前方的封闭罗纹圈，可能改善高领感且保持覆盖。后侧帽兜保留。

五视角自审：玩家质疑露颈只是小变化，要求全身；设计质疑转头时裂开，要求正侧背及表情/行走；美术质疑颈部变粗或过长，要求与 neck-v2 对照；工程质疑额外皮肤影响批次/贴图，要求双档统计；QA 质疑领口露出网格空隙，要求实际运行图和源形变。最强反方意见：上胸整体仍是简单锥形，降低领口不会自动解决肩袖、躯干松量和全身人偶感。

ATRIUM_CREW_NECK_STUDY=1 必须与 ATRIUM_OPEN_NECK_STUDY=1 一起使用，仍强制 tmp 输出。完整复现沿用 neck-v2 的源皮肤、脸型、眼睑等隔离开关，输出 tmp/portrait-study/crew-neck-v1。未安装或上线。


## 实际结果

正面和四分之三里，前领口从横向高领变为下凹圆弧，浅色内搭层次保留；本轮检查的正侧背静态图未见明显空隙。但颈部仍偏柱状，领缘有不均匀感，肩袖和整体衣料仍不够自然，暂不安装。静态图不能证明所有转头角度覆盖，后续需补转头和完整服装动作验证。

桌面 GLB 2,976,056 bytes / 25,876 triangles，移动 1,111,832 bytes / 23,112 triangles；相对 neck-v2 减少 180 / 94 面，图数仍 10。两档各 4 项纹理 UV 检查通过；八姿态源拉伸保护通过，最大全身边长比 3.66392、最坏 P99 1.30089，不能据此宣称无穿插或真实布料。桌面对照含真实 W 键移动三帧与位置记录，errors 为空；没有覆盖完整玩法、异常恢复和真机性能。

五视角裁决：内搭领口的自然度有局部改善，成本下降，但反方关于整体硬壳和颈部比例的意见依然成立。保留候选用于下一轮制作，不扩大到全员、不上线。全七人生产美术及原图还原、性能、用户反馈的总目标仍未完成。

移动模拟的连续表情与实际对话输入检查通过，578 次采样，errors 为空。使用候选移动 GLB，属于桌面 GPU 视口模拟，不是移动真机验收。
