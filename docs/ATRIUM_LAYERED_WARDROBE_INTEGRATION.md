# 分层领口与贴面抽绳接入

2026-09-23，正式基线 `d328bed`。上轮眉眼已接入，是实际进展；本轮推进参考图的深色外套与浅色内搭层次。完整七人生产美术与高标准还原目标保持未完成。

首次玩家进入中庭、移动观察居民、靠近交流，再继续探索。此次希望让正常游玩距离的衣装层次更可信，不增加输入或等待步骤；保留真实 3D 环绕、动作与碰撞。预算仍为严格桌面 60fps、180 calls / 500,000 triangles / 220 geometries，衣身局部 2,400 面。

## 实际制作

在当前已修复颈部蒙皮的主角上重建此前隔离的半开领口：浅色内搭位于实际切割出的加权衣面，局部内收，前领口下移；拉链两侧分开、拉头下移，抽绳向外侧布置。内搭与外套隐藏连接仍连续封闭，不是可脱卸的两件完整衣服。

首版正面实拍发现抽绳局部断开。真实绳面采样确认，原四个锚点之间的长连线穿进弯曲衣面：左右分别 56/69 个采样点穿入，最深约 5.13/6.37 mm。改为每约 6 mm 沿实际衣面取样，并降低微小绳体横截面细分。修复版每侧 1,704 点均有衣面命中、零穿入，最小源间距约 1.75/1.52 mm。该检查包含三角形内部，不只看锚点；它只证明源中性姿态，运行 LOD 与动作另用实拍验证。

当前源、master、双档 GLB、动作源及九动作同步接入；清单主角记录更新为实际衣身 2,300 面和权重误差，源路径指向正式模型。默认启用分层衣装，`ATRIUM_LAYERED_WARDROBE=0` 且不设置显式开关可回到此前封闭领口。旧研究复现应先关闭此默认，再设置相应 `ATRIUM_OPEN_NECK_STUDY` / `ATRIUM_CREW_NECK_STUDY`。

## 五视角复核

| 视角 | 反对意见 | 当前证据与界限 |
| --- | --- | --- |
| 玩家/产品 | 只改近景，对游玩无收益 | 正侧背、全身和真实 W 键行走三帧中，浅色内搭打破封闭深色前胸；正常画幅可辨 |
| 游戏设计 | 低领口在转头时露出断颈 | 当前最终模型六组头部姿态、每组三视角，未复现此前大面积露缝；不是全范围或完整自然动作证明 |
| 美术 | 内搭仍像色块，衣服仍像硬壳 | 存在真实切线与内收，抽绳连续恢复；肩袖、后帽和衣身松量仍生硬，不作整体美术签收 |
| 工程性能 | 更清晰衣装会耗尽当前面数预算 | 桌面 26,532 面、移动 24,469 面，比基线减少 26/56 面；实测全场景资源另记录 |
| 质量验收 | 沿用旧研究的形变证据会漏检 | 重建衣身逐项相等断言失败，保留失败并直接重测实际安装源八姿态及六组转头；不拿首版通过替代最终版 |

## 证据与残余风险

证据根目录 `evidence/atrium/wardrobe-current-study/`。`desktop/` 为正式基线与首版分层衣装；`v2-desktop/` 为抽绳修复对照；固定相机但 idle 相位未锁，不能作像素差分。均含真实行走位置记录。`v2-mobile/` 为最终移动档 577 次连续表情采样和实际触控对话，通过；移动是桌面 GPU 模拟。

`v2-cord-clearance.json` 为真实源绳面间距；`cloth-equality-failure.txt` 保留衣身逐项相等假设失败。重建间差异根因本轮未查明，故不声称衣身源逐项一致。`integration/deformation.json` 直接覆盖最终安装衣身；`integration/face-invariants.json` 证明最终脸部 Basis/Blink/Talk 与之前正式源相同。`integration/head-motion/` 是最终安装 GLB 的 18 张转头图；`integration/motion.json` 为便携九动作同步。28 项相关回归及生产构建通过，构建仍有大包提示。

最终桌面 GLB 2,428,124 B / 26,532 面，移动 952,472 B / 24,469 面，均 7 图元；比基线少 63,876/13,680 B。衣身 2,300 面、封闭、权重误差约 1.003e-7。没有新增单独材质绘制批次，不把单角色 7 图元等同于全场景调用数。

最终源八姿态的最大边长比 3.66392、最坏 P99 1.30089，通过既有严重拉伸保护；这不是布料物理或无穿插证明。最终 GLB 六姿态颈部固定区 37 点的最大身体局部漂移约 2.98e-15，与实拍一同支持当前颈部修复有效，但仍不穷尽动作范围。

桌面同一生产构建 30 秒以上输入环绕：P50/P95/P99 为 16.7/17.5/33.4 ms，峰值 101 calls / 495,518 triangles / 81 geometries，无脚本报告错误。严格 60fps 未达标，P99 显示偶发长帧；历史测量不是控制变量 A/B，不据此认定衣装造成或解决尾部延迟。初末指纹一致：`05e494bdd4d936544ec2fc287fa70756d1b853e9ab38ea7144b1a33afbbe1c2a`。

同构建随后移动模拟：P50/P95/P99 为 16.7/17.5/17.7 ms，峰值 83 calls / 330,828 triangles / 77 geometries，触控移动约 1.82 米，无脚本报告错误。测量进程均正常退出，仍不是真机性能。部分截图 Node 在写出报告后延迟退出，持续轮询原句柄后均返回 0，本轮没有重启或强制终止这些验证。
