# 鼻唇与下颌体积协调研究

## 目标与裁决

面向在探索、环绕与对话中观察主角的玩家，减少恢复下颌后的嘴部后缩感，保持角色身份、真实三维和既有表情。基线是未安装的 jaw-transition-v3，而非正式资源。此次只调整 `you`，不表示七位人物已经达到生产美术标准。

v1 温和恢复鼻唇前后体积：基础头部与后续美术处理均曾压平这一带，两者叠加后，恢复下颌会暴露嘴部后缩。调整在既有美术处理之后执行，相同位移应用到 Basis、Blink、Talk。显式 `ATRIUM_FACE_BALANCE_STUDY=1` 且输出位于 tmp 才启用，默认构建不变。

**保留研究候选，暂不替换正式资源。** 侧面比例较基线协调，但正面提升较小，嘴角、鼻翼阴影与皮肤仍显僵硬，头发仍有硬块和碎边。现有证据不足以判定参考还原度、美术质量或真实设备性能达标。

## 证据

全部报告与截图位于 `evidence/atrium/face-balance-study/`。

- `v1-source.json`：505 个顶点变化，最大位移 0.01446952（头部局部坐标）；894 个眼眶或下颈部顶点精确不变。拓扑、UVMap、蒙皮权重、父级和世界变换不变。Blink/Talk 相对 Basis 的差值误差不超过 1.49e-8。未声称材质颜色或 FaceRoughness 数值完全一致，后续表面生成可能依赖新坐标。
- `v1-desktop/`：同相机基线/候选的正面、侧面、斜侧、背面、全身、闭眼及说话截图。待机相位没有锁定，不能解释为逐像素因果对照。已人工查看正面、侧面、斜侧、说话侧面及闭眼正面。
- `v1-coverage.json`：源文件闭眼状态实际眼球堆叠 4,961/4,961 采样被眼皮覆盖，最小间隙 0.00180650。仅证明该状态下的离散采样。
- `v1-mobile-motion/`：桌面 Chrome 移动视口模拟；578 次自动眨眼采样覆盖 0–1，触摸进入对话、选择玩家提问、关闭对话成功，说话峰值 0.84998，无页面异常。已查看移动视口正面。不是实体手机、口型同步或完整回归证明。
- `v1-resources.json`：桌面 2,428,088 B / 26,532 三角面；移动 952,440 B / 24,469 三角面。相比 jaw-v3 各增 40 B / 56 B，面数不变。不据此推断帧率改善。

## 复现

构建时设置 `ATRIUM_RESIDENT_IDS=you`、`ATRIUM_JAW_TRANSITION_STUDY=3`、`ATRIUM_FACE_BALANCE_STUDY=1`、`ATRIUM_BUILD_ROOT=$PWD/tmp/portrait-study/face-balance-v1`，使用 Blender 后台执行 `scripts/build-atrium-residents.py`。

源验证执行 `scripts/verify-atrium-face-balance.py`，分别用 `ATRIUM_FACE_SOURCE`、`ATRIUM_FACE_BASELINE` 指向 face-balance-v1 与 jaw-transition-v3 的 `models/atrium/residents/you.blend`，用 `ATRIUM_FACE_REPORT` 指定报告位置。桌面比较沿用 `scripts/review-atrium-hero-art.mjs`，移动动画沿用 `scripts/verify-atrium-facial-motion.mjs`，候选运行文件在构建根的 `public/assets/atrium/residents/`。

## 上线与目标复核

仅保存本地研究实现与证据；正式资源、运动资源、运行时指纹不变，不涉及线上回滚。远端推送仍受此前自动审批拒绝限制。没有新增线上用户反馈。

下一步优先对照角色参考修整嘴角和鼻翼的形状与明暗，再统一检查头发、眼神、皮肤及轮廓；不应通过继续叠加局部变形替代整体美术验收。下颌与鼻唇候选需要联合通过动作、参考还原度和性能验收后才能进入正式资源。
