# MirrorLife 代码与网站生产美术评估

评估日期：2026-10-13。代码基线：`0b9d92d`。范围：中庭 `atrium.html`、七名人物、当前资源、隔离服装候选及已有验收记录。未验证线上域名；本地构建验收不能替代生产部署验收，也不代表整个旧版 `game.html` 已全面通过。

## 结论

**尚未达到生产美术级别，不建议以“高还原完成版”验收或发布。** 当前是具备真实 3D 行走、环绕和居民交流能力的可玩原型。工程基础和制作工具有实际进展，但人物轮廓、角色差异、服装结构、材质与场景光照仍有明显原型感。不能把测试通过、提交数量或局部拓扑指标换算成美术完成率。

用户要求的七人整体品质、高标准参考还原和真实游玩连续性保持不变。面向首次及回访玩家，核心循环应是探索 → 认识居民 → 发现线索 → 共同决策 → 继续探索。画面应在正常游玩距离帮助辨认人物和理解环境，近距离对话也不能暴露明显拼接感。

## 2. 网站视觉验收

判定尺度以项目参考图的自然青年人物、层次丰富的日常衣装、温暖空间、柔和光影和真实环绕为准。参考图没有提供面部特写，因此不能宣称精确复刻某张脸。

| 维度 | 实际可见问题 | 优先级与验收判断 |
| --- | --- | --- |
| 人物整体比例与轮廓 | 正式 NPC 肩部尖硬、躯干与袖子像分段拼装；多名人物轮廓接近 | P0：生产美术不通过 |
| 脸与头发 | 脸型差异小，部分发型像整块帽壳；主角相对细化但与群体品质不齐 | P0：需要统一角色设计 |
| 服装 | 正式版本缺少可信的肩袖连接、衣料厚薄和褶皱；候选圆顺一些，但近似光滑胶衣，背部和腋下仍不自然 | P0：局部改善不能整体验收 |
| 手、鞋与接触 | 鞋部仍偏胶囊形；静态截图不足以证明持杯、坐姿、行走接触可信 | P1：动态接触证据不足 |

## 3. 验收证据质量与性能

本次对当前 Vite 生产构建进行三组本地桌面路径复测（旧记录另行保留）：正式资产、衣片候选、抬高袖窿候选。脚本用真实进入、WASD 行走、四次鼠标环绕、E 对话、点击回复、Escape 退出和离开后重新落座验证流程。三组均通过，每组保存 12 张连续截图，页面错误和失败 GLB 请求均为空。该路径只覆盖林晓交流，不代表全部居民和完整剧情验收。候选仅通过拦截林晓 GLB 加载作隔离比较，不能当成正式网站已经使用新模型。

**发现验收证据缺陷：** `edited/cloth-front.png` 的镜头被主角背部遮挡，不能证明林晓正面衣装质量。脚本的 `passed` 仅覆盖交互断言，不等于截图构图合格，更不等于美术通过。近景使用评审镜头，必须与普通玩家镜头证据分开；本报告用实际对话截图和无遮挡侧背图辅助判断，不用该正面图作通过依据。

## 4. 五个视角的反方评审

以下为本次同一评估者的五视角审查，不冒充独立多人评审。

| 视角 | 可证伪的质疑 | 当前证据与裁决 |
| --- | --- | --- |
| 玩家 / 产品 | 首次玩家是否能独立完成一次循环，而不靠测试脚本预设路线？ | UI 有目标，自动路径可走；缺无提示用户观察，保留疑问 |
| 游戏设计 | 交流与选择重复三次后，是否仍有变化和继续探索的动机？ | 状态逻辑测试通过，不等于有趣；需要完整循环试玩与行为记录 |
| 美术 | 正常对话和环绕是否仍显得像拼装模型？ | 正式阵列和实际对话可见硬肩、相似发型、平板衣料；不通过 |
| 工程性能 | 增加美术细节能否保持桌面和真手机预算？ | 历史面数接近上限、桌面 P95 超门槛；未证实可全面加细节 |
| QA / 发布 | 自动脚本全绿是否会把遮挡截图或候选当成正式交付？ | 已发现正面截图遮挡；证据审核必须独立于功能 pass |

最强反对意见：目前继续扩大局部模型研究，无法保证交付用户要求的整体视觉结果。应先收敛出一个完整可玩的生产样板，再扩展全员。

## 5. 达到生产美术的执行与验收顺序

1. **锁定完整样板：主角、林晓及其对话区域。** 一次审查全身比例、头发、五官、外套、裤装、手、鞋、坐立与对话构图；明确七人身份差异设计。玩家正常距离必须明显改善。
2. **完成结构与表面制作。** 先处理肩袖、腋下、领口、衣摆和手脚轮廓，再制作材质粗糙度、布料与皮肤层次。保存可编辑源文件、骨骼绑定、LOD、动画和授权溯源；现有回导验证不等于全部 UV/材质生产流程完成。
3. **同步处理样板场景。** 校准曝光、明暗层次、接触阴影、家具边缘、植物轮廓和窗外景深层次；不能指望人物精细化独自填平环境差距。
4. **在真实路线验收样板。** 正侧背及四向、远中近景、行走/坐立/对话/持物；保留 UI 正常画面。遮挡、穿插、足底滑动和动作变形逐项检查；不能只看静帧。
5. **样板达标后推广其余五人。** 保留每个人的脸、发型、体态、衣装和动作差异，逐人检查两档 LOD，不把单人通过外推到全员。
6. **性能、发布和反馈闭环。** 当前构建的桌面与真手机测试、完整异常回归、资源指纹、预览验收、回滚和线上观测齐备后再给生产通过结论。首次玩家能独立完成并愿意继续玩，才算体验兑现。

本报告不提供虚假的百分比或工期承诺。下一个有效里程碑是“一名完整角色与局部场景在正式玩法中达到统一标准”，而不是再增加若干参数实验。总体生产美术目标仍未完成。
