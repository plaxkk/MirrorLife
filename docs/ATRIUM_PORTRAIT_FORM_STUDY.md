# 完整面部比例制作

2026-09-23，基线 2b2fb1a。上一轮标准 AO 与阴影归因有可复现代码及对照证据，属于进展；没有达到生产美术。当前完整七人目标、原参考、真实 3D 玩法和桌面/移动验收仍保持全部范围。

玩家终点：首次玩家在靠近交流时看到协调、自然的青年面部，并继续交谈和探索；仅有局部材质或自动检查不足以兑现该结果。本轮以未安装的 skin-ao-v1 为比较基线，不改变正式资产、交互反馈或等待流程。原预算 180 calls / 500000 triangles / 220 geometries 保持。

五视角自审：玩家视角质疑变化只在大特写可见，须保留全身和正常对话画幅；设计视角质疑眼球层次压薄后凝视和眨眼失真，须源遮挡与实际动作检查；美术视角质疑收鼻后变尖、面颊过瘦或材质变脏，须正侧及四分之三视角；工程视角质疑拓扑重建带来预算/UV 退化，记录实际双档；QA 质疑使用旧覆盖报告，源和运行检查须绑定新 SHA。自审不是独立美术签收。

form-v1 以连续源网格调整：鼻部横向最大收束 19%，鼻梁向前最多 .004 head-local；下半脸横向最多收束 4.5%，平滑衰减且保留眼部锚点。虹膜、瞳孔和高光沿本地深度压至四分之一，重新安排层间位置，减少逐层外凸的珠状轮廓。眼睑仍基于实际新眼球包络生成，未缩放眼球来掩盖闭眼。

复现：沿用 skin-ao-v1 的所有隔离制作开关，追加 ATRIUM_PORTRAIT_FORM_STUDY=1，ATRIUM_BUILD_ROOT=$PWD/tmp/portrait-study/form-v1；Blender 执行 scripts/build-atrium-residents.py。新开关强制 tmp 输出。

v1 源闭眼 4964/4964 覆盖，最小 head-local 间隙 .003468，但三分之四实拍鼻侧过渡偏硬，未接受。v2 将鼻部收束改为更宽的高斯衰减、最大 14%，鼻梁前移减为 .002，避免局部轮廓过尖。

## 本轮结果

v2 鼻侧过渡比 v1 柔和，正侧和四分之三图已保存；眼周、唇周和皮肤仍不够自然，整体人偶感没有解决。因此两个样稿都未安装，不能把更窄的比例本身宣称为高质量。

实际可编辑网格测量：瞳孔与眼白的最前缘深度差从 .007800 降至 .001450（EyePivot 本地单位，运行还受父级缩放），没有用参数值代替源测量。这只是几何层次变化，不是美术完成率或视觉提升百分比。

v2 闭眼 4964/4964 采样覆盖，最小 head-local 间隙 .002912；对应当前源 SHA 在 v2-coverage.json。移动模拟自动眨眼 577 样本，范围 0..1，真实触控选择对话后口部响应，pageerror 为空；实际峰值及 GLB 指纹见 v2-mobile-motion/report.json。它不证明手机真机、同步口型或人工美术认可。

桌面 26050 面 / 2765240 字节，移动 23246 面 / 1061028 字节，均为 7 图元；相比 skin-ao-v1 增加 46 / 44 面。两个 LOD 与 master 均通过贴图 UV 检查，脚本语法和 diff 空白检查通过。现用双档模型 SHA 未改变，故未将旧 21 阶段发布报告冒充本候选回归。全身/正侧/四分之三与部分闭眼图绑定实际请求文件；待机相位未锁定，只作定性评估。

本轮没有达到生产美术签收。后续需结合统一面部表面细节与眼周结构继续制作，并回到七人整体、实际游戏尺度、性能和用户反馈验收；不能无限依靠局部比例微调代替整个人物质量。
