# 唇部颜色与粗糙度对照

## 目标与结果

面向探索中靠近人物、进入对话的玩家，检查偏红、偏亮的唇部是否是主角人偶感的主要来源。基线为未安装的 face-balance-v1，候选 lip-finish-v1 保持相同鼻唇/下颌几何，只降低唇色叠加强度并提高局部粗糙度。

**没有发现足以支持安装的明显整体收益。** 桌面正面对照中唇色稍淡，斜侧面嘴角及鼻翼仍生硬。保留可复现候选与证据，不推广默认设置。不能把调色幅度或通过检查本身当成生产美术进展。

重新检查 `design/references/atrium-visual-target.png`：原图支持青年比例、分组短发、分层外套与自然日常风格，但没有面部特写。近景脸部是设计补全，不能声称特定唇形或唇色的精确还原率。后续应优先从正常游玩尺度检查整体轮廓、发型、肩颈和衣装，避免持续只调近景局部。

## 实现与证据

- `ATRIUM_LIP_FINISH_STUDY=1`：唇色混合权重 .65→.38，目标色相对基础肤色的绿/蓝系数 .59/.64→.72/.72，唇部粗糙度降低量 .14→.07。沿用原唇区软遮罩，不添加烘焙光照。构建输出限制在 tmp；默认关闭。
- `evidence/atrium/lip-finish-study/v1-source.json`：头部顶点、面、全部形态键、蒙皮权重、基础 UV、父级及世界变换精确相同。1,361 个面角颜色变化，最大通道差 .07188651；粗糙度差为 0 至 .06999791。检查仅覆盖头部，不推断其他物体或美术质量。
- `v1-desktop/`：基线/候选正侧背、斜侧、全身、中性/闭眼/说话截图；人工查看正面前后与候选斜侧。待机相位未锁定，不做像素差因果分析。
- `v1-mobile/`：移动资源档同视角对照，用于检查低档外观，不是实体手机、性能或真实触控对话验证。人工查看移动档全身图后，肩胸横向体积、直筒袖口与鞋形的简化比唇色更显眼，应提高整体造型的优先级。
- `v1-resources.json`：桌面 2,428,072 B / 26,532 面，移动 952,420 B / 24,469 面；比面部基线减少 16/20 B，面数不变。此字节差没有可感知性能意义。

候选源 SHA256：`d4dbca9ffedfaa1822bea252085e7f9420e31e8cf8a85348e56d53ad7ff5b6ef`。

复现：使用 Blender 执行 `scripts/build-atrium-residents.py`，设置 `ATRIUM_RESIDENT_IDS=you`、`ATRIUM_JAW_TRANSITION_STUDY=3`、`ATRIUM_FACE_BALANCE_STUDY=1`、`ATRIUM_LIP_FINISH_STUDY=1`、`ATRIUM_BUILD_ROOT=$PWD/tmp/portrait-study/lip-finish-v1`。`scripts/verify-atrium-lip-finish.py` 使用 `ATRIUM_LIP_BASELINE`、`ATRIUM_LIP_SOURCE` 指定两份 blend，`ATRIUM_LIP_REPORT` 指定报告文件。
