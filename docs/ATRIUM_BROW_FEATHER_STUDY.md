# 眉形毛流与轮廓续作

2026-09-23，正式基线 `5393df1`。上一轮皮肤接入是实际进展；本轮针对当前模型粗黑圆管眉，继续制作近景神态，完整七人生产美术目标不变。

玩家旅程仍是进入→探索→交谈→继续探索。面部应在正常对话距离可辨，而不只在放大图中有细节。保留真实 3D 环绕、原身份与表情，不增加输入步骤。预算沿用 180 calls / 500,000 triangles / 220 geometries 及桌面严格 60fps，不将单角色面数等同于场景性能。

本轮在当前曲面虹膜与轻量皮肤基线上制作，未沿用旧眉形研究的旧脸部资产。`ATRIUM_BROW_STUDY=2` 启用新的错开根梢毛束和浅眉体；`1` 保留此前样稿，默认仍不启用。两者必须输出到 `tmp/`。

## 制作与反证

首版缩薄底层到原样稿的 48%，添加 48 束毛流。实际正面截图显示眉毛在对话距离过细，桌面又增加 1,474 三角面，否决。第二版恢复底层到原样稿的 115%，毛束减少到 32，扩大毛束在上下边缘的分布，让毛流负责轮廓过渡。

五视角自审：

| 视角 | 反对意见 | 回答方式 |
| --- | --- | --- |
| 玩家/产品 | 细眉在真实对话距离消失 | 首版实际发生，保留图并修正厚度；第二版必须复拍 |
| 游戏设计 | 眉形改变使表情持续惊讶或呆滞 | 比较正面、闭眼、讲话，连续眨眼与真实对话另验 |
| 美术 | 毛束成为锯齿、侧面悬浮 | 贴合实际额头表面，检查正侧面及移动档，不以源网格完整替代视觉签收 |
| 工程性能 | 增加许多小几何却没有收益 | 首版 27,050/24,783 面，7 图元；基线 25,576/24,017 面，否决该成本收益组合 |
| 质量验收 | 旧研究的验证不能支持当前脸型 | 新建源检查脚本，与当前正式源 Basis/Blink/Talk 逐坐标比对，运行对照绑定实际请求 SHA |

证据目录 `evidence/atrium/brow-feather-study/`。`source.json` 为首版源检查：左右各 836 顶点、非流形边 0、实体体积为正，脸部三个形变坐标完全一致。`desktop/` 是首版同镜头运行对照，命令正常退出；idle 相位未锁定，不作为像素差分。

构建复现：设置 `ATRIUM_RESIDENT_IDS=you ATRIUM_BROW_STUDY=2 ATRIUM_BUILD_ROOT=$PWD/tmp/portrait-study/brow-feather-v2`，使用 Blender 执行 `scripts/build-atrium-residents.py`。首版参数历史保存在本文件，当前脚本实现第二版。

此研究没有替换正式运行资产，不宣称发布、真机、完整可玩性或七人美术完成。当前全局短板仍包括面部神态、发型、衣装连续结构及性能稳定性。

## 第二版结果

`v2-source.json`：左右各 580 顶点、非流形边 0、实体体积为正，Basis/Blink/Talk 与当前正式源逐坐标相同。双档 UV 检查通过。桌面 2,491,608 B / 26,558 面，移动 966,264 B / 24,526 面，均 7 图元；相对正式版增加 982/509 面，不能由此推断全场景满足性能预算。

`v2-desktop/` 正侧背、中性/闭眼/说话对照显示眉体可读性恢复，眉尾收尖，侧面未观察到明显悬空；但仍像实心图形，细束对自然神态的收益有限。`v2-mobile/` 记录最终移动档 570 次连续表情采样及实际触控对话通过。移动是桌面 GPU 模拟；未做性能或完整发布验收。

决定：保留候选，暂不安装。下一步联合处理眉形、眼睑与眼窝神态，避免继续增加难以在游玩尺度辨认的小几何。此次结果没有支持生产美术完成。
