# 茶杯专用转腕与握点候选

## 目标与裁决

让泡茶玩家看到可信的侧面握柄，同时保持杯口朝上、动作结束后恢复探索手势。针对上一轮四指与杯柄方向错配，本轮增加茶杯专用转腕和补偿握点，水壶继续使用原握点。保留真实三维移动、环绕、照料反馈和全七人制作目标。

**方向调整有效，仍未通过接触美术验收，不安装候选。** 首版将杯柄长轴转向四指排列轴，但握点偏在指根。第二版将把手移入指弯，三个指端区间出现 3 mm 内采样点；同时近面法线筛查发现疑似穿入，不能用接近数量掩盖碰撞问题。下一步需要茶杯独立的指垫/拇指修形，而非继续平移整个道具。

## 制作与运行

在 `ATRIUM_HAND_GRIP_STUDY=1` 的隔离构建上增加 `ATRIUM_TEA_GRIP_STUDY=1`。`TeaWristOffset_1` 记录将四指排列轴转向杯柄长轴的转腕，`TeaGripAnchor_1` 存储逆向旋转补偿和握点。运行端仅对带这两个节点的候选应用转腕，手腕和补偿框架随茶杯状态渐变；水壶选择原框架。正式已安装资产没有专用节点，未更换其手势资产。运行代码改变，旧发布指纹不能代表本轮源码；接触报告记录模块 SHA。

首版局部握点 `(0,-.034,-.027)`，第二版 `(0,-.044,-.049)`，单位米。原型预览的位置覆盖记录在 `position-prototype/geometry.json` 的 `anchorOverride`；正式 v2 解码检查该值为 null，证明位置已写回源并重新导出。

## 证据

目录 `evidence/atrium/tea-grip-study/`：

- `v1-local/`：源静止姿态、实际导出手形与杯柄几何，四组指端最近距离 19.42/14.87/18.62/16.04 mm。首版位置不接受。
- `v2-local/`：同一选择规则（中立 z<-70 mm、X 四区间），最近距离 .056/.620/3.195/.504 mm；3 mm 内点数 6/3/0/10。但近面法线符号筛查中，疑似穿入超过 1 mm 的点数为 3/2/2/7，最深约 6.53 mm。有限顶点、最近面法线不能证明完整容积碰撞；该反例足以阻止放行。诊断图使用平面法线和半透明杯身，只作几何定位。
- `v2-source.json`：相对 hand-grip-v2，身体 Basis 与 GripRight 全部坐标精确一致；转腕乘补偿旋转与原握点朝向误差为 0，杯柄轴在新手局部坐标约为 `(1,0,0)`。仅证明源局部构造，不证明缩放后的动态世界状态。源 SHA `36bfa05416412a4a9546c857d3942ec0b6cdb62a634082d15713a8a185a9da7a`。
- `v1-contact/`、`v2-contact/`、`v2-mobile/`：实际 E 键触发照料、六个截图视角、动作自然完成后的形态释放检查通过，无页面错误。已查看 v2 桌面杯柄反向/俯视与移动俯视，握持方向比张掌托杯更合理，指垫接触仍待精修。移动为桌面 Chrome 模拟，并非触屏/真机测试。
- `v2-orientation.json`：桌面和移动各三个稳定持杯瞬间，杯口上轴与世界上轴点积最小 .99037/.99504，转腕混合权重均 >.9996。仅覆盖稳定截图时刻，未完成拿起、取消、反复触发全轨迹方向与手腕变形检查。
- `v2-resources.json`：桌面 2,477,020 B / 26,404 面，移动 1,092,872 B / 24,341 面，均 6 材质、7 绘制单元。相比 hand-grip-v2 仅新增节点和元数据约 376/372 B；原握姿整网格数据约 191 KB 成本仍存在。
- `regression.txt`：28 项回归通过；`build.txt`：构建通过，仍有大 chunk 提示。双档基础 UV、脚本语法、diff 检查通过。未测新帧时，未同步九动作，不声明候选发布完成。

## 五视角复核与后续

| 视角 | 质疑与裁决 |
| --- | --- |
| 玩家/产品 | 手侧握是否比张掌托杯可信？正常近景改善，但指垫穿入疑点尚在，不能称体验完成。 |
| 游戏设计 | 茶杯改动是否影响浇水和释放？两种真实活动及自然释放检查通过；取消/重复尚待补齐。 |
| 美术 | 点接近是否等于自然包握？不等于。法线筛查提示部分指端穿入，必须做道具专用手指修形。 |
| 工程性能 | 新增帧变换会否倾倒杯子或增加面数？源补偿与稳定姿态朝上检查通过，面数不增；动态过渡和真机成本未验收。 |
| QA/发布 | 近景是否能放行？最强反对证据是疑似穿入，候选不安装。不能用 28 项旧资产回归替代新候选接触验收。 |
