# 跟随抖动、窗墙碰撞与人物续作

面向首次及回访玩家：能连续走动、环顾、靠窗探索，随后与居民交流并返回共享桌决策。优先保证路线和操作，再检查美术与性能；保持双层 180 calls / 500,000 triangles / 220 geometries 预算，不提高限制。

## 原因与修正

- 相机原先每帧搜索可用俯角，经过遮挡边缘时会自行变换构图。取消自动改俯角，保留玩家拖动输入和球体扫掠避让；受阻缩短镜距，离开障碍后缓慢恢复。相机位置与朝向使用同一个平滑目标，避免楼梯原始高度直接踢动朝向。狭窄区域仍可能淡出人物，这是保护视野的取舍，不能声称所有镜头变化已消失。
- 物理固定 60Hz，显示帧原先直接读取离散位置；未发生物理步的显示帧还会将行走速度归零。新增前后物理位置插值，保留最近物理步的移动向量驱动转向和动画。传送、坐下后重置插值状态。高刷新率硬件的主观手感仍需实机验证。
- 旧窗边只有玻璃平面的简化阻挡，漏掉向室内凸出的窗墙和层叠窗套。`build-atrium-architecture-collision.py` 从已保存 Blender 源的 140 个评估后实体提取 107,520 三角面，合为一个 Rapier 静态 trimesh；保留真实洞口。可见 GLB 几何没有变化，新增物理表面由独立 collision.json 加载，源场景保留同一清单。
- 没有用整体加粗胶囊代替漏碰撞修正：尝试半径 0.34m 会阻塞安静角的既有通道，已撤回，仍为 0.30m。回归对照检查旧玻璃边界与新窗套边界至少相差 0.1m。四处夹具选在实际可达后侧平台，不在回程梯楼板开口上。
- 七人缩小头部、调整下颌与面颊，并重新压低头部位置保持颈部连接。玩家采用深藏蓝日常连帽外套、同色系口袋和较小折叠帽体。保存原创 Blender、master、桌面/移动 GLB 及动作源。没有新增第三方或付费素材。面部、衣服、肩型与参考仍有明显差距，不能作为精品人物最终交付。

## 五视角反对意见

| 视角 | 可证伪反对意见 | 回答与边界 |
|---|---|---|
| 玩家/产品 | 不自动抬头后，窄梯会看不到人物 | 保留碰撞与近距离淡出，走动角度不再自行选择；窄梯截图和回游录像验证可继续操作。舒适度不由单次角度断言认证 |
| 关卡 | 补窗框后会堵路或把人物顶上窗台 | 四处真实 W 输入推墙检查高度和胶囊无交叠；两梯上下与完整回游检查可达性 |
| 美术 | 缩头换衣色没有解决玩偶感 | 保存同相机前后和七人正侧面；长颈和亮色口袋首版已修正。发束、脸部体积和布料细节仍不足 |
| 工程性能 | 107k 物理面增加下载、内存和查询成本 | 单独记录 collision.json 大小及完整加载/帧时间；这些面不进 renderer.info，但绝不当作免费成本。预算未扩大 |
| QA | 只检查胶囊不能证明衣袖和手指不穿墙 | 明确范围为身体运动阻挡及选定窗墙，没有逐顶点服装碰撞证明。动画接触、座椅和实际回游分开验证，仍保留未测姿势风险 |

## 复现与交付边界

`node scripts/verify-atrium-window-contact.mjs` 使用本机 Chrome，四处真实输入推墙及平地跟随角度采样。`node --test test/atrium-circulation.regression-1.test.mjs` 检查漏碰撞反例和原有通路。全套运行 `ATRIUM_FACE_BASELINE=tmp/body-feedback-before-you.glb node scripts/verify-atrium-release.mjs`，基线是修改前玩家 GLB；脚本顺序运行，不并行争抢 GPU。

真实手机、长时稳定 60fps、全部手部/布料顶点接触、完整参考品质仍未验证或未完成。最终同构建测量以 `evidence/atrium/acceptance.json` 和 `PERFORMANCE.md` 为准，不借用上一候选数字。

## 本候选性能结果

同构建桌面 1920×1080 / DPR 1 / AMD Radeon Pro 5300M / Chrome 152：P50/P95/P99 为 16.8/49.8/82.9ms，峰值 87 calls / 496,110 triangles / 76 geometries。桌面帧率门槛未通过，不能将剩余卡顿归为镜头逻辑或宣称稳定 60fps。GPU P95 37.10ms，脚本 CPU P95 6ms；这只是定位线索，未证明外部负载是唯一原因。

移动模拟 P50/P95/P99 为 16.7/17.5/33.4ms，69 calls / 311,405 triangles / 72 geometries；P95 达到模拟 30fps 门槛，不是手机认证。导航到可进入桌面 6.04 秒、移动模拟 7.17 秒。桌面 collision.json 解码体积 3,165,878 字节，实际传输 684,597 字节，资源请求耗时约 908ms；运行期 JS heap 约 71.7MB，不包括完整原生/GPU 内存。

## 同构建回归与录像

候选指纹 `843fd879493ba6647e7fa5cabadc0ee374cabad71d6bbb819a09fc294fcb0cef` 的 18 步验收流程执行完成，包含 20 项回归、21 项操作、4 处窗边推墙、19 项设施接触、坐姿、两梯上下、异常恢复和 40 个实际路线节点。性能采样执行完成不等于帧率门槛通过。

平地跟随采样 148 帧，实际俯角范围约 2.22e-16 rad；这只证明该条平地路线没有自行改变俯角，不证明所有帧间位置、受阻缩距或手感都无抖动。四处推墙后胶囊均无交叠，脚底距对应楼板约 0.02m；独立室内镜头显示窗边身体位置，但书架遮挡了部分身体，不据此认证全部衣物顶点。

连续输入录像 97.467 秒 / 1,462 帧 / 52,504,412 字节，完整解码通过。检查八格间隔抽帧和 95 秒画面，确认上下楼、回廊和返回共享区确实可见，没有黑屏或错误画幅；不是逐帧人工审核。录像脚本用较快输入走完流程，不能把 97 秒当成首次玩家实际体验时长。截图、相机参数、录像与性能原始报告在 `evidence/atrium/review.html` 汇总。
