# 颈部渐变蒙皮 · 2026-09-23

上一轮用真实运行姿态确认了刚性颈部的切口外露；本轮推进结构修复，而不是再用领高遮盖。全七人生产美术与高标准还原仍为目标，当前主角候选是制作阶段，不代表整体完成。

玩家承诺：居民交流和转头时颈部不再整根从领口翘起。首次探索→靠近交流→继续探索的玩法、输入反馈、身份、3D 环绕和目标预算保持（180 calls / 500000 triangles / 220 geometries）。此次不改变转头幅度或提高领口，不宣称性能和全范围碰撞验收。

五视角自审：玩家质疑只对诊断角度有效，需实际运行对话；设计质疑新骨骼影响表情和头发/眼球相对位置，需形变及运行近景；美术质疑线性蒙皮会缩颈或产生橡胶感，需六姿态前侧斜视；工程质疑多骨骼和蒙皮顶点成本，需导出属性和成本统计；QA 质疑源/运行驱动不一致，需源坐标测量及运行顶点测量。最强反方意见是固定根部并不自动保证所有角度与衣装碰撞、颈部解剖造型自然。

## 实现

新增独立 CervicalRig，SkinNeckAnchor 固定在身体相对坐标，SkinNeckHead 由已有 HeadPivot 驱动；头部包含的 native 颈部不再整体刚性随头移动。世界高度 ≤1.32 的源顶点固定，≥1.41 的顶点完全随头，中间 smoothstep 权重过渡。原源顶点、UV、面和 Blink/Talk 保留，静止姿态误差要求 <1e-5。源 COPY_TRANSFORMS 约束使可编辑模型可直接转动 HeadPivot；运行使用既有绑定同步算法，为存在 SkinNeckHead 的模型增加可选绑定，旧模型找不到该骨骼时不添加绑定。

制作开关 ATRIUM_NECK_RIG_STUDY=1 要求隔离 crew-neck 候选；本次输出 tmp/portrait-study/neck-rig-v1。没有安装候选 GLB，运行同步支持已加入源码。真实运行资源仍是此前正式资产，不能将本轮代码构建或候选检查当作正式版本全量验收。

## 独立接入准备与便携动作修复

后续验证将颈部修复与所有未批准的脸部/衣装研究分离：ATRIUM_NECK_RIG_STUDY=1 只要求 tmp 隔离，不再依赖 crew-neck。候选 tmp/portrait-study/installed-neck-rig-v2 基于当前安装造型，不启用皮肤、眉眼、比例或领口研究。

发现并修复三项此前未覆盖的问题：

1. 便携动作烘焙缺少新颈部骨骼，现纳入每帧驱动、NLA 分轨和导出；源约束在烘焙时静音，避免重复驱动。新增 ATRIUM_MOTION_ROOT 支持隔离动作输出，仍读取既有九段动作数据。
2. 旧便携文件同样存在恒定头部位置通道被删、静态节点缺少该位置的问题。实际 Blender 动作 HeadPivot.location.z 为 1.473，GLB 却既无默认 translation 也无该通道。明确设置 export_optimize_animation_keep_anim_object=True 后保留；单独关闭重复关键帧优化没有解决，因此撤回该尝试。失败报告保留。
3. 新骨架最初继承了头部非等比缩放，便携动作对比残余误差约 .0037。现在 CervicalRig 只取头部静止位置/旋转，不继承缩放；源约束改为 COPY_LOCATION + COPY_ROTATION，静态头部尺寸保留在模型变换里。这样运行、源和便携动画都无需表达旋转引起的剪切。首版带缩放样本仍是历史证据，当前复现代码以无缩放版本为准。

检查脚本 scripts/verify-atrium-neck-motion-export.mjs 使用真实 GLTFLoader 解压与 AnimationMixer 播放，九段动作 ×25 时刻，比较骨骼与控制器的静止偏移变换。最终最大矩阵元素误差 2.7743e-7，全部通过；不是仅检查通道存在。校准不能直接用尚未采样动画的控制器默认位置，脚本改为使用制作约定的 rig 静止位置、控制器静态缩放和骨骼静止矩阵。

独立候选源世界坐标下 Basis/Blink/Talk 与安装源误差 <1e-5，源六姿态变换和运行六姿态固定端测量通过。刚性 GLB 与蒙皮 GLB 的 POSITION 所在空间不同，不能直接把其原始字节差异判为形状变化；已有错误比较被源世界坐标验证替代。

独立双档为 2,495,524 / 948,972 bytes，25,096 / 22,629 triangles，与安装版本面数相同；各 3 项纹理 UV 检查通过。九动作 GLB 为 1,294,596 bytes。模型与便携动作都尚未替换安装资产，21 阶段完整功能/性能接入验收仍待执行；这一轮不能称已发布或整体生产美术完成。
