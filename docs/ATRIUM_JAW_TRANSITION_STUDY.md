# 下颌与颈部过渡制作

2026-09-23，基线 `1c5442e`。三版隔离候选，第三版保留供后续鼻唇与下半脸协调；本轮未替换运行人物，全七人生产美术目标保持未完成。

## 玩家目标和设计判断

首次玩家靠近人物、交谈并继续探索时，应看到自然的下颌和颈部关系，而不是脸直接融入圆柱脖子。遵循流程通畅、设计统一、性能稳定的北极星；保留可移动、可旋转的三维模型和实际表情。维持既有 180 calls / 500000 triangles / 220 geometries 全场景预算，不通过假镜头或隐藏模型达标。

代码检查发现，原头部在局部 z=-0.13 就开始向圆柱颈部混合，影响原生下颌体积。仅把鼻子或脸横向收窄不能解决这一结构问题。本轮改变下颌到颈部的过渡，同时以原有领口、表情和转头作为约束。

## 三版结果

1. **v1 整段下移**：过渡起点改为 -0.18。实际正侧面恢复下巴，但前凸过强、脖子偏细，领口出现可见缝隙，否决。
2. **v2 局部减弱混合**：保留原过渡起点，只在下颌附近最多减弱 55% 的圆柱混合，并在 -0.205 以下关闭作用。画面收敛，但减面重新分配，使领口根环从 36 点变成 37 点。保留失败检查和完整报告，不以静态截图代替几何约束。
3. **v3 减面后传递位移**：默认头部照常减面；以原始拟合网格及目标网格构造位移场，投影到减面后的下颌局部。保留 36 个根环顶点及边连接，坐标完全一致。既恢复部分下颌投影，也避免全头减面因局部改形而改变颈部连接。

第三版的侧面及四分之三颌线更清楚，首版突出的下巴和明显领口缝隙已消除；正面仍有人偶感，鼻唇比例与表面质感尚不协调，未作为生产美术完成或全员模板推广。

## 真实几何和动作证据

`v3-profile.json` 对源模型进行九个高度、三个横向位置的前后射线测量。中心前表面在 z=-0.16/-0.18 相对基线前移约 0.01372/0.01690（头部局部单位，非世界米数）。头部源面数 3681 不变。

**根环不变不等于整个下颈表面不变。** 长三角形连接到上方移动顶点，仍让下方剖面产生微小变化：z=-0.22、x=±0.07 的前向射线差约 0.000705；中心为零。报告保留实际结果，不把公式的局部作用范围扩张成整片表面完全不变的声明。

- v3 源闭眼覆盖 4961/4961，最小局部间隙约 0.00180650；不能代替部分眨眼和运行验收。
- 六组源头部姿态通过真实蒙皮变换检查，固定端/上头部/渐变区误差均小于 1e-5；不是完整碰撞保证。
- 最终 GLB 六组头部姿态、三视角共 18 张运行图检查，未见首版的大领口缝隙。37 个运行锚点最大身体局部漂移约 4.47e-15。
- 最终移动模拟自动眨眼 578 次采样、触控对话通过，无页面运行错误；这是桌面 GPU 手机视口模拟，非手机真机。
- v2 的动态证据保留在单独目录，不能代替 v3 结果。

## 五视角复核

| 视角 | 可证伪质疑 | 回答 |
| --- | --- | --- |
| 玩家/产品 | 局部颌线不等于整个人物自然 | 近景仍有人偶感，保留候选继续鼻唇协调，没有宣称生产完成 |
| 游戏设计 | 下颌变化可能破坏讲话和转头 | 最终候选连续表情、触控对话、六组转头检查；仍非完整游玩验收 |
| 美术 | 原生下巴恢复过多会变得过凸 | v1 实拍确认并否决，v2/v3 采用局部较温和恢复 |
| 工程性能 | 减面重分配影响连接或增加面数 | v2 根环失配被检出，v3 保留根环点和边；双档面数不增加 |
| 质量验收 | 公式无作用区不代表实际表面不变 | 剖面实际存在微小差异，明确记录；根环、源蒙皮和实际姿态分别验证 |
