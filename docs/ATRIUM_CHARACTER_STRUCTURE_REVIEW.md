# 人物结构重制

基线 c400168。目标仍是首次与回访玩家在行走、环绕、交流、生活动作中看到可信的亚洲成年青年。现有进入→探索→交流→共同决策→自由探索循环保持；首次 30 秒进入并识别共享桌，首段 3–5 分钟完成交流与发现，选择结果继续进入记录。本轮先把玩家头部做成可用的结构样板，再决定居民扩展，避免把有缺陷的头部复制七份。

玩家承诺：改善明显木偶化的面部和头颈连接，保持移动、镜头、身份、动画、接触与存档；不以单张肖像替代真实 3D 资产。全双层预算保持 180 calls / 500,000 triangles / 220 geometries；载入时间与双档 P50/P95/P99 在最终候选实测。仍有载入反馈与重试。原参考图只提供远景人物，细部属于设计补全，不能宣称精确复刻某张脸。

## 结构选择

采用 MakeHuman CC0 图形基础网格中的头部区域（只含 body group、Y > 6 的面，保留 UV），以自编 Blender 脚本适配现有 HeadPivot。未引入 MakeHuman 程序代码或新运行引擎。来源、源网格散列与官方许可在 `models/atrium/source/`。服装、头发、骨架仍为项目制作。

统一鼻、颧、下颌、耳朵和嘴唇，移除旧的独立嘴片与耳壳；原头部接合现有颈部产生双层裁口，改为原生颈部延续至衣领内部。头发投射到同一头皮表面，耳侧发际线避开耳廓。真实头部网格保留 Blink/Talk 形变。直接压缩眼眶产生折痕，连续局部调整未解决后停止该方案，改为面向外的上下弧面眼睑，外缘贴合脸部，内缘合拢并前移覆盖角膜；玩家眼球不再缩放。其原生头部 2,999 面，加 768 面的弧面眼睑，共 3,767 三角面在双档均保留，其他部件继续按原 LOD 减面；是否满足全场景预算须实测。

玩家肩部不再额外扩大 8%，夹克腰部增加松量和有限的表面起伏，保持连续蒙皮；不是独立套壳或布料物理。保留现有手脚关节与握持点；它们的细部仍需后续重制。

## 五视角反对意见

| 视角 | 可证伪的质疑 | 证据与处理 |
| --- | --- | --- |
| 玩家/产品 | 新头部更写实但仍僵硬，与参考图不统一 | 正侧面、正常距离、移动中对比；不把鼻子更明显视为完整美术通过 |
| 游戏设计 | 身体比例变化破坏坐姿、浇水与接触 | 生活设施握持、坐下起身、主梯和回程梯实际回归 |
| 美术 | 原生眼眶无法闭合、嘴部形变露洞、头发穿耳、颈口穿衣 | 自动眨眼观测，加独立标注的固定表情近景与四向截图 |
| 工程 | 新头部形变、额外材质和资产许可增加运行及维护成本 | 双档资源、渲染和帧时间；记录 CC0 图形数据与程序许可边界 |
| QA | 静态模型通过而动画 GLB、移动档或重入仍是旧版 | 双档形变资产检查、九段动作重新导出、同候选完整回归与录像 |

这是同一执行者按五视角自审，不是五位独立评审者或人工美术认证。最终运行结果见下方。


对话接入：玩家选择“你希望今晚是什么样？”后进入 1.1 秒的本地说话动作，居民保持对话朝向与站立状态，期间播放倾听姿势，再恢复回应。取消时立即清除玩家说话状态。没有语音服务或音素同步；这是本地手势和嘴部形变。验证使用真实按钮点击，固定表情接口只供另外的近景检查。


## 候选性能与首次回归中断

候选指纹 `6b0086ea008e4379feac2416942f7c68e3590af1458ccc401bed2b5a541195d2`。第一次生产测量保留：桌面 1920×1080 / DPR 1 / Chrome 152 / Radeon Pro 5300M，P50/P95/P99 = 16.7/33.5/67.1 ms，峰值 115 calls / 497,202 triangles / 92 geometries。移动适配是在同一桌面 GPU 上模拟 390×844 / DPR 3 / renderer DPR 1.25：16.7/17.5/66.7 ms，峰值 93 / 315,823 / 88。双档渲染预算通过，桌面帧时间不通过，移动长尾仍明显且未测真机。不能用较少 draw calls 宣称更快。

导航到可进入分别约 5,508 / 4,858 ms，点击进入到活动状态约 92 / 103 ms。玩家桌面 GLB 300,360 字节 / 24,633 三角面，移动 GLB 266,416 字节 / 21,225 面；相对 c400168 分别增加 77,836 / 89,136 字节及 443 / 2,012 面，原因是保留面部形变与完整眼睑。九段动作 GLB 838,516 字节 / 28,471 面。夹克连续表面 2,308 面、单连通、0 非流形边，最大权重误差 0.00000756，在原局部 2,400 分配内。

初次回归在新增表情测试中中断：脚本开启 capture CSS 隐藏界面后尝试点击对话选项。修正为真实输入阶段恢复 UI，再回到截图模式；运行时代码和模型未变，续跑前后比较指纹，已完成的性能测量不重选。中断说明保存在 `evidence/atrium/facial-motion/initial-run-failure.json`。最终状态以 acceptance.json 为准。


## 最终验证与裁决

27 项试点测试通过；候选回归完成（含恢复前后指纹检查共 20 步），覆盖双档、控制、窗边接触、握持、坐姿、两梯、资源失败和重入。连续真实输入路线有 43 个路点，发现 7 条线索，与林/陈/周三人交流，完成 balanced 决策，无记录到的运行错误。录像 103.467 秒 / 1,552 帧 / 37,947,305 字节，完整解码通过；抽看八格路线画面，非完整人工逐帧审片。

新增面部检查：自动眨眼从 0 到 1 再恢复；闭眼与说话固定姿势中眼球尺度保持不变；真实点击提问按钮观测到嘴部形变。首次表情照片因对话后人物转身拍到了背面，已将肖像检查放在真实对话之前，增加朝向断言并重新拍摄正侧面。补拍使用本机 4193 开发预览 / headless Chrome，同一运行指纹；生产性能仍使用原 4195 结果。已实际查看最终闭眼正面、自然侧面与路线接触表。

最强反方结论保留：闭眼能覆盖角膜，但眼睑仍偏厚、外缘仍可辨；新脸有连续鼻颧与下颌，却仍缺少参考图的亲近表情和精细皮肤处理。发壳仍厚，颈部侧影偏直，手指、鞋体与衣服褶皱仍粗糙。窄梯镜头依然被墙体占据较多画幅。六名居民未重制、移动真机未测试、严格桌面 60fps 未达标；本轮不能判定整体人物美术或性能完成。

后续优先打磨眼睑/眉眼和发型，再改手脚与服装形体；扩大居民前必须重新分配现有 500k 预算，不能批量复制新细节后静默提高限制。发布方式为提交并推送项目分支；本机预览可检查。可回退本轮提交，不改存档结构。生产站点与真实玩家体验尚未验证。
