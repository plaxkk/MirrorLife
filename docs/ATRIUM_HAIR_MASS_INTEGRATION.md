# 主角侧分与主发块本地接入

2026-09-23。第二版侧分、额头贴合与顶侧体积进入本地主角源、双档和九段动作。是局部外观改进，全七人生产美术目标未完成，未发布。

## 玩家结果与取舍

目标玩家在中庭探索、靠近人物对话并环绕查看时，看到更自然的短发轮廓。遵循流程通畅、设计统一、性能稳定的优先级；保留真实三维移动、镜头、表情和交互。参照 `design/references/atrium-visual-target.png` 中自然、略蓬松的年轻人物，不把远景参考当作精确脸部照片。

上一轮收束小发片不足以改变发帽体积。本轮直接塑造顶、侧、后区：抬起偏侧的前顶体积，收近侧区与后脑，并给分缝宽缓的高低过渡。首版峰值偏尖，否决；第二版降低前顶抬升并放宽分缝。正式模型相对旧版的左右均匀弧形前缘，侧分及顶侧层次更明确；发片硬边、近景块面、整体人偶感仍存在。

双档面数不增加，原贴图、UV、材质及面部形变保留。没有提高贴图或用固定镜头替代模型。没有采用上一轮根梢渐收候选，也未把其逐条带审计元数据放入正式资源。

## 制作、范围与源检查

第二版相对 sweep-v2 调整 2732 个顶点，最大局部位移 0.0204631。头部局部空间中进行广域修形，并用实际头皮最近表面保持间隙。2 个三角面的划分变化，分别检查：未变三角形没有新增负向采样身份；变化三角形没有负向采样。

全发型透明度阈值 0.4 以上，实际三角顶点、边中点与重心共 24048 个样本；基线 6 个负向样本，候选 4 个，最深值仍为 -0.00271744。不是全头发零穿模声明；采样不覆盖连续表面、纹理滤波及全部动画姿态。

合入前简单数组比较发现眼白、眼高光、抽绳端和太阳绣章也不同。随后进行顶点多重集合及保留绕序的面几何多重集合比较，确认这些都是排列顺序变化，实际几何完全一致；只有头发物理几何改变。原始与规范化结果都保留，不能把索引重排误报为形状变动。双档实际导出每眼 421 点虹膜/瞳孔检查零遮挡、零缺失、零瞳孔不匹配。

正式资产复制前后 SHA 见 `integration/copies.json`；只更新主角清单行。可编辑人物、master、双档、可编辑动作与动作 GLB 共六文件同步。其余六人未重新制作。

默认复现首轮失败，最大误差 0.0187127；原因是保存源中 Head 已挂在 CervicalRig 下，而生成器把 `head.parent` 当成头发控制器。修复为明确使用 HeadPivot，几何换算与父级绑定一致；最终 2984 顶点及 UV 精确一致、最大坐标误差 0。失败记录见 `integration/default-exact-failure.txt`。原整人物构建在颈部蒙皮前创建头发，父级原本就是 HeadPivot，所以这项修复没有改变已测运行资产。

默认 `ATRIUM_REFINED_HAIR=1` 等效启用 sweep=2 / mass=2；显式实验参数仍限制输出到 tmp。复现旧发型或历史实验须设置 `ATRIUM_REFINED_HAIR=0`，再按对应实验传参；不传实验变量可生成本轮默认发型。

## 五视角复核

| 视角 | 反对意见 | 证据与结论 |
| --- | --- | --- |
| 玩家/产品 | 只是微调、靠近仍像人偶 | 正面轮廓改善足以作为局部迭代；整体近景尚不满足生产美术 |
| 游戏设计 | 只检查静态图，可能破坏表情和动作 | 同一最终 GLB 的移动模拟 575 次连续眨眼和触控对话通过；九段实际播放颈部同步通过 |
| 美术 | 正面改善但顶侧出现尖峰或沟槽 | 首版偏尖被否决；第二版正侧背、左侧与俯视检查后保留，硬片边缘仍列为风险 |
| 工程性能 | 体积改动暗增面数和资源 | 桌面 26532 面/2428124 B；移动 24469 面/952460 B，面数不变，体积几乎不变；性能单独测量 |
| 质量验收 | 重建无关几何或默认参数与候选不一致 | 规范化源检查消除列表重排误报；默认参数单独验证；28 项回归、双档 UV 和七人双档包围范围检查通过 |

## 验证与残余风险

- 构建通过，保留大于 500 KB 的代码块警告。
- 28 项相关回归全部通过，九段动作同步、七人双档五姿态蒙皮包围范围通过。
- `v2-desktop/` 对照旧正式版与最终候选；`v1-desktop/` 对照 sweep-v2 与首版，基线不同，不得混用。
- `v2-mobile/` 为桌面 GPU 的手机视口模拟，实际请求的候选 SHA 与安装双档一致，不是手机真机。
- 本轮未重跑完整 21 阶段发布门禁、未发布、未进行用户美术签收。全七人造型、衣装、自然表情、严格性能预算仍未完成。

生产构建连续输入环绕测量：桌面 P50/P95/P99 = 16.7/18.2/18.6 ms，峰值 101 calls / 495518 triangles / 81 geometries；移动模拟 = 16.7/18.5/18.7 ms，峰值 83 / 330828 / 77，触控移动 1.822 m。两档无运行错误；严格 60fps 门槛仍未达到。

上一安装版桌面/移动模拟 P95 都为 17.5 ms；本轮读数更高，不能把差异直接归因于发型，也不能据此宣称无性能退化或性能优化。面数、调用数未增长；尚无同构建交叉 A/B 测量来判断因果。
