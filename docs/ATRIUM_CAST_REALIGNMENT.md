## 验收与限制
- 同条件近景显示前掌较平、鞋带可见，但系带像直条，鞋舌与裤脚衔接仍弱，不接受生产美术完成。
- 身体核心非脚部坐标精确保持，其他网格的坐标、带绕序面片、平滑标志、形态键对应与变换精确等价。
- 初次按数组编号比较误报眼白变化。继续检查发现坐标集合和带绕序面片一致，但 UV 不同。最终检查将 UV 独立列出，只允许两只眼白且材质无图像/UV/属性节点依赖的未使用 UV 差异；并未宣称源文件所有字段不变。失败与定位报告均保留。
- 两脚源最低 Z 均保持 -0.06099999696，脚踝局部矩阵精确不变。这不等于完整鞋底接触或楼梯碰撞证明。
- 游戏全身与头像对照、两份资产各三张真实 W 键行走截图完成，移动距离断言通过，页面错误为零。站位与镜头是审查夹具，不是完整玩家探索路径。
- 桌面 2,425,604 B / 26,548 三角面；移动 954,824 B / 24,485 三角面，分别较正式模型增加 16 三角面。两个 LOD UV 检查及脚本语法检查通过。未跑该候选完整双档发布套件、真机性能或鞋带曲线全表面间隙检查。
