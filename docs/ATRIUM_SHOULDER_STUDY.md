# 肩胸轮廓研究 · 2026-09-23

上一轮源皮肤为实际进展，但全身角色仍像硬壳人偶。原参考里是自然落肩的生活外套；现有全身/四分之三图中，颈下上胸鼓起、肩袖转折硬。全七人生产美术目标保持，不将此研究定义为完成。

首次玩家看到可信的居民，靠近交流，再继续探索；本轮承诺是正常游玩距离可感知的柔和肩胸轮廓。交互入口、即时反馈、探索→交流→继续探索循环不变。仍按 180 calls / 500000 triangles / 220 geometries 预算，保留真实 3D 和既有身份/绑定。此次不更改玩法或提高预算。

假设：此前上胸横向扩张 20% 使外套呈硬壳；在合并衣身和袖子前改为 6%，上胸纵深最多收 14%，外肩平滑下降最多 14mm，可能改善轮廓。不会用后期贴片遮盖连接。候选强制 tmp 隔离。

五视角自审：玩家质疑近景有效远景无感，要求全身；游戏设计质疑落肩会破坏抬臂，要求动作检查；美术质疑削薄上胸可能造成塌肩和头大，要求正侧背与基线比较；工程质疑重新 remesh 增面，要求资产统计；QA 质疑肩窝裂口和蒙皮异常，要求单连通/封闭网格及权重验证。反方最强意见是局部收窄无法解决整体比例和衣服结构，不可据此宣布生产美术完成。


## 实测与裁决

- v1 正面和四分之三出现更深的肩袖凹折，否决收窄/下压方案。虽然源形变保护检查通过，不能用它推翻视觉退步。
- v2 仅保留纵深调整，横向和高度恢复基线；避免 v1 最明显的肩窝凹折，但上胸依然呈封闭立领硬壳，侧面服装缺少自然松量，全身效果没有足够收益。保留研究，不安装。
- v2 八姿态源检查通过；全身体边长最大拉伸 3.66392 倍（坐姿，基线相同），最坏 P99 从 1.29944 到 1.30089。此宽松回归只能发现严重拉裂，不代表衣料物理正确，也没有证明局部无穿插。
- v2 桌面 26,041 / 移动 23,237 triangles，相比基线均少 9 面；文件 3,005,880 / 1,118,756 bytes。双档 UV 检查通过，图数均 10。合并过程封闭、单连通、权重断言通过。未测真机和此次候选全场景 P95。
- 扩充运行比较工具：正/侧/背衣装镜头，以及真实 W 键移动的三帧截图，保存位置变化；已检查实际游玩背面截图。不是完整探索交流回归，也不是锁定步态对照。首轮移动断言误把位置对象当数组，工具失败已修正，重新完成两版本捕获，errors 为空。

结论：两次实验证明局部缩放不能解决上胸到领口的整体硬壳形状，不能继续靠微调系数宣布提高还原度。下一步应重新设计领口、内搭和肩部的连续衣装结构，并协调袖形/腰身，而不是继续压缩原锥形封闭壳。当前正式资源保持原状。全七人美术、用户反馈、性能和发布仍未完成。
