# MirrorLife 30 分钟垂直切片：双线回声

> 版本：v1 / 方案 2「同一个你，两种被记住的方式」
> 目标：把现有 Three.js 室内、物理移动、多 Agent、关系、记忆和 AI 剧情师收束成一局完整、可传播、可复玩的社会模拟体验。

## 1. 设计来源与转译

本切片参考 [Donchitos/Claude-Code-Game-Studios](https://github.com/Donchitos/Claude-Code-Game-Studios) 中 game designer、quick design 与 vertical slice 的方法，但不照搬题材：

- 从目标情绪倒推机制，而不是从功能列表拼玩法。
- 同时满足自主、胜任与关联：玩家能选择，能读懂后果，也会在意角色。
- 用 30 秒微循环、5–15 分钟中循环和整局宏循环保持节奏。
- 张力与释放采用锯齿结构，每个高点之后给玩家观察和理解的空间。
- 垂直切片必须完成“进入—挑战—选择—后果—余波”，而不是只做漂亮场景。
- 验收问题必须可证伪，不能只问“看起来好不好”。

## 2. 核心体验承诺

一句话：

> 我的社会分身先替我活出一个选择；我只能改写其中最重要的一次，然后看见所有人会如何记住这两个不同的我。

目标情绪曲线：

```text
好奇 → 看见被忽略的人 → 犹豫 → 承担选择 → 看见关系余波 → 想把问题发给朋友
```

这不是传统读档：

- “事实”是分身根据性格、记忆和当下关系做出的真实选择。
- “如果”是剧情师基于相同现场生成的另一条可行时间线。
- 玩家整集只有一次改写权，不能把所有结果刷成最优解。
- 未被选择的未来仍会作为反事实记忆留下，影响玩家对角色的理解，但不改写世界状态。

## 3. 30 分钟单局结构

首发故事线为「让沉默被听见」，由五个可进入建筑组成。

| 时间 | 幕 | 场所 | 玩家行为 | 戏剧功能 |
| --- | --- | --- | --- | --- |
| 0–3 分钟 | 冷开场 | 邻里广场 | 进入现场，发现一把空椅 | 给出可截图的强钩子，不先解释系统 |
| 3–8 分钟 | 第一幕：识别 | 邻里广场 | 走动、观察三至六个空间证物、听见第一段沉默 | 教会物理探索与证据阅读 |
| 8–12 分钟 | 第一选择 | 邻里广场 | 看见事实/如果，可保留事实或提前使用改写 | 第一次建立“选择稀缺” |
| 12–17 分钟 | 余波 | 静心角 | 跟随未开口的人，观察其记忆与边界 | 从公共事件进入私人感受 |
| 17–22 分钟 | 第二幕：改写 | 公议庭 | 面对两种都合理的说法，关系张力升高 | 迫使玩家决定何时使用唯一改写 |
| 22–26 分钟 | 代价 | 共情室 | 角色根据前面证据自行行动，玩家只能介入一次关键节点 | 证明 Agent 不是等待点击的道具 |
| 26–30+ 分钟 | 第三幕：回声 | 街坊故事馆 | 看见五个角色对同一事件的不同记忆，生成双线故事卡 | 完成情绪释放、传播与下一集钩子 |

节奏规则：

- 每 30–60 秒必须出现可读的新信息：证物、台词、移动、关系变化或选择预告。
- 每 4–6 分钟必须出现一次不可同时满足的社会张力。
- 每次高张力选择后至少留 45 秒自由观察时间，不立即塞入下一任务。
- 一局结束时必须保留一个未解决的问题，但当前集的戏剧问题必须有明确余波。

## 4. 三层玩法循环

### 4.1 30 秒微循环：看见—靠近—倾听

1. 玩家在三维房间中看见一个空间证物。
2. 使用统一物理坐标靠近，陈设碰撞不能穿越。
3. 按 E 倾听，获得一条场所记忆和一个角色反应。
4. 证据写入本集上下文，改变后续分支文案和 Agent 行动偏好。

成功感来自“我读懂了一个之前没有注意到的细节”。

### 4.2 5–10 分钟中循环：事实—如果—承担

1. 社会分身先根据当前记忆提出“事实选择”。
2. AI 剧情师给出一个同样合理、但价值取向不同的“如果选择”。
3. 玩家预览两条关系余波。
4. 玩家保留事实，或消耗整集唯一一次改写。
5. 被选择的行动进入关系事件、角色记忆、剧情证据与下一场任务。

成功感来自“我理解了两种选择的价值，而不是猜中标准答案”。

事实分支使用可解释、可复现的决策评分，而不是场景默认顺序：

```text
FactScore = 0.5 + Persona + Values + Memory + Relationship + State + Continuity + StableTieBreak
```

- `Persona` 来自 MBTI 社会行动偏好与 Big Five 特质。
- `Values` 来自玩家选择并在模拟中持续更新的 Schwartz 价值排序。
- `Memory` 读取最近 24 条长期记忆、关系记忆、生活胶囊与反思，按重要度和时间衰减计分。
- `Relationship` 读取现场对象的信任、张力、互惠与披露深度。
- `State` 读取当前情绪、精力和总体信任，避免低能量分身作出不可信的高承诺。
- `Continuity` 让本集已经形成的行动方式留下惯性，但不会压过强人格或记忆证据。
- `StableTieBreak` 只用于完全接近的分数，采用稳定哈希，保证同一状态得到同一结果。

玩家看到的不是原始分数，而是最多三条可读证据，例如“日常照护者更常用支持靠近现场”“最近 18 条记忆与这次做法产生回声”。这些证据随同 `choiceId` 写入场景记录、长期记忆、终章和分享卡。

### 4.3 30 分钟宏循环：一集社会记忆

1. 五个场所组成三幕故事。
2. 同一个事件被不同 Agent 记成不同版本。
3. 故事馆把真实行动压缩成一张 4:5 双线故事卡。
4. 下一集从上一集最有张力的未解决关系开始。

成功感来自“这个世界真的记得我，并且不是所有人以同一种方式记得我”。

## 5. 多 Agent 分工

| Agent | 可见职责 | 不允许做的事 |
| --- | --- | --- |
| 玩家分身 | 基于玩家人格、近期选择和关系证据提出事实分支 | 替玩家花掉改写权 |
| 现场居民 | 根据欲望、边界、记忆和关系自行移动、回应、拒绝或离场 | 为了推进剧情突然改变人格 |
| AI 剧情师 | 选择最有张力的现场、生成反事实、控制节奏、压缩余波 | 宣布标准答案或凭空制造未发生的证据 |
| 世界裁决器 | 检查物理可达、资源、授权和关系约束，写入最终状态 | 接受不满足世界规则的 Agent 提议 |
| 叙事压缩器 | 把多 Agent 行动变成可读节拍和社交切片 | 暴露原始思维链或大段 Agent 日志 |

Agent 演化规则：

- 每个重要行动必须带 `actorId / targetId / zoneId / turn / evidenceId`。
- 角色记忆分为“发生了什么、我怎样理解、我下一次准备怎样做”。
- 关系变化必须由事件证据驱动，不能只改数字。
- “无人行动”“拒绝任务”“离开现场”都可以成为剧情事实，不能自动判定失败。
- 反事实只进入 `counterfactual` 记忆，不进入物理世界和正式关系状态。

## 6. 一次改写机制

每条五场所故事线拥有：

```text
rewriteTokens = 1
```

玩家每到关键时刻都能看见事实和如果，但只有一次能让“如果”成为正式世界状态。

使用改写后：

- `rewriteTokens` 变为 0，并跨场所持久化。
- 被选择的行为照常更新人物情绪、信任与关系事件。
- 参与角色收到一条 `counterfactual-aftermath` 任务，在之后用真实行动回应。
- AI 剧情师保存本次改写证据，后续剧情可以引用其余波。
- 生成一条可复盘、可分享的双线故事回执。

保留事实同样是有效选择：克制不等于错过，玩家可以把改写权留到更重要的场景。

## 7. 传播设计

每次关键选择生成一张 1080 × 1350 的 4:5 竖版故事卡，适配小红书、朋友圈和 X 图片流。

卡片只包含四层信息：

1. 现场画面：真实室内和在场角色，不使用通用宣传插画。
2. 事实：分身原本会怎样做。
3. 如果：玩家改写成了什么。
4. 余波：另一个角色明天会如何记住这件事。

传播文案不炫耀分数，而提出一个可争论的问题，例如：

> 真正的倾听，是邀请一个人开口，还是允许对方继续沉默？

互动闭环：

- 分享者发出自己的双线卡。
- 分享者也可以把终章的未解决问题生成「镜像接力」邀请链接。
- 好友分身入场后，答案会进入 Agent 决策器并形成 16 条真实行动证据；玩家在中点只选择关系距离，主人、好友与第三人的共同后果在四幕结局中可见。
- 朋友先看见共享边界，再明确同意，用自定昵称、一个价值取向和一次回答生成轻量分身回应。
- 回应链接返回后，邀请者必须再次同意“加入下一集”或选择“只保存回应”。
- 入场后的好友分身是可观察、会记忆、会行动的访客 Agent，拥有 16 回合限时任务，并可随时从剧情志或安全边界移除。
- 下一集剧情师优先选择两位分身价值取向冲突、但都能被理解的议题。

## 8. 视觉与交互原则

- 世界画面至少占视口的 80%，界面不能重新变成仪表盘。
- 深夜墨蓝、象牙白、珊瑚红、玉绿色与少量金色构成成人化多巴胺配色。
- 事实和如果不是两个弹窗，而是同一个物理空间上的两层时间光。
- 中线可拖动，用空间占比预览两条未来；最终选择使用 A / D 或点击卡片。
- 顶栏只显示集名、幕和剩余改写次数。
- 左右胶片轨只显示三个节拍：刚才、现在、明天。
- 关键角色必须出现在选择画面中；没有人物的空房不能作为最终传播截图。

## 9. 可证伪验收

### 9.1 首次体验

- 80% 新玩家在 60 秒内完成第一次靠近并倾听证物。
- 80% 玩家能用自己的话解释“事实”和“如果”的区别。
- 70% 玩家在第一次选择时会犹豫至少 5 秒，而不是把界面当成普通奖励按钮。

### 9.2 30 分钟留存

- 中位单局时长达到 28–38 分钟，不依赖强制等待或不可跳过动画。
- 60% 玩家完成至少四个场所，40% 完成整集五个场所。
- 结束后 70% 玩家能说出至少一个角色如何因为自己而改变。

### 9.3 传播

- 30% 完成整集的玩家主动打开分享动作。
- 15% 生成或保存故事卡。
- 分享卡被非玩家理解核心矛盾的成功率达到 70%。
- 朋友看到卡片后愿意回答“你会怎么选”的比例达到 25%。

### 9.4 技术与系统

- 改写次数跨房间与刷新持久化，不能通过重新进房恢复。
- 同一次选择只写入一次关系事件和一次角色记忆。
- 没有改写权时仍能预览反事实，但不能提交。
- UI 选择、世界状态、剧情师证据和分享回执使用同一个 `choiceId`。
- 室内选择界面在 1536 × 1024 与 390 × 844 均无关键操作溢出。

## 10. 当前切片实现边界

当前代码已具备：

- 五场所故事线和三幕进度映射。
- 房间之间已加入可收起的「余波路线」：五节点从真实场景存档读取，离开房间后在街道聚焦并高亮下一栋建筑，但不会自动传送或替玩家完成章节。
- 每集一次、跨场所持久化的改写权。
- 事实/如果双线预览、键盘选择和可拖动中线。
- 选择写入人物状态、关系、生活周记、角色记忆和 AI 剧情师余波任务。
- 未被选择的反事实会进入三个旁观 Agent 的任务、记忆和后续行动计划，而不是停留在 UI 文案中。
- 每个房间会从旁观 Agent 中稳定选出一位「活体余波见证者」：人物使用真实室内物理坐标，玩家需要转向、点击本人并主动倾听；另一种未来随后进入关系、双方记忆和下一章节奏。
- 五个场所完成后，故事馆会汇总事实/改写比例、三位 Agent 的不同理解、玩家身份判词和下一集钩子。
- 4:5 单场景回执与 1080 × 1350 整集故事卡的本地生成、系统分享及下载降级。
- 终章可关闭、回看并返回街道，完成“进入—挑战—选择—后果—余波”的完整闭环。
- 事实分支会根据玩家人格、价值观、长期记忆、关系状态、当前状态与本集连续性进行确定性推演，并在界面、存档、终章与分享文案中展示可读依据。
- 同一社会状态重复推演会得到相同 `choiceId` 和排序；旧存档缺少推演字段时仍能正常读取并继续游戏。
- 终章已加入同意制「镜像接力」：邀请、好友授权、一次性分身回应、回流后二次同意、访客 Agent 入场、四幕共演、4:5 共同证据卡、下一棒和可撤回均可在纯前端链接中完成。
- 好友分身入场后会获得定向剧情任务、长期记忆、与玩家分身的关系证据和剧情师 relay 记录；离场会清理 Agent、inbox 与关系，并以撤回状态防止刷新复活。
- 邀请与回应 payload 使用白名单字段、长度限制、版本号和损坏校验；界面明确说明校验和不等于加密或身份认证。
- 整集已加入 local-first「体验指纹」：只计算前台活跃时长，记录发现、重看、双线预览、选择停留、房间完成与传播动作；终章可主动导出不含昵称、自由输入和设备标识的匿名试玩证据。

下一阶段必须继续补齐：

- 用真实玩家测试验证 30 分钟时长与分享转化，不用开发者自测代替。
- 使用 `mirrorlife-episode-playtest-v1` 证据汇总至少 5 名新玩家的活跃时长、完成率、选择停留和分享动作，再决定 PROCEED 或 PIVOT。
- 当接入账号与服务端回传时，将当前链接校验升级为签名、过期时间、一次性消费和正式删除审计。
