## 目标对齐

首次玩家在探索和交流时应看见参考里的自然青年短发，而非发帽上粘贴叶片。核心循环仍是探索→交流→决策→继续探索；首次 30 秒进入与移动、首次 5 分钟居民对话路径均不调整。深色短发身份、自由环绕、动画与交互保持。局部研究不缩减全七人、材质、动作、真机与用户反馈的总目标。全场景预算仍为 180 calls / 500,000 triangles / 220 geometries。

## 制作假设与五视角反对意见

背面旧发束在平滑帽底上孤立结束；新候选用连续侧后发层及顺发流起伏替代独立块面，保留前额分组、减小其鼓包。发际线作细微长短变化。全部是真实网格，未使用固定镜头贴片。

- 玩家：普通游玩距离可能看不到改善；要求全身和近景比较。
- 设计：头部环绕和转头可能暴露新裂缝；要求左右、背面、俯视及动态证据，静态研究不能直接放行。
- 美术：连续发层可能变成带纹理的头盔；此项若成立即否决，不能凭低面数通过。
- 工程：连续细分可能挤占场景预算；比较双档几何统计，不放宽预算。
- QA：默认构建或其他居民可能被误改；实验 `ATRIUM_GROOM_STUDY=1` 强制输出 tmp，运行资产保持基线，截图报告绑定候选 SHA。

本次五视角为执行者自审，非外部人工签收。验收从同镜头正侧背、左侧、俯视和全身开始；只有观察到收益后才安排运行接入与完整路径复验。最强反方意见是帽状轮廓仍可能成立。


## 结果与设计重审

- v1：侧后连续起伏表面，桌面少 342 面、移动少 178 面，但背面成了发帽、顶部出现规则放射纹，否决。
- v2：延长发梢、降低鼓包并缩短底层边带；双档面数不变，但后脑尖梢过长，顶区原有大片光滑帽底暴露更明显，否决。
- v3：体素融合与局部平滑，保持原面数，接缝减轻却抹掉分层，帽状外形仍成立，否决。

这三次尝试没有达到美术要求，因此停止原有宽度/厚度/融合路线，回到发流布局假设。新增俯视对照暴露基线的顶区缺口；原代码的六条顶后导向只覆盖 azimuth 1.65..3.40，另一侧依赖起始 theta≈0.63 的鬓侧层。v4 改为十条跨顶后导向覆盖 1.12..4.765，并将鬓侧层十四条减为十条，保持总发束数 27；修复覆盖分配而非再加几何细分。该归因是由代码与视觉共同形成的制作假设，最终仍以截图判断。

本轮公共运行模型尚未替换。证据包含桌面同镜头中性正侧背/左/俯视/全身与闭眼、说话图，每版 22 张，报告绑定实际加载 SHA；不等同连续动作、移动档或完整发布验收。生产美术、用户认可、真机、桌面 P95 门槛都未因此完成。


## 新布局验证（v4/v5）

v4 顶区平滑缺口显著缩小，支持覆盖范围不足的假设；但所有顶后导向使用近似同一末端纬度，使耳侧发束越过当地发际线，否决接入。v5 将末端绑定当地发际线，顶区覆盖保留，耳侧过长问题减轻。桌面与移动仍为 26,190 / 21,433 面，体积分别 2,184,848 / 842,908 B。前后左右、俯视、全身与三表情均完成桌面截图，共 22 张；本轮未冒用基线完整回归作为候选验收。

v5 尚不具备接入资格：发根交叠呈硬块，粗大的近似对称截面仍像塑料片，前后发流衔接未自然统一。保留它作为覆盖修正的研究基线，不把局部改进宣告生产通过。下一步需重新分配细/中/主发束截面、根梢厚度与长度层次，先用同镜头视检证明自然度，再做移动动态与完整流程。原运行资产未改动，默认 groom study 为 0。

Python AST、JavaScript 语法与 diff whitespace 检查通过；所有候选实际请求加载，报告 page errors 为空。发布、真机、全七人美术与真实用户反馈仍未完成。

### 验收与最强反对意见

- 玩家/产品：普通视距收益可能不明显。已保存全身及近景同镜头对照，尚无真实玩家认可。
- 游戏设计：头发可能破坏近墙可见性。候选四处窗口实输入碰撞/镜头检查通过，四次 fade=0，离墙恢复约 1，平地相机角度稳定；此证据基于下述实验补丁。
- 美术：发片过黑、顶部层次厚重、边缘噪点和亮色碎片仍破坏统一性。**成立，未采用**。原材质统一启用 alphaHash 会在发片半透明边缘出现颗粒；只在淡出时启用 hash、完整可见时启用 alpha-to-coverage 的补丁减轻边缘颗粒，却在侧上方暴露亮色碎点。尚不能判定是覆盖、阴影或层间深度问题，不能虚报修好。
- 工程：桌面 25,096 面，比基线少 1,094；移动 22,629 面，比基线多 1,196。贴图令桌面约 2.49MB、移动约 1.16MB；尚未做候选帧时验收，不能用原基线预算测量代替。
- QA/发布：桌面三个导入阶段各有 22 张对照及 SHA、无 pageerror。候选移动模拟连续眨眼 578 样本，范围 0..1；触控对话响应峰值约 .84976，无 pageerror。模拟不等于手机真机，也不等于完整探索闭环。

运行透明策略仅为实验，截图后已恢复 `src/atrium-main.js`。完整补丁保存在 `evidence/atrium/groom-continuity/cutout-runtime-study.patch`；cutout、window、mobile-motion 三组证据附运行源码 SHA 与补丁说明。没有把实验截图冒充现有运行结果。公共 GLB 与默认构建发型保持不变。
