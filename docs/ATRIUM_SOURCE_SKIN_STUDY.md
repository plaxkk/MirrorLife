# 原始 UV 面部表面制作

2026-09-23，基线 f3e0335。上一轮完整面部比例样稿有实际源测量和运行证据，属于进展，但美术未合格。本轮仍以完整七人生产美术为目标；先在主角 form-v2 隔离候选上验证一致表面细节，不将局部研究替代交付。

玩家终点：首次玩家靠近交流时看到自然的眼周、唇周和肤色层次，愿意继续交流和探索。角色身份、真实 3D 环绕、眨眼/说话、交互和等待反馈保持。原预算 180 calls / 500000 triangles / 220 geometries 不变。

五视角自审：玩家质疑纹理噪声只对大特写有用，需同镜头全身和近景；设计质疑贴图眼线会在闭眼时变脏，需部分闭眼及连续动作；美术质疑写实纹理与风格化脸型不协调，且原色与手部不匹配；工程质疑原始大图误入运行 GLB，需确认只导出双档头部图集；QA 质疑原始 UV 和新眼睑不连续、深色像素被背景扩展误删，必须用实际导出、源 UV 和烘焙覆盖证据回答。

## 来源与映射

素材来自官方 MakeHuman system assets 的 young_asian_male，官方清单标注 CC0，原 MHMAT 头部明确记录 2020 年 9 月 CC0 发布。原 PNG 和元数据保持原样，作者/来源/哈希见 models/atrium/source/skin-young-asian-male/。不运行 MHMAT 中的着色器程序。

现有 native 头部原 UV 保留，但重建眼睑先前使用 0..1 的临时 UV，不能直接匹配整张皮肤。新增 SourceUV：外层保留源映射，眼睑根据眼窝边界的局部 x/z→u/v 最小二乘拟合，与边界 UV 连续插值到睑缘。该层仅用于可编辑制作源；运行 UVMap 单独展平和烘焙，随后移除 SourceUV。

初版将 72% 源皮肤和 28% 原 authored 颜色混合；粗糙度、法线和独立 AO 沿用制作。原 PNG 是全身解剖 UV 图集，但仅头部表面参与输出，不引入其他身体几何。

## 深色细节保护

旧皮肤背景扩展采用颜色下界，只适合原先无深色绘制的程序肤色。对源皮肤改为额外烘焙纯白 emission 覆盖图，覆盖超过 .99 的像素作为有效采样，不再把真实暗色当成空白。覆盖图不进入运行材质；颜色、粗糙度、法线和 AO 分别延展未覆盖像素，断言保留有效 texel 逐值不变。

复现：form-v2 的全部隔离开关追加 ATRIUM_SOURCE_SKIN_STUDY=1，ATRIUM_BUILD_ROOT=$PWD/tmp/portrait-study/source-skin-v1，Blender 执行 scripts/build-atrium-residents.py。新开关要求 FACE_PAINT_STUDY，沿用强制 tmp 输出。

首版构建在新增 UV 层后触发 Blender 旧颜色层 RNA 引用失效，报 IndexError；改为在创建 FaceResponse 后重新解析 Color，并在复制 UV 时重新查找 UVMap。修复后构建完成。独立实际烘焙回归覆盖新增 SourceUV、多颜色层和清理，已通过。

v1 近景层次增加，但肤色较暗且与手部不统一。v2 将源图混合降至 60%，在源材质节点将饱和度设为 .85、Value 设为 1.35；不改原 PNG。闭眼小暗点在之前版本中也存在。源 UV 眼周 440 个 loop 采样中，没有 maxRGB<80 的像素，最低样本为 (150,102,78)；这不支持“将照片瞳孔贴到眼睑”解释，也不证明整个眼周没有问题，因此没有添加猜测性的遮罩。


## v2 验证与决定

桌面 GLB 3,006,508 bytes / 26,050 triangles，移动 1,116,164 bytes / 23,246 triangles；相对 form-v2 分别增加 241,268 / 55,136 bytes，三角形数不变。三份导出均有 10 张图，头部颜色/法线/ORM 为 512（桌面/母版）、256（移动）；2048 原图和头部 SourceUV 未进入运行导出。身体原有第二 UV 不属于此次新增，不能据此误报头部清理失败。详见 assets-v2.json。

三份导出头部位置、法线、索引和全部 morph 数据与 form-v2 逐值一致，UV 检查通过。最终源皮肤实际 Blender 回归通过：颜色层完整、SourceUV 清理、Basis/Blink/Talk 不变、实际导出可用。移动模拟连续采样 578 次，眨眼和对话检查通过，errors 为空；不等同真机性能验收。

美术决定：保留为隔离研究，不替换正式资源。第二版降低首版暗沉，唇鼻耳部层次更连续，但眼神僵硬、局部肤色斑驳、发型块状、衣身板硬仍明显，全身画幅的收益有限。优先继续改善五官结构、表情和完整轮廓，而非不断叠加纹理。未做此次候选完整玩法/性能发布验收，七人生产美术目标仍未完成。
