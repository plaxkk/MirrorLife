# 主角轻量皮肤材质接入

2026-09-23。本轮改善对话近景中的唇色、面颊和耳部暖色，以及额鼻与面颊的反光差异。仅主角本地接入；七人生产美术、发布和用户签收仍未完成。参考图没有面部特写，不能据此声称脸部还原率。

首次玩家仍沿进入中庭→移动探索→交流→继续探索的循环操作。此改动的玩家承诺是近景更容易辨认面部层次，不增加操作或等待步骤。保留真实 3D 环绕、原表情与动作；以原桌面严格 60fps 预算检查，不能用截图替代可玩性。

## 制作选择

保留解剖区域顶点色，将逐角粗糙度编码到第二套 UV，使用一张线性 256×1 查找图。PNG 实际 187 B，粗糙度约 0.5363–0.6800。可编辑源保留 FaceResponse，运行导出移除无用途的第二颜色流。没有新增头部颜色或法线贴图。

桌面资产 2,488,360 B / 25,576 三角面，比上一版增加 3,428 B；移动资产 963,860 B / 24,017 三角面，增加 3,600 B。可编辑人物源、master、两档运行模型、动作源及九动作导出同步。默认构建启用，`ATRIUM_SKIN_RESPONSE=0` 可回到上一版皮肤响应。

全贴图版本、28% 源皮肤混合版本和收窄鼻颌版本均留在隔离实验，没有安装。前两者增加资源，但近景收益不足；收窄比例没有充分解决自然面部造型。当前方案使用自制区域颜色，没有使用源皮肤照片。

## 五个视角复核

| 视角 | 可证伪的反对意见 | 证据与结论 |
| --- | --- | --- |
| 玩家/产品 | 颜色变化在对话中不可见 | 正侧面与移动模拟近景显示唇色、面颊有变化，但整体人偶感仍明显，仅算局部进步 |
| 游戏设计 | 材质制作破坏眨眼、讲话或转头 | 源 Basis/Blink/Talk 坐标完全一致；移动模拟 578 次连续表情及实际触控对话通过，九动作 225 次颈部同步检查通过 |
| 美术 | 增加贴图就能达到生产级皮肤 | 否决重贴图版本；最新图仍有粗眉、发片、口周和硬质衣装问题，不能签收整体美术 |
| 工程性能 | 新 UV 和材质造成过大资源开销 | 实际双档解码与 PNG 检查通过，增加约 3.5 KB、面数不变；性能结果见下文 |
| 质量验收 | 测试通过只是检查错了对象 | 原测试读取全查找图中值而误判，改为解码 Draco 的实际面部 UV 区间；保留其他六人原约束，21 项通过 |

## 验证与证据

证据根目录：`evidence/atrium/skin-response-study/`。

- `vertex2-source.json`：10,497 个面角编码检查，UV 最大误差约 2.99e-8，查找图最大误差约 7.43e-8，源表情坐标与基线一致。
- `installed-materials.json`：双档与九动作文件实际图像完全线性，保留 COLOR_0/TEXCOORD_1，没有 COLOR_1。
- `installed-eyes.json`：两档曲面虹膜运行射线检查通过。
- `vertex2-motion.json`：九动作、225 次同步检查。
- `vertex2-mobile/`：当前最终移动档的连续表情、触控对话和截图；`neutral-front.png` 是最新正面图。
- `v1/`、`source28/`、`form/`、`vertex/`：制作对照，镜头相同但 idle 相位未锁定，不作为像素差分。
- `integration/tests.txt`：21/21；`integration/build.txt`：生产构建通过，仍有大包提示。
- 失败记录保留：首次 Blender UV 新建导致旧属性引用失效；旧粗糙度测试中值误判；第一次测试修正错误依赖不存在的压缩 UV accessor bounds。最终均已修正。

本轮没有重跑完整 21 阶段发布套件，也没有手机真机或长时间稳定性证据。移动性能是桌面 GPU 上的视口/触控模拟。

同一生产构建、依次运行的 30 秒以上输入环绕检查：桌面 P50/P95/P99 为 16.7/18.2/18.7 ms，峰值 101 calls / 493,606 triangles / 81 geometries；移动模拟为 16.7/18.1/18.6 ms，峰值 83 / 329,924 / 77，触控移动 1.85 米，均无脚本报告错误。桌面仍未达到严格 60fps 预算。与历史结果不是控制变量 A/B，不据此宣称性能提升。

面部骨相和口眼神态、眉形、发际线及顶部发片、衣装结构和全员统一仍未达到高标准。下一轮应优先解决整体造型中可见的问题，继续以同视角和连续动作验收。当前是本地增量，不是生产发布；远端推送仍待目标仓库授权。
