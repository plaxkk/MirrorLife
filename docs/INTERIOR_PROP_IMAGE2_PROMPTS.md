# MirrorLife Interior Prop Image2 Prompt Pack

这份清单用于 Pro / ChatGPT image2 手动重绘陈设物素材。目标不是裁剪母图，而是为每个陈设物重新生成一张独立、透明背景的游戏贴图。

## 生成规则

- 每次只生成一个物品。
- 输出 PNG，透明背景。
- 分辨率至少 512x512，推荐 1024x1024。
- 不要文字、不要标签、不要额外物件、不要多个物品拼在一起。
- 生成后按 `目标路径` 命名并放回项目目录。
- 放回后运行：`npm run verify:interior-props-image2`。
