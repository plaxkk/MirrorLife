# 双层天井生活馆 · 桌面端断点续作

## 目标对齐

目标玩家是首次进入生活馆的用户：从入口看见中央活动，交流、探索、共同决策，走完两层后仍可自由继续。继续沿用 Three.js、Rapier、既有角色骨架及存档边界，保护 `src/interior-three.js` 和 `.workbuddy/` 的既有修改。本轮不替换主世界，也不改变建筑通路或提高原预算。

## 本轮交付

- 接续并验证原未提交工作：楼梯连续曲面、叶片曲面、居民连续发型及贴面五官、长袖覆盖修正、完整手指、道具握持锚点、动作导出绑定。
- 补齐墙顶到屋顶之间的连续实体过梁及碰撞；封闭椅背和扶手曲线的端面，消除可见空洞。
- 从 Blender 静态场景烘焙两层地面接触遮蔽，源图打包进 `.blend`，另交付 PNG 与采样参数。运行时按世界坐标投影到水平地面；纹理失败时仍可进入、行走并记录诊断。
- 简化运行时土壤隐藏倒角，把桌面峰值从 505,273 降到 493,955 三角面。没有借此宣称帧率提高。
- 增加 `npm run verify:atrium:release`，固定 production build、顺序采样、刷新录像并验证前后资源指纹。

新增遮蔽纹理由本项目原创三维资产射线采样生成，沿用项目 MIT 许可；没有购买或调用外部资产/生成服务。

## 五个视角的反对意见与裁决

这是按五种职责进行的自审，不是假称外部人工或多人审核。

| 视角 | 可证伪的质疑 | 证据与结论 |
|---|---|---|
| 玩家/产品 | 修画面后会不会进不去，或者依赖纹理下载才能玩？ | 完整输入驱动回游通过；新增纹理失败用例仍可进入及行走。首次玩家的理解速度与乐趣仍需真人试玩。 |
| 关卡设计 | 楼梯侧墙新增碰撞会不会堵住上下楼或绕行？ | 物理回归与 33 个输入驱动路线节点覆盖两梯、两层、侧区及退出重入，完整录像可复查。 |
| 美术 | 封口和 AO 只是掩盖基础模型质量，仍达不到参考？ | 接受此最强反对意见：漏缝/端面已修，图集中可见接触改善；建筑比例、重复窗格、角色肩部及光照层次仍有明显差距，美术门禁未通过。 |
| 工程性能 | 精修会不会超预算，降低面数是否真的更流畅？ | 封口后的超预算样本保留，土壤 LOD 后数量回到预算内；桌面 P95 34.3ms，未证明流畅度改善，60fps 门禁仍未通过。 |
| QA/发布 | 新资产、新代码和旧录像会不会混为一谈？ | 自动套件在同一构建上重录并核对前后指纹。10 项浏览器异常检查、11 项试点测试通过；生产、真机、长时和弱网未验证。 |

## 可复查证据

- 入口：启动 `npm run dev -- --host 127.0.0.1 --port 4193`，打开 `http://127.0.0.1:4193/atrium.html`。WASD 移动，拖动环顾，滚轮缩放，E 交互，Esc 取消，J 手记。
- 对照、多角度和近景：`evidence/atrium/review.html`。同镜头前状态另存 `before-contact-reference.png`、`before-contact-table.png`；它们是本轮修补前的状态，不混作当前图。
- 录像：`evidence/atrium/playthrough.mp4`，连续真实键盘与鼠标操作，15fps 输出按捕获时间戳保留时长，约 92.27 秒；自动流程不等待真人阅读，不能宣称已经测得 3–5 分钟人类游玩时长。
- 握持：`character-contact/contact.json`，18 个有效握持样本，位置误差最大约 2.41e-11m；这是锚点重合精度，不是人体手指表面接触精度。
- 异常：`resilience.json`；性能：`PERFORMANCE.md` 及两档 measurement JSON；版本与步骤：`acceptance.json`。
- 模型源、GLB、模块、动作与纹理路径见 `ATRIUM_PILOT_HANDOFF.md`。`assets.json` 记录 79 个文件、体积与哈希。

## 未完成与目标复核

本轮让近景和建筑连接更可信，并保住既有可玩闭环；仍不能宣布达到精品风格化 PC 游戏水准。参考图中更紧凑的空间构图、曲面主梯、窗洞节奏、成年化角色、织物和肩部变形、脚底 IK、自然生活表演、空间声音及完整 GI 仍需制作。场景有真实模型但不是美术最终验收通过。

主世界居民身份/关系双向关联仍是原有试点边界；没有将原创试点居民强行匹配至不相干的主世界身份。桌面稳定 60fps、真机手机 30fps、长时运行、弱网与首次真人试玩未通过或未执行。没有真实玩家反馈可报告。

发布方式为提交并推送当前开发分支，生产未部署；回滚可回到本轮提交前的 `2db7eaf` 对应试点版本，必须通过正常 revert，保护玩家存档和其他用户修改。下一轮最高优先级是人物肩部/脚底接触与建筑比例精修，同时补 GPU 计时和固定设备长时样本。
