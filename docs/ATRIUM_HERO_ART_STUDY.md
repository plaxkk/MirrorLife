# 主角标杆制作与参考对照

## 目标与边界

面向首次进入中庭、自由探索并靠近居民交谈的玩家。沿用探索→交流→决策→继续探索的核心循环。首先让主角在正常游玩距离具有参考中的青年体态、分层生活外套和自然短发，再推进七人统一品质。用户已要求自主负责完整制作与验收。实验截图不能替代运行资产，局部进展不能算作整个人物目标完成。

参考：`design/references/atrium-visual-target.png`。直接可辨认的是深蓝外套、米色与暖黄色袖部、短深色头发、收口裤装、运动鞋、松弛的生活姿态。参考的面部像素不足以指定精确五官；近景属于设计补全。场景光照与人物造型需要分别判断，不能要求材质独自弥补场景光影差距。

预算保持全场景 180 calls / 500,000 triangles / 220 geometries；桌面帧时间 P95 ≤16.67ms，移动 ≤33.33ms。主角服装原有 2400 三角形局部分配不变。真机与真实玩家反馈不能由桌面模拟代签。

## 制作假设与可证伪反对意见

| 视角 | 质疑 | 需要的证据 |
| --- | --- | --- |
| 玩家/产品 | 近景新增细节在普通距离看不出收益 | 同镜头全身、正常探索画幅；轮廓与暖色分区清晰可辨 |
| 游戏设计 | 静态肩胸改善，却在抬臂或坐立时拉扯 | 八姿态蒙皮检查、真实走路/坐立/楼梯与交流 |
| 美术 | 新头发只是换一种发帽或密集条块 | 正侧背和三分之四近景，根部嵌合、发梢与轮廓检查 |
| 工程性能 | 细节消耗所剩不多的全场景面数预算 | 双档资产统计、运行峰值和端到端帧时间 |
| QA/发布 | 混用陈屿未提交实验，或旧截图冒充新资产 | 独立主角候选、资产哈希、运行截图与回归报告绑定 |

这是执行者的五视角自审，不代表外部美术师或真实玩家认可。

## 制作方式

`scripts/atrium-hero-art.py` 在现有源构建链中增加主角专用作者步骤：缝合前调整肩胸体积；在连续蒙皮衣身上切出暖色袖部拼接；对全部面部形变键施加相同下脸部修形；制作有嵌入发根、错层方向和不同长度发梢的真实网格短发。保留原控制骨架、眼睑、交互锚点和运行代码。

候选先由 `ATRIUM_HERO_ART_STUDY=1` 输出至 `tmp/`，同镜头请求替换仅用于诊断，不是玩家路径或发布。v4 已作为主角局部改进候选装入实际桌面/移动资产，完整运行验收见下文。构建默认启用此造型，`ATRIUM_HERO_ART=0` 可生成旧版对照。陈屿 v3–v5 未推广到运行资产。

最强反对意见仍成立：近景发束有雕塑块面感，面部眼窝/口部不够自然，领口与帽兜仍需进一步制作。v4 是有实际收益的运行改进，不是“七人生产美术完成”。不能把局部改善或参考服装色块对齐包装成参考图的整体还原。

完整发布检查运行于构建产物，包含输入驱动探索→交流→决策、两档画面与性能、九动作、接触、坐立、楼梯、异常恢复、录像解码及资产指纹复查。最终结果以本轮 `evidence/atrium/acceptance.json`、`validation/progress.json` 和 `PERFORMANCE.md` 为准；验收未结束前不得引用上一轮 acceptance。

五视角裁决：玩家视角的袖部色块与肩线收益有同镜头全身图；玩法视角待输入路径和坐立/楼梯运行证据；美术视角保留上述反方结论；工程视角增加 1,094 桌面三角形但减小 GLB 123,524 字节，必须继续看全场景峰值；QA 以最终资产指纹绑定报告，桌面模拟不替代真机。

发布方式为检查后的分支提交与推送；不把它写成生产部署。回滚可以恢复父提交的主角双档、源文件和构建入口。真实玩家反馈、手机实测和整体人物美术验收仍未获得，不代签。


复现同镜头对照时必须显式指定两份资产，避免新版安装后意外把新版自己当作旧版：

```sh
ATRIUM_REVIEW_BASELINE=tmp/hero-art-study/baseline.glb ATRIUM_REVIEW_CANDIDATE=public/assets/atrium/residents/you.glb ATRIUM_REVIEW_OUTPUT=tmp/hero-release-comparison node scripts/review-atrium-hero-art.mjs
```

首次完整检查在楼梯等待半层高度时超时（12 秒），见 `evidence/atrium/validation/stairs-first-failure.txt`。同一生产构建与未修改脚本连续两次复验均完成主/回程上下行；没有通过延长超时或修改角色移动来放行。首次失败的具体原因未确认，保留为自动化稳定性风险。剩余检查从原资产指纹继续，不能宣称首次全流程无失败。

最终验收：21 阶段自动检查已完成（楼梯首次失败后复验），完整输入路线录像 105.8 秒、1,587 帧，逐帧解码成功，最终资产指纹 `7c7d433bb21ab726148bf85c105a291beebd47e477c3adbf642b28c98beca3c3` 与开始一致。桌面 P95 17.4ms（不通过 16.67ms），移动模拟 P95 17.5ms（通过 33.33ms）；两档全场景几何/绘制预算通过。此结果只允许保存局部改进，不构成整体生产美术或生产上线通过。
