# 发片根梢渐收研究

2026-09-23。基于隔离的 hair-sweep-v2 制作；默认人物资源未替换，全七人生产美术目标保持未完成。

## 设计和结果

重新核对 `design/references/atrium-visual-target.png`：目标是自然、略蓬松且有主要发束层次的年轻人物。近景对话与三维环绕必须成立，保持移动、对话和表情链路；以首次玩家靠近人物、交谈、继续探索为使用路径。不得以截图局部改善代替完整美术质量。

源 short01 共 200 个连通组，含 1138 顶点的连续底网，以及 199 组独立发片。尝试在不增加面数和贴图尺寸的预算内，沿四边形条带拓扑追踪根梢：以距实际底网较近的一端作为根部，根部不动，逐渐把宽度收至 30%，中段留起伏、梢部向底网外侧收束。该启发式不等于原作者标定的毛发生长方向。

实际处理 184 组条带、1288 个顶点，最大局部位移 0.0237497；368 个根端点与 1138 个底网顶点不变。面拓扑、UV、贴图像素、材质、头部全部形变、父级和变换保持不变。8 个三角面的划分变化，检查单独列出。

桌面正面、侧面、背面、左侧与俯视已检查：顶端碎边略减，主要发帽体积仍然存在。移动模拟近景也仍有宽硬块面。没有达到生产美术标准，不安装。连续底网的主要体积及大块层次需要重新设计，继续单纯收束小发片不能解决核心问题。

## 五视角质疑与证据

| 视角 | 可证伪质疑 | 实际结果 |
| --- | --- | --- |
| 玩家/产品 | 玩家靠近后仍看到硬壳，无法感知足够收益 | 近景确有硬块；不进入默认资源 |
| 游戏设计 | 几何调整影响表情与对话反馈 | 移动模拟 577 次连续眨眼及触控对话检查通过；尚非完整游玩验收 |
| 美术 | 收窄发片会露底或只改善正面 | 顶部碎边略减，正侧背/俯视主体仍帽状；收益不足 |
| 工程性能 | 同面数也可能增加资源体积 | 双档面数不变，但审计元数据随 extras 导出增加约 16 KB；没有声称性能优化 |
| 质量验收 | 重三角化和透明区域掩盖相交 | 同一参考三角化与实际候选三角化分别采样，结果均保留；不宣称连续碰撞无缺陷 |

## 检查边界

`v1-source.json` 比较基线条带上的 9016 个顶点、边中点和重心采样；相对底网的负向采样从 1235 降至 545。同一参考三角化下没有新增负向采样身份。实际候选三角化也为 9016 个样本、545 个负向样本，最小有向距离 -0.011009。

这包含透明区域及埋入底网的根部，是发片/发底的有向最近面采样，不能等同于穿入皮肤，也没有证明没有发片交叠、连续穿插或全姿态问题。8 个三角划分变化意味着固定参考身份检查不能独自覆盖实际网格，故另报实际候选结果。两者数量相同也不证明空间身份相同。

双档实际导出：桌面 26,532 面 / 2,444,276 B；移动 24,469 面 / 968,624 B。相对 sweep-v2 各增加 16,184 B，其中包含留在候选源对象上的逐条带审计 JSON，并随 extras 导出。若将来采用该方向，需将审计元数据从运行导出剥离并重新验证；当前候选因美术收益不足未采用。UV 请求检查通过，脚本语法和 diff 检查通过。

移动结果为本机 Chrome 的手机视口模拟，非手机真机。未重跑性能或全量发布门禁，未改正式资产，不宣称发布或用户美术签收。

## 复现

先按 `ATRIUM_HAIR_SWEEP_STUDY.md` 生成 sweep-v2，作为独立对照。候选构建：

```sh
ATRIUM_RESIDENT_IDS=you ATRIUM_HAIR_SWEEP_STUDY=2 ATRIUM_HAIR_CLUMP_STUDY=1 ATRIUM_BUILD_ROOT="$PWD/tmp/portrait-study/hair-clumps-v1" /Applications/Blender.app/Contents/MacOS/Blender --background --python-exit-code 1 --python scripts/build-atrium-residents.py
```

源检查使用 `scripts/verify-atrium-hair-clumps.py`，环境变量：

- `ATRIUM_HAIR_SOURCE=tmp/portrait-study/hair-clumps-v1/models/atrium/residents/you.blend`
- `ATRIUM_HAIR_BASELINE=tmp/portrait-study/hair-sweep-v2/models/atrium/residents/you.blend`
- `ATRIUM_HAIR_REPORT=evidence/atrium/hair-clump-study/v1-source.json`

证据在 `evidence/atrium/hair-clump-study/`：`v1-desktop/` 是相同镜头对照（待机相位不锁定），`v1-mobile/` 是实际候选请求替换后的连续表情/触控结果，源及 GLB SHA 分别见源检查和资源/浏览器报告。
