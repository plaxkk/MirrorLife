# 活体余波设计 QA

## 已证明

- 真实选择会生成固定见证者，并把该 Citizen 放入同一室内物理 occupant 集合。
- “寻找”之后，摄像机转向人物，人物以金色轮廓和“未发生的未来”标识出现。
- 自动化通过人物的真实屏幕投影坐标点击角色，而不是直接调用完成函数。
- 人物详情呈现反事实证词；倾听后关系事件增加、角色记忆写入、路线恢复。
- `aftermath_focused` 与 `aftermath_witnessed` 会进入匿名体验证据。
- 刷新后已倾听状态保持。

## 仍需真人证明

机器验证能够证明人物真实存在、点击链路和状态写回正确，但不能证明玩家会自然理解这段余波。真人测试需要记录：是否发现发光人物、是否在点击前知道自己为何寻找、倾听后能否说出“事实未改变，但关系容纳了另一种理解”。
