# 近墙视野与肩袖续作

目标：首次玩家贴近楼梯侧墙时仍能辨认脚下通路，同时改善正常对话距离的肩袖轮廓。沿用 Three.js / Rapier、双层回游与既有身份和存档；预算仍为整处 180 calls / 500,000 triangles / 220 geometries。

## 实现与反方检查

- 玩家：自动镜头会不会抢方向？保持玩家 yaw，只在原俯角可用距离不足 1.4m 时尝试提高俯角；每个候选都做原有球体扫掠，恢复较慢。抬高增加脚下信息，但近墙依旧有淡出颗粒，不等于手游手感已获人工验收。
- 关卡：抬高是否撞顶棚或让窄梯无法走？候选无改善时保留原角度，顶棚单元用例覆盖；完整键鼠两层回游另行复测，模型碰撞和路线不因镜头改变而删改。
- 美术：肩部修改是否只是把凸起移位？首版单人运行对照仍有高肩峰，进一步降低前三圈袖山，并在合并前压低躯干外肩。移除旧袖压褶叠层，提高独立手指源网格的保留率。仍保留真实五指和握持锚点，没有以隐藏手部解决问题。方肩、手部接触与面部简化仍需观察，不宣布最终美术通过。
- 工程：更多镜头探测和手指三角面是否超预算？仅在原视角受限时追加探测，保持原限额，需同候选采样回答；不以单元测试代替性能测量。
- QA：单张站姿不能证明运动中无穿模。单人前后镜头、七人正侧面、接触/坐姿/楼梯专项与连续录像分开保留。待机相位不锁定，图像对照不是严格像素 A/B。

## 制作与能力边界

项目原创 Blender 源、master、两档 GLB 和动作源同步；没有外部生成或付费资产。首次 Blender 沙箱启动退出 139，沙箱外同命令重试成功；首次 Chrome 对照在沙箱内启动失败，沙箱外重试成功。

前一候选为 `adc0af0`。当前候选最终数据以 `evidence/atrium/acceptance.json` 和 `PERFORMANCE.md` 为准。整体空间比例、主梯曲面、日光、服装变形、完整表情、真实手机及长期稳定性尚未完成；本轮不是最终试点验收或生产发布。

首次候选手指保留率 0.9 导致桌面峰值 502,017 triangles，否决并改为 0.8（原版为 0.6），保留 `controls/rejected-digit-budget.json`。同轮首触摸 250ms 位移断言失败，单独复测测得 0.413m 并通过，阈值未放宽；该次失败缺少当时详细位移，不能据此确定根因或宣称首触摸抖动已解决。现已保存 `controls/touch-start.json`，最终验收重新执行同一断言。

最终独立采样：桌面 P50/P95/P99 = 16.7/18/18.5ms，峰值 87 calls / 495,520 triangles / 76 geometries；移动模拟 = 16.7/18.4/18.7ms，69 / 311,066 / 72。预算通过，严格桌面 P95 60fps 门槛未通过。移动仍是桌面 GPU 模拟；本轮未重现上一候选 200ms P99，不足以证明长帧根因已修复。首触摸断言最终测得约 0.393m 并通过。

视觉复查已看玩家正面、何川侧面与窄梯近窗：肩峰降低、楼梯踏步可见；侧面仍暴露裤侧折线悬空感，渐隐颗粒、脸颈简化和整体材质层次仍需处理。没有逐帧或人工用户体验验收签字。
