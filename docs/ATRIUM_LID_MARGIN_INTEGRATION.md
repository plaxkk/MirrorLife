# 眉眼与睑缘本地接入

2026-09-23，基线正式资产 `5393df1`。上轮眼形研究已提供制作与反证，本轮在温和眼形 gaze-v2 上增加连续眼睑毛根色带，并将眉形、眼形、睑缘组合接入本地主角。全七人生产美术仍未完成。

玩家在真实 3D 中庭探索、接近交谈、继续探索；此次改动希望改善对话近景的眉眼轮廓和闭眼可读性。不增加交互步骤或等待，保留身份、移动与环绕。仍以桌面严格 60fps、180 calls / 500,000 triangles / 220 geometries 为预算，不能仅凭截图宣称可玩性完成。

## 制作和取舍

上睑毛根色带在原顶点色中沿边缘形成，眼角渐淡，下睑只做弱变化。它随连续眼睑变形，不增加眼线网格、贴图或独立绘制。与 gaze-v2 相比，234 个面角颜色改变，所有源几何/形变、拓扑、UV 和粗糙度逐项相同，见 `source.json`。色带本身不改变面数。

正式接入包含上轮眉体和眼形，因此相对之前正式版仍增加几何：桌面 2,492,000 B / 26,558 面，移动 966,152 B / 24,525 面，均 7 图元；相对基线分别增加 3,640/2,292 B、982/508 面。眉体毛束占主要新增面数。源、master、双档运行模型、动作源和九动作导出一起同步。

默认启用此组合；`ATRIUM_REFINED_GAZE=0` 且不设置显式研究开关可重建此前眉眼。显式 `ATRIUM_BROW_STUDY`、`ATRIUM_GAZE_STUDY`、`ATRIUM_LID_MARGIN_STUDY` 仍可覆盖对应部分，研究输出强制隔离。复现历史实验时应先设置 `ATRIUM_REFINED_GAZE=0`，再设置当时显式开关，避免新默认叠加。

## 五视角验收

| 视角 | 反对意见 | 证据与界限 |
| --- | --- | --- |
| 玩家/产品 | 颜色只在放大图中有用 | 正常对话画幅变化克制；闭眼/半闭眼轮廓较清楚，作为局部增量接入 |
| 游戏设计 | 新边缘在眨眼时脱离眼皮 | 颜色位于原连续网格，578 次移动模拟表情和实际触控对话通过 |
| 美术 | 色带成为浓妆且改变角色气质 | 上睑局部加深、眼角淡出，下睑弱化；实拍未见浓重黑线，但整体脸部仍人偶化，不能整体签收 |
| 工程性能 | 加细节破坏资源和帧率预算 | 色带不增面或纹理，组合成本与当前运行性能单独记录；单角色图元数不是全场景调用数 |
| 质量验收 | 接入资产不同于截图或动作版本 | 文件替换前后 SHA、运行资产报告、九动作实际解码、双档材质与包围范围检查绑定当前资产 |

## 当前证据

目录 `evidence/atrium/lid-margin-study/`。`desktop/` 对照 gaze-v2 与新增睑缘，固定相机但 idle 相位未锁，不作像素差分；含中性、25/50/75% 闭眼、闭眼和讲话正侧面。`mobile/` 最终候选实拍及 578 次连续表情/真实触控对话通过，命令正常退出。

`source.json` 证明色带不改源形变。其基线 gaze-v2 的闭眼覆盖是 4,961/4,961；此次未重新运行相同源几何的覆盖射线，不虚报为新测量。`integration/motion.json` 检查当前便携九动作；`integration/bounds.json` 检查七人双档五姿态蒙皮包围范围；`integration/materials.json` 检查实际导出粗糙度查找图。28 项相关单元/回归检查与生产构建通过，构建仍有大包提示。

本轮没有完整 21 阶段发布套件、手机真机和用户审美签收。对照参考图没有面部特写，不宣称特定脸部像素还原。当前是本地增量接入，未发布；远端上传授权限制仍在。

桌面生产构建输入环绕测量：P50/P95/P99 为 16.7/17.5/17.7 ms；峰值 101 calls / 495,570 triangles / 81 geometries。无脚本报告错误，严格 60fps 仍未达到。面数距离 500,000 上限仅剩 4,430，后续全员制作必须同步控制成本。历史测量不是控制变量 A/B，不将波动宣称为性能提升。

接入检查前后运行指纹相同：`4a5103f36fccfb8c6c422ecdf00598c00ec3dc46dc5a8f57762d5ffbde20ef28`。

同构建顺序运行的移动模拟：P50/P95/P99 为 16.7/17.5/17.7 ms，峰值 83 calls / 330,940 triangles / 77 geometries，实际触控移动 1.85 米，无脚本报告错误。桌面与移动测量均正常退出；这些结果不替代手机真机与长期游玩。

剩余重点：自然脸部骨相和眼睑层次、发际线与顶部发片、衣装连续结构和全员一致性。不能把眉眼局部改进当作生产美术目标完成。
