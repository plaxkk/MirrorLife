# 头部近景错误裁剪修复 · 2026-09-23

检查上一轮颈部绑定的实际截图，发现主角近景只剩头发和眼睛，脸部与颈部未显示。重新加载默认资产复现成功。此前骨骼矩阵、固定端顶点与21阶段执行记录没有覆盖此可见性缺陷，不能作为颈部外观验收通过的证据。原失败图保留，不覆盖历史记录。

玩家承诺：首次玩家靠近、旋转观察和交谈时，完整头脸持续可见，继而继续探索。保持自然青年角色、真实3D环绕和现有交互；原180 calls /500000 triangles /220 geometries预算不变。本轮先修复该阻断缺陷，眼球层次研究暂未进入运行资源，也没有生成新的美术候选。

根因：`loadAtriumActor` 将原始 geometry 包围球复制给 SkinnedMesh。颈部蒙皮资产的顶点存储在绑定空间，Head节点另有约1.473的高度变换；原始顶点包围球中心局部y约1.458，被重复抬高。实际蒙皮后的局部中心约-0.019。错误范围使脸部被视锥裁剪掉。

修复：使用 `SkinnedMesh.computeBoundingSphere()` 计算经过逆绑定矩阵和骨骼变换的局部包围球，再保留原0.65动作余量及正常视锥裁剪。只在人物加载时计算，无每帧全顶点扫描。资产、面数、骨骼和表情未改。

五视角自审（同一执行者，不代表外部签收）：
- 玩家：数值正常仍可能看不到脸；实际修复前后近景证明脸与颈恢复。
- 游戏设计：动作可能越界；检查七人双档的站立、行走、说话、坐下、转头姿态。
- 美术：可见不等于自然；脸型、眼睛、肤质和衣装仍不达生产美术标准。
- 工程：关闭全部裁剪会扩大成本；保留裁剪，仅修正局部坐标，另做生产构建性能采样。
- QA：只测新公式会漏回归；新增检查读取实际压缩GLB并比较全部蒙皮顶点与运行包围球，同时记录旧原始包围球的失败距离。
