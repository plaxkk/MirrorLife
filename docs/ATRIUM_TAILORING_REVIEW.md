# 主角外套与织物制作验收

## 目标对齐

本轮承接 `ATRIUM_PRODUCTION_ART_GOAL.md` 中未完成的主角外套制作。目标玩家是首次进入中庭、移动探索并靠近居民交谈的玩家；承诺是人物服装具有可辨认的层次和布料表面，并继续支持真实 3D 环绕、坐立、持物和上下楼。完整七人生产美术仍未完成，本轮不将局部修整视为全量交付。

首次 30 秒继续为进入中庭并找到探索方向；前 5 分钟继续为探索、交流和决策，再回到探索。输入、碰撞、交互、保存和反馈路径不变。全场景预算保持 180 calls / 500,000 triangles / 220 geometries；桌面 P95 目标 60fps，移动 P95 目标 30fps。未新增相机限制或截图专用角色替身。

## 实现与问题定位

- 主角连续蒙皮衣身增加胸腰松量、口袋旁斜褶和肘部压缩，帽兜、包边、抽绳与口袋双线为真实网格。
- 背面检查拒绝了最初过长、呈硬壳状的帽兜，先收拢下缘，再依据衣身背部表面留出间距并垂落；拒绝了陷入衣身和僵硬向后突出的候选。失败候选截图保留于 `evidence/atrium/production-tailoring/rejected/`。
- 上一轮导出候选的身体颜色贴图为空，导致身体黑亮。受控实验表明：源网格颜色数据非空；纯色材质可烘焙；旧材质在 512/1024 分辨率下仍会烘焙全黑；仅重载文件、禁用蒙皮或替换 Principled 节点均未解决。新建的显式顶点色与粗糙度材质可完整烘焙。未将具体 Blender 内部故障机制视为已证明。
- 正式身体材质直接读取 `Color`，并将 `SurfaceRoughness` 还原为线性粗糙度，再加入有遮罩的染色、纤维与粗糙度变化。皮肤不应用织物变化。可编辑 `.blend` 保留程序材质；GLB 使用标准颜色、粗糙度和切线法线贴图。
- 身体贴图桌面 1024²、移动 512²，附属衣料桌面 512²、移动 256²。烘焙后移除已烘入颜色的顶点色，避免重复相乘。绑定姿态烘焙后恢复修改器，不改变运行蒙皮。
- 构建拒绝空白或近空白贴图；运行资产回归检查双档与 master 的贴图覆盖、尺寸、UV、蒙皮、单身体 primitive、皮肤/鞋面/布料粗糙度，以及无重复顶点着色。材质响应测试读取实际粗糙度贴图，不把 glTF 省略的默认常量误判为材质丢失。

## 五视角交叉评审

本记录为同一执行者的五视角自审，不代表外部玩家或美术师认可。

| 视角 | 最强质疑与反例 | 证据与裁决 |
| --- | --- | --- |
| 玩家 / 产品 | 近景纹理改进在普通游玩距离可能不明显 | 全身、正常场景与路线截图检查；帽兜与抽绳轮廓可见，微小织纹不作为主要收益 |
| 游戏设计 | 帽兜、抽绳在坐立和抬臂时可能穿插 | 保留原闭环与动作控制，使用服装姿态、坐立、持物、楼梯和路径运行证据；自动测试不代替所有表面接触的人工审核 |
| 美术 | 帽兜可能像硬壳，法线可能像塑料噪点 | 对第一版作了否决并缩短轮廓；正侧背检查材质。面部、发根发梢和全员材质仍不够生产级 |
| 工程 / 性能 | 纹理使下载量显著增长，弱网和手机可能更差 | 桌面主角 GLB 从约 0.28 MB 增至约 2.30 MB；移动从约 0.24 MB 增至约 0.86 MB。必须报告代价，不用局部帧率掩盖下载成本 |
| QA / 发布 | 构建成功仍可能导出全黑或重复染色，旧证据可能混入 | 加入解码 PNG 回归与单候选指纹检查，重新执行完整验收。手机真机和生产发布仍是独立门槛 |

最强反方结论：本轮增加约 2.03 MB 桌面资源和 0.61 MB 移动资源，尚无弱网手机证据证明它值得；因此不能以本地验收宣称已达到所有目标设备的生产标准。
