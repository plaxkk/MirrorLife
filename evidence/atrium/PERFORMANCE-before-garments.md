# 天井生活馆 · 楼梯接触续作候选性能

当前指纹：`33f28e9c215fd9ad13f1f52db2b57bba131bcf6a6e4f9f59e5cf91399e2d5b92`。原始结果来自本轮 `npm run verify:atrium:release`，完整步骤见 `acceptance.json`。

结论：两档几何数量仍在原预算内；桌面稳定 60fps 未通过，本次 P95 为 49.3ms。移动模拟 P95 32.9ms，P95 在该样本中通过 30fps 初始目标，但 P99 67.1ms 显示长尾卡顿；仍不能外推真实手机性能。

## 条件与方法

本机可见 Chrome 152，ANGLE Metal / AMD Radeon Pro 5300M。桌面 1920×1080、DPR 1；移动模拟 390×844、页面 DPR 3、渲染 DPR 1.25。移动仍使用同一桌面 GPU，没有真机与热降频样本。机器型号沿用历史报告的 MacBookPro16,1、i7-9750H/16GiB。

本机 production preview 127.0.0.1:4195，各测试顺序执行，性能采样不录像、不运行 Blender。进入后等待 1.8 秒，再用真实鼠标环绕约 30 多秒；保留动态居民。OS 缓存未清空，没有模拟公网、弱网或长时游玩。该性能路线在入口环绕，不能当作楼梯解算最坏成本测试。

GPU 计时使用 EXT_disjoint_timer_query_webgl2，每十帧异步采一帧，最多四个在途查询。只计主画面与动态阴影的 GPU 命令时间，不包括显示呈现、输入、加载或 CPU 脚本。本次两档均支持，discarded 为 0；无支持时返回 null。不能把 GPU 时间直接当作总帧时间。

## 预算与比较边界

继续沿用 180 calls / 500,000 triangles / 220 geometries，双层共用一份预算。renderer.info 每帧包含主画面和动态人物阴影；静态建筑阴影在加载时生成一次，其耗时计入加载。三角面含通道重复，geometries 是 GPU 对象数。

本轮新增脚底射线探测和两段腿解算，没有增加网格、材质或渲染通道，桌面峰值保持 493,955 三角面。前一候选桌面/移动模拟 P95 分别为 50/33.3ms（`PERFORMANCE-before-stairs.md`），当前为 49.3/32.9ms。移动样本波动较大；这不是固定条件交替 A/B，不能归因于本轮代码改善，也不能由入口环绕结果量化楼梯解算成本。

资源合计是 Resource Timing 同源 resource 条目，不含导航文档，不是全部发布体积。当前资产清单 79 项：source/master 93050805 bytes，public 10261911 bytes。显存、进程总内存、手机功耗与温度仍未取得。

当前性能完成门禁仍未通过。后续必须固定条件分析渲染成本、实测楼梯最坏路径和长时样本，保留人物身份、完整建筑与连续探索；不能通过降低画幅后继续宣称原生 1080p 达标。

## 连续录制路径补充

可见 Chrome 的完整回游曾记录 100 calls / 499,557 triangles / 80 geometries，仍在原预算内，但三角面仅剩 443 的余量。该次录像画幅不合格，不能作为交付影片；其较高渲染峰值仍保留，不能只引用入口环绕的 493,955 作为全部观察中的最高值。

最终完整录像使用本机 headless Chrome / ANGLE Metal，画布全程保持 1920×1080，输出 1280×720。该次峰值为 89 calls / 484,569 triangles / 80 geometries，录制期间 P50/P95/P99 为 33.3/33.4/50ms。录制、窗口模式和路径都与入口性能采样不同，两组不做直接提升比较；桌面稳定 60fps 门禁仍使用可见 Chrome 的 49.3ms P95 判为未通过。
