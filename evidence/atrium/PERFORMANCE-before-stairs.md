# 天井生活馆 · 坐姿续作候选性能

当前指纹：`f8da85d60b905ad7a1bad929428573c8dd9045941fa6e21ce5b8f40c1804aca4`。原始结果来自本轮 `npm run verify:atrium:release`，完整步骤见 `acceptance.json`。

结论：两档几何数量仍在原预算内；桌面稳定 60fps 未通过，本次 P95 为 50ms。移动模拟 P95 约 33.3ms，贴近 30fps 目标边缘，不能外推真实手机性能。

## 条件与方法

本机可见 Chrome 152，ANGLE Metal / AMD Radeon Pro 5300M。桌面 1920×1080、DPR 1；移动模拟 390×844、页面 DPR 3、渲染 DPR 1.25。移动仍使用同一桌面 GPU，没有真机与热降频样本。机器型号沿用历史报告的 MacBookPro16,1、i7-9750H/16GiB。

本机 production preview 127.0.0.1:4195，各测试顺序执行，性能采样不录像、不运行 Blender。进入后等待 1.8 秒，再用真实鼠标环绕约 30 多秒；保留动态居民。OS 缓存未清空，没有模拟公网、弱网或长时游玩。

新增 GPU 计时使用 EXT_disjoint_timer_query_webgl2，每十帧异步采一帧，最多四个在途查询。只计主画面与动态阴影的 GPU 命令时间，不包括显示呈现、输入、加载或 CPU 脚本。本次两档均支持，discarded 为 0；无支持时返回 null。不能把 GPU 时间直接当作总帧时间。

## 预算与比较边界

继续沿用 180 calls / 500,000 triangles / 220 geometries，双层共用一份预算。renderer.info 每帧包含主画面和动态人物阴影；静态建筑阴影在加载时生成一次，其耗时计入加载。三角面含通道重复，geometries 是 GPU 对象数。

本轮没增加场景网格和材质，桌面峰值仍为 493,955 三角面。前一候选的桌面 P95 是 34.3ms（`PERFORMANCE-before-seating.md`），当前为 50ms。存在环境波动及新增计时条件，不能宣称性能改善，也不能仅凭这两个样本量化坐姿代码的性能回归；需要固定条件下 A/B 和长时样本。

资源合计是 Resource Timing 同源 resource 条目，不含导航文档，不是全部发布体积。当前资产清单 79 项：source/master 93050805 bytes，public 10261911 bytes。显存、进程总内存、手机功耗与温度仍未取得。

本轮新增坐姿、离座和计时测试通过，不能替代真实手机、长时玩家和生产验收。当前优先修复渲染瓶颈，保持人物、建筑与连续探索；不通过降低画幅后继续宣称原生 1080p 达标。
