## 环境与方法

本机 MacBookPro16,1，Intel i7-9750H / 16GiB，GPU 为 ANGLE Metal / AMD Radeon Pro 5300M，可见 Chrome 152。桌面 1920×1080、DPR 1；移动为同一桌面 GPU 上 390×844、页面 DPR 3、渲染 DPR 上限 1.25 的触屏模拟。系统型号沿用前轮本机查询，浏览器/GPU/画幅来自本轮实际页面。

`npm run verify:atrium:release` 先测试与构建，再启动 127.0.0.1:4195 production preview，顺序运行各项验收。性能阶段不录屏、不运行 Blender，各档单独启动 Chrome。进入后等待 1.8 秒，再进行约 30 多秒的实际鼠标环绕。场景与动态居民持续运行；不是长时稳定性测试。OS 缓存未清空，未模拟公网或弱网。

## 预算与前后对照

180 draw calls / 500,000 triangles / 220 geometries 未提高。双层整体共用一份预算。每帧计入主画面及动态角色阴影，静态建筑阴影只在加载时生成一次，其耗时计入加载。三角面含渲染通道重复；geometries 是 GPU 对象数。

本轮封口后候选为 505,273 三角面，超过预算。移除运行时盆内土壤不可见倒角后为 493,955，减少 11,318；原可编辑土壤模型、花盆与叶片未删减。失败基线保存在 `performance-before-soil-lod.json`。上一候选桌面 P50/P95/P99 为 17.5/34/49ms，本次为 32.7/34.3/50.5ms，因此只证明数量降低，不能宣称帧率改善。更早历史报告见 `PERFORMANCE-previous.md`。

新增接触遮蔽是一张 384×576 PNG（约 128 KiB），384×288/层、每点 24 条半球射线、1.15m 半径，来自静态三维几何。运行时共用原有绘制批次，纹理对象数从 17 到 18，并新增地面投影 UV。不是 GI，也不替代动态人物阴影。
