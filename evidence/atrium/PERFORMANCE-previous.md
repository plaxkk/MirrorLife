## 环境与方法

- MacBookPro16,1，Intel Core i7-9750H 2.60GHz，16GiB RAM，macOS 26.5.1 (25F80)。GPU：ANGLE Metal / AMD Radeon Pro 5300M；可见 Chrome 152。型号由系统只读查询取得，完整浏览器设备字段在两个 measurement JSON 中。
- 桌面：1920×1080，页面 DPR 1，实际渲染 DPR 1，桌面 GLB 与阴影档。
- 移动模拟：390×844，页面 DPR 3，实际渲染 DPR 1.25，移动 LOD。仍是同一台桌面 GPU，不是真实 iOS/Android；没有模拟移动芯片热降频。
- 本机 Vite production preview，127.0.0.1:4194。每次测试独立 Chrome 临时配置；页面资源冷导航，OS 文件缓存未清空。没有公网网络时延或带宽限制。
- 进入后等待 1.8 秒，再以真实鼠标输入环绕采样约 35–36 秒。性能阶段不录像、不运行 Blender。动态居民和交互系统保持启用。
- 原始 rAF 帧间隔，不只统计 CPU render 函数。峰值取每帧 `renderer.info` 主画面与动态人物阴影合计；静态建筑阴影在加载时生成一次，其成本在加载耗时中。

资源数据来自浏览器 Resource Timing；不是整个部署目录体积，导航文档本身不属于 resource 条目，transferSize 包含协议头及缓存口径。不要把这些数值当作公网下载耗时。7 名角色、20 条关节绑定/居民在实际运行统计中可见。

CPU 测量：桌面脚本 P50/P95 为 2.5/3.5ms，render 调用为 2.6/3.6ms；移动模拟为 1.7/2.1ms 与 2.5/3.6ms。这些值不包括 GPU 完成时间，不能因为 CPU 数值低就宣布性能达标。GPU 定时、显存、进程总内存、手机温度与功耗未获取。

最后一次完整回游（同时录屏、途中不抓静态截图）在退出前累计步行约 150.45m，峰值 92 calls / 454,523 triangles / 80 geometries，帧时间 P50/P95/P99 为 17.3/33.9/35.2ms。它覆盖不同位置和交互，但含采集开销，不与上表无录屏环绕样本混算。退出后重入及截图期间存在更长尖峰，保留在 `walkthrough-stats.json`；不据此宣布重入流畅度已通过。

移动端实际触屏摇杆输入持续约 900ms，玩家移动约 1.943m；截图和原始坐标记录见 `mobile-measurement.json`。这验证输入链路，不验证手机硬件性能。

## 预算及优化前对照

180 draw calls / 500,000 triangles / 220 geometries 没有提高。本试点把两层作为一个连续加载空间，以全场景每帧统计检验该原有单房间预算，而不是每层分别享有一份预算。当前数量指标通过，视觉和帧时间不能由此推定通过。

| 记录 | P50 / P95 / P99 | 峰值 calls / triangles / geometries |
|---|---|---|
| 优化前、无头 Chrome | 66.7 / 249.9 / 333.3ms | 108 / 589,141 / 76 |
| 优化前、可见 Chrome | 16.7 / 33.2 / 34.0ms | 108 / 589,141 / 76 |
| 当前、可见 Chrome | 33.1 / 34.4 / 66.7ms | 87 / 464,218 / 76 |

两份优化前 JSON 原样保留。无头与可见模式不是等价条件，早期资源统计范围也较窄，不能把两者差异全归因于代码优化。当前减少了曲线枝干细分、陶器/土壤/窗外城市细节和人物非关键小件，保留建筑源模型、主要轮廓与物理数据；优化确实减少渲染数量，但本次中位帧时间没有改善。不能挑选较好的早期样本代替本次结果。

LOD、按材质合并、城市方位分组、视锥裁剪、静态阴影缓存、Draco 已实现。房间级遮挡剔除、全面实例化、KTX2、专业烘焙 GI 尚未完成。没有调高预算或移除玩家环绕/二层路径来换取指标。

## 资源与剩余工作

`assets.json` 共 77 个文件：可编辑源及 master 共 96,148,931 bytes；public 试点资产共 9,996,792 bytes。public 总量包含两档 LOD、独立模块、动作参考和许可文件，运行时不会同时下载全部。资产清单检查了 GLB 头、声明边界、骨架/动作/模块数量，并不替代解码拓扑及动作接触审查。

下一步优先定位帧调度/GPU 瓶颈并在固定设备环境复测；同时精修关节变形与光照，防止只优化数量却继续损害画面。需要真实手机和更长的真实玩家路径数据，才能验收桌面/移动性能目标。构建中原有经典脚本和大包警告仍在，未隐藏警告或改变包体门槛。
