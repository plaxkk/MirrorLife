当前指纹：`1011bd1ddb6def071a6e35d8dd6a580e541d81aeb076e2fd0ef21247511f3441`。完整顺序验收步骤见 `acceptance.json`，原始设备和帧时间数据见 `performance-measurement.json` 与 `mobile-measurement.json`。

结论：两档入口环绕样本的几何数量在原预算内；桌面稳定 60fps 未通过，P95 100.4ms。移动模拟 P95 17.6ms，在该样本中低于 33.33ms，但不能外推真实手机。

## 条件与方法

本机可见 Chrome 152，ANGLE Metal / AMD Radeon Pro 5300M。桌面 1920×1080、DPR 1；移动模拟 390×844、页面 DPR 3、渲染 DPR 1.25。移动仍使用同一桌面 GPU，没有真机与热降频样本。机器型号沿用历史报告的 MacBookPro16,1、i7-9750H/16GiB。

本机 production preview 127.0.0.1:4195，各测试顺序执行；性能采样不录像、不运行 Blender。进入后等待 1.8 秒，再用真实鼠标环绕约 30 多秒；保留动态居民。OS 缓存未清空，没有模拟公网、弱网或长时游玩。该路线在入口环绕，不能当作所有角落或楼梯最坏成本测试。

GPU 使用 EXT_disjoint_timer_query_webgl2，每十帧异步采一帧，最多四个在途查询。只计主画面与动态阴影的 GPU 命令时间，不包括显示呈现、输入、加载或 CPU 脚本。两档均支持，discarded 均为 0。GPU 时间不能直接代替总帧时间。

## 预算与比较边界

继续沿用 180 calls / 500,000 triangles / 220 geometries，双层共用一份预算。renderer.info 每帧包含主画面和动态人物阴影；静态建筑阴影在加载时生成一次，其耗时计入加载。三角面含通道重复，geometries 是 GPU 对象数。

七人桌面资产合计增加 201 个唯一三角面，本次桌面峰值由 493,955 变为 494357。前一候选桌面/移动模拟 P95 为 49.3/32.9ms，当前为 100.4/17.6ms。桌面本次结果明显变差，保留上一轮 `PERFORMANCE-before-garments.md`；没有固定条件交替 A/B 或系统追踪，不能归因于某一服装修改，也不能把移动模拟改善宣称为优化收益。

当前资产清单 79 项：source/master 97156045 bytes，public 10883491 bytes。上一候选 public 为 10,261,911 bytes，增加 621580 bytes，主要来自人物 UV、网格和同步动作文件。资源合计为 Resource Timing 同源 resource 条目，不含导航文档，也不是全部发布体积。显存、进程总内存、手机功耗与温度仍未取得。

完整回游、录像解码与全画幅检查的结果另见 `acceptance.json` 的追加验证。录像在本机 Chrome headless 运行真实 WebGL，15fps 输出并保留实际时间；不把录像帧率当作游戏性能。

本次录像回游峰值为 89 calls / 485,543 triangles / 80 geometries；全程检查的页面与画布为 1920×1080，输出录像 1280×720、95.2 秒、1,428 帧、50,869,567 bytes。ffmpeg 完整解码返回 0，另检查八个间隔抽帧，见 `playthrough-contact-sheet.jpg`。这些操作和录制开销与独立可见 Chrome 性能样本不同，不能取二者较好值作为最终帧率。
