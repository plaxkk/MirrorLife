## 条件与统计口径

本机 Chrome 152，可见窗口，ANGLE Metal / AMD Radeon Pro 5300M。设备型号沿用 MacBookPro16,1、i7-9750H、16GiB。桌面 1920×1080 / DPR1，移动模拟 390×844 / 页面 DPR3 / 渲染 DPR1.25。手机实机、热降频、功耗和弱网未验证。生产构建本机 4195 端口，进入后预热 1.8 秒，再用真实鼠标环绕 30 多秒；顺序运行，不同时录像或运行 Blender。未清空 OS 缓存，不能外推公网冷启动。

双层试点继续共用 180 calls / 500,000 triangles / 220 geometries。renderer.info 包含主画面和动态人物阴影，静态建筑阴影加载时只生成一次。三角面统计包含通道重复；geometry 是 GPU 对象数，不是 Blender 对象数。场景、人物、阴影、材质和渲染分辨率均未为本轮优化降档。

## 改动与对照

移除地点、菜单按钮、目标卡、对话框、抽屉共五处 backdrop-filter。保留暖色半透明底、布局、边框、文字、阴影与所有操作。截图 `compositor/blur-hud.png`、`flat-hud.png` 可见实际差别：取消模糊后背景轮廓略微透出，目标文字仍可读。

同页面四段环绕 A/B：原模糊 P95 49.4/34.2ms，关闭后 17.6/17.5ms。固定镜头四段 A/B：原模糊 49.7/34.2ms，关闭后 17.6/17.5ms。固定镜头各段页面可见但未持有焦点；仅为一致条件诊断。完整原始数组、设备及焦点状态见 compositor 目录。这些结果支持该 CSS 效果对本机性能存在显著成本，未进行完整系统追踪，不宣称解释所有卡顿。

上一候选独立样本 P95 100.4ms，保留于 `PERFORMANCE-before-compositor.md`。该值未在本轮 A/B 原模糊样本中完整重现，因此不能把 100.4 到当前值全部归因于此次代码修改，也不能以最佳样本取代实际验收结果。

资产清单仍为 79 项，public 10883491 bytes，source/master 97156045 bytes。资源表使用同源 Resource Timing 条目，不含导航文档，不等于全部发布体积。此次未重导模型，资源体积没有通过删除人物或细节降低。

完整回游及录像验证见 acceptance.json 追加记录。录像在本机 Chrome headless 执行真实 WebGL，按真实时间输出 15fps，不用于替代独立性能测试。美术、首次玩家体验、真实手机和长时间稳定性仍是未通过门禁。

本次回游峰值 89 calls / 485,543 triangles / 80 geometries；页面与画布全程为 1920×1080。交付录像 118.73 秒、1,781 帧、56,147,496 bytes，通过完整解码与帧数核对；检查八个均匀抽帧和 116 秒末段画面，未出现画幅缩小。记录自动操作时间，不能代替真实玩家 3–5 分钟阅读与决策体验。
