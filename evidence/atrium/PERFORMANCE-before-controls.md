## 条件与口径

本机 Chrome 152 可见窗口，ANGLE Metal / AMD Radeon Pro 5300M；设备登记沿用 MacBookPro16,1、i7-9750H、16GiB。桌面 1920×1080 / DPR1；移动模拟 390×844 / 页面 DPR3 / 渲染 DPR1.25。真实手机、热降频、功耗、弱网及长时间稳定性未验证。生产预览 4195 端口，顺序运行，性能采样不与 Blender 或录像并行。系统缓存未清空，不能外推公网冷启动。

双层合计预算保持 180 draw calls / 500,000 triangles / 220 geometries。renderer.info 包含主画面与动态人物阴影；三角面包含通道重复，geometries 是 GPU 对象数。静态建筑阴影加载时生成一次。本轮更改七名人物头部比例和面部几何，沿用画质、场景、完整交互与前轮界面合成优化。

GPU 每十帧异步查询，仅覆盖 WebGL 渲染，不包含显示呈现、浏览器整体合成及输入。不能相减分位数估计其他阶段。显存、进程总内存未获取，仅记录 JS heap。输入到活动帧是进入操作的端到端记录，不是每个操作的输入延迟分布。

资产清单 79 项，public 10835119 bytes，source/master 96663957 bytes。Resource Timing 合计不含导航文档，不等于整个发布包。移除旧独立鼻部件后部分几何减少，不将其解释为总体美术完成。

上一轮数据保留在 PERFORMANCE-before-faces.md。桌面峰值三角面从 494,357 变为 489937；观察到的差异不是严格控制动画相位的性能 A/B，不据此声称帧率收益。

## 流程与残余风险

本候选完整发布验收包含 15 步，另见各 validation 日志、坐姿/楼梯/异常原始报告。连续回游录像使用本机 Chrome headless 实际 WebGL，以真实时间编码 15fps，不作性能样本；全片解码记录见 video-validation.json。最终美术、首次玩家 3–5 分钟阅读决策、手机实机及主世界完整集成仍未通过。

人物正/侧面同镜头对照见 faces/review.html；五视角审查和已知差距见 ../../docs/ATRIUM_FACE_REVIEW.md。

录像为 99.6 秒 / 1,494 帧 / 52,574,697 bytes，通过全片解码；抽查八个均匀帧及 97 秒末段画幅。回游峰值 93 calls / 470,524 triangles / 77 geometries。回程区域可见近处窗框大面积遮挡，镜头体验仍需修正，不能归入已通过美术/体验门禁。
