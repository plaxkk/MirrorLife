# Quick Spec：静心角 · 静默陪伴

日期：2026-07-16
状态：已实现，等待真人节奏测试

## 1. 验证问题

> 玩家能否在不增加新弹窗教程的情况下，理解「不点击、不逼近、不解释」也是一种有后果的社会行动？

这是对五章「找三件陈设—二选一」重复节奏的第一次具身化 PIVOT 测试。

## 2. 玩法规则

1. 静心角会稳定选择一名真实 Citizen Agent 作为陪伴对象。
2. Agent 使用真实室内 X/Z 坐标，并在仪式期间暂停游走，不会在读条时漂移。
3. 玩家需要把人物保持在视野中，与 Ta 维持 1.05–5.2 世界单位的距离，并让镜头安静八秒。
4. 视线移开、继续走动或过度靠近时，进度以 22% 速率回落，不会一次清零。
5. 点击「回到这段安静」只会重新聚焦人物，保留已经积累的陪伴进度，也不会重复制造开始事件。
6. 仪式替代一条陈设线索：静心角只需要两处物件证据和一段静默陪伴。
7. 点完第三件陈设不能绕过仪式；系统会明确告诉玩家最后的证据在人身上。
8. 完成会写入关系事件、玩家关系记忆、居民记忆、事件日志和匿名体验证据。
9. 完成状态跨刷新保留；未完成的中间进度不持久化，避免重新进房时误判。

## 3. 进度公式

命名表达式：

```text
PresenceProgress(t + Δt) = clamp(P + Δt × (V ? 1 : -0.22), 0, 8000)
V = G ∧ D ∧ S
```

| 符号 | 类型 | 范围 | 含义 |
| --- | --- | --- | --- |
| `P` | float | 0–8000 ms | 当前已积累的静默陪伴时间 |
| `Δt` | float | 0–120 ms | 当前渲染帧纳入判定的时间步长 |
| `G` | bool | true / false | 人物是否在视线容差 0.24 rad 以内 |
| `D` | bool | true / false | 世界距离是否在 1.05–5.2 之间 |
| `S` | bool | true / false | 镜头、玩家位置和输入是否稳定 |
| `V` | bool | true / false | 当前帧是否构成有效陪伴 |
| `PresenceProgress` | float | 0–8000 ms | 更新后的仪式进度；到达 8000 时完成 |

输出被强制限制在 0–8000 ms，避免负进度和完成后继续累加。有效陪伴以 1× 实时增长，失配只以 0.22× 实时回落。

示例：玩家已安静 2.0 秒，随后视线移开 0.7 秒，进度为 `2000 - 700 × 0.22 = 1846 ms`，而不是清零。

## 4. 反馈语言

- 常态人物使用低对比玉绿虚线「不想解释」。
- 视线与距离成立后，轮廓转为金色呼吸节奏。
- 进度条不显示分数，只显示四次呼吸和尚需时间。
- 失配反馈说明当前边界，不使用「失败」「重来」或惩罚音效。
