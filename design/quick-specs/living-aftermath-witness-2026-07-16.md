# Quick Spec：双线回声 · 活体余波见证者

日期：2026-07-16
状态：已实现，等待真人节奏测试

## 1. 要解决的问题

五章故事已经具备场所探索、事实/如果选择和跨房间路线，但连续游玩仍可能退化为五次重复的“找三件物品—二选一”。反事实虽然已进入 Agent 任务和记忆，玩家却不一定能在空间里看见它真的属于某个人。

可证伪问题：

> 玩家完成一次选择后，能否不看剧情日志，仅凭房间中的人物、光圈和行动，在 30 秒内理解“未被选择的未来仍被另一个人认真记住”？

## 2. 核心规则

1. 每个房间生成三个反事实旁观者时，稳定选择其中一人为 `aftermathWitness`。
2. 见证者是真实 Citizen Agent：使用同一人物 ID、人物状态、室内物理坐标、角色记忆与关系系统。
3. 选择完成后，房间路线进入第三阶段“听见活体余波”，下一章按钮暂时变为“寻找某人”。
4. 点击“寻找”只旋转视角并高亮人物，不自动完成互动。
5. 玩家必须点击房间中的真实人物，再主动选择“听完这段余波”。
6. 倾听会写入关系事件、玩家记忆、见证者记忆、事件日志和匿名体验证据。
7. 玩家仍可从门直接离开；系统不以强制等待惩罚跳过，但重新进入该房间时见证者仍在。
8. 已倾听状态跨刷新持久化，不会重复生成或复活。

## 3. 视觉语言

- 见证者使用玉绿色常态轮廓；被玩家寻找时转为金色脉冲虚线。
- 人物上方只显示“未发生的未来”，避免任务箭头和奖励分数。
- 人物详情使用墨蓝、玉绿和少量金色，保持成人化多巴胺风格。
- 移动端复用全高人物详情面板，主要行动保持在首屏内。

## 4. 验收

- [x] 见证者存在于当前室内 occupant 集合，并使用物理世界投影坐标。
- [x] 路线在见证前显示人物姓名，不显示下一章按钮。
- [x] “寻找”只聚焦和高亮，不改变 `discussed` 状态。
- [x] 点击实际房间人物后才出现“听完这段余波”。
- [x] 倾听后新增关系事件、双方记忆与 `aftermath_witnessed` 证据。
- [x] 倾听后恢复下一章入口；刷新后不再出现待处理见证者。
- [x] 桌面 1536×1024 与移动端 390×844 无横向溢出。
- [ ] 真人试玩中，70% 玩家能在不看日志的情况下复述见证者代表的另一种未来。
