# Quick Spec：公议庭 · 证词视差

日期：2026-07-16
状态：已实现，等待真人节奏测试

## 1. 可证伪问题

> 玩家能否不靠“选 A / 选 B”，而是通过真实移动理解：同一件事可以同时拥有两个互相冲突、却都不能被删除的位置？

本切片承接静心角的「静默陪伴」，但采用相反节奏：静默陪伴要求停下，证词视差要求主动穿过空间。它替换公议庭原有的三件陈设点击，不增加新的答题弹窗。

## 2. 完整循环

1. 系统从真实 Citizen Agent 中选出世界观距离最大的一对，并放入公议庭同一个 X/Z 物理世界。
2. 玩家走到版本 A 的讲述者附近，保持安全距离、将人物留在视野中 2.2 秒。
3. 玩家必须真实移动到版本 B 的位置，再听完另一种说法。
4. 两侧都被听见以后，地面才显现「第三个位置」。
5. 玩家站进第三个位置 2.6 秒，不选择赢家，让分歧本身成为场所证据。
6. 两次倾听分别写入 Agent 关系与双方记忆；最终站位写入玩家长期记忆和匿名体验证据。

## 3. Agent 配对公式

命名表达式：

```text
WorldviewAxis(c) = clamp(0.34O + 0.26A + 0.24S - 0.16Q, -0.16, 0.84)
ParallaxPair = (argmin WorldviewAxis(c), argmax WorldviewAxis(c))
```

| 符号 | 类型 | 范围 | 含义 |
| --- | --- | --- | --- |
| `O` | float | 0–1 | Agent 的 Big Five 开放性 |
| `A` | float | 0–1 | Agent 的 Big Five 宜人性 |
| `S` | float | 0–1 | Agent 的自我导向价值强度 |
| `Q` | float | 0–1 | Agent 的安全价值强度 |
| `WorldviewAxis` | float | -0.16–0.84 | 从「先确认边界」到「保留行动空间」的站位轴 |
| `ParallaxPair` | tuple | 两个不同 Agent | 当前社会中轴值最远的一对讲述者 |

输出被限制在 `-0.16–0.84`，避免异常存档让单一维度压过其他人格事实；相同分数使用稳定哈希打破平局，同一社会状态会得到同一对人物。

示例：某 Agent 的 `O=0.7, A=0.6, S=0.8, Q=0.4`，则 `WorldviewAxis = 0.238 + 0.156 + 0.192 - 0.064 = 0.522`。

## 4. 倾听与站位进度

命名表达式：

```text
ListenProgress(t + Δt) = clamp(P + Δt × (G ∧ D ∧ S ? 1 : -0.32), 0, 2200)
CenterProgress(t + Δt) = clamp(C + Δt × (Z ∧ S ? 1 : -0.28), 0, 2600)
```

| 符号 | 类型 | 范围 | 含义 |
| --- | --- | --- | --- |
| `P` | float | 0–2200 ms | 当前一侧已经积累的倾听时间 |
| `C` | float | 0–2600 ms | 第三个位置已经积累的停留时间 |
| `Δt` | float | 0–120 ms | 当前渲染帧纳入判定的时间步长 |
| `G` | bool | true / false | 讲述者是否在视觉枢轴 0.30 rad 以内 |
| `D` | bool | true / false | 玩家距离讲述者是否在 0.9–3.15 世界单位之间 |
| `S` | bool | true / false | 镜头、玩家和移动输入是否稳定 |
| `Z` | bool | true / false | 玩家是否进入第三位置 0.72 世界单位半径内 |
| `ListenProgress` | float | 0–2200 ms | 单侧证词的完成进度 |
| `CenterProgress` | float | 0–2600 ms | 承担分歧的完成进度 |

两个输出都被夹在明确上限内。失配只缓慢回落，不清空已经付出的注意力；这避免把社会倾听做成惩罚式节奏游戏。

示例：玩家已听 1.5 秒，随后移动 0.5 秒，剩余进度为 `1500 - 500 × 0.32 = 1340 ms`。

## 5. 反馈与美术语法

- 版本 A 使用低饱和珊瑚色，版本 B 使用低饱和矢车菊蓝；两者权重完全相同。
- 两位人物之间只有虚线，不出现胜负、赞成率或正确答案。
- 第三个位置使用象牙金呼吸环，只在两侧都被听见后出现。
- HUD 使用深墨蓝底，保持成人化多巴胺风格；不增加 emoji 或新的通用弹窗。
- 镜头对焦依据 Three.js 的真实视觉枢轴，而不是门口出生点，移动端目标同样居中。

## 6. 可证伪验收

- [x] 三次直接调用陈设探索仍不能完成公议庭。
- [x] 两位讲述者是当前社会的真实 Agent，并占据相距至少 2.2 的物理位置。
- [x] 两段证词必须从各自人物附近、面对人物并停稳后获得。
- [x] 第三个位置在两段证词完成前不可见，也不能提前计时。
- [x] 玩家通过统一碰撞与寻路世界抵达三处位置。
- [x] 两次关系事件、双方记忆和 `parallax_started / perspective_heard / parallax_completed` 证据存在。
- [x] 完成状态跨刷新保留，桌面 1536×1024 与移动端 390×844 无横向溢出。
- [ ] 70% 新玩家不看说明也能说出「游戏不是让我选边，而是让我听见两个位置」。
