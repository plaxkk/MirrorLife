# 记忆授权 / Memory Authorization

## 可证伪假设

如果玩家必须亲自把一段真实 Agent 记忆搬到所有者允许的范围，而不是在菜单里选择隐私选项，那么“讲述不等于公开”会成为可感知的游戏行为。若玩家能靠点击陈设完成、越界不被识别、回执保存原文，假设失败。

## 核心动词

接过 → 搬运 → 测试边界 → 被叫停或被托付 → 在授权位置封存。

## 规则

- 记忆来源：Agent `memoryFiles` 或 `memoryStore`；为空时才从当前生活状态生成 lived trace。
- 授权范围：私密、托付、公开，由 Agent 开放性、神经质、个人信任和关系信任推导。
- 玩家在非授权位置停留 900ms 会触发边界纠正，不扣分、不清空进度证据。
- 玩家在授权位置停留 1800ms 完成封存。
- 回执只保存 `ownerId / memoryId / scopeId / turn`，不保存原文。
- 完成后写入双方记忆、关系事件和本集体验证据。

## 验收

- 桌面与 390×844 移动端无横向溢出。
- 真实 Agent 处于统一 X/Z 坐标并被物理系统固定在现场。
- 三个授权位置可通过室内寻路抵达。
- 陈设点击不能绕过玩法。
- 越界与正确封存都有 telemetry。
- 刷新后授权回执仍存在且不泄漏记忆文本。
