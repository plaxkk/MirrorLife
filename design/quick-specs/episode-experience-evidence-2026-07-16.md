# Quick Spec：双线回声 · 体验指纹与匿名试玩证据

日期：2026-07-16  
状态：已实现，等待真人试玩数据

## 1. 可证伪问题

> 一个第一次进入 MirrorLife 的玩家，是否真的用 28–38 分钟完成“发现—犹豫—承担—分享”，而不是把页面开着、快速点完或在中途失去方向？

过去只能证明流程可运行，不能区分活跃探索、后台停留、真实犹豫和机械点击。本功能把玩家的体验节拍变成可复核证据，同时在终章呈现为有情感含义的“体验指纹”。

## 2. 玩家价值

- 终章不显示得分，而显示“真正走过多久、第一次看见发生在何时、决定前停留多久”。
- 体验指纹来自玩家自己的行为节奏，同一条剧情也会形成不同回执。
- 它强化核心幻想：世界记住的不只是你选了什么，也记住你如何抵达这个选择。

## 3. 记录边界

只在本机、当前五章故事存档内记录：

- 活跃前台时长，页面隐藏后立即暂停。
- 进入房间、首次发现、再次查看、开始/完成具身仪式、打开选择、预览另一条时间线、提交选择、完成房间、寻找/倾听活体余波、打开终章、分享、发起镜像接力和返回街道。
- 选择 ID、房间 ID、相对时间和选择界面停留时间。

明确不记录：

- 玩家昵称、好友昵称、人格输入、自由文本、真实姓名。
- User-Agent、IP、设备 ID、精确地理位置。
- 页面在后台或设备休眠期间的时间。

导出格式为 `mirrorlife-episode-playtest-v1`，只生成匿名 JSON，由玩家主动复制或保存。

## 4. 验收标准

- [x] 真实房间探索会生成 `episode_started → room_entered → evidence_found → choice_opened → choice_committed → room_completed` 证据链。
- [x] 重看证物单独记录为 `evidence_revisited`，不重复首次发现。
- [x] 选择停留从选择界面真正出现后开始计算。
- [x] 页面隐藏、离开和卸载时刷新活跃时间；恢复前台后继续同一会话。
- [x] 刷新后 session、事件和活跃时间保持，且活跃时间不会倒退。
- [x] 终章桌面端显示三项体验指纹；移动端保留一项核心指标和匿名导出入口。
- [x] 匿名导出不包含 profile、昵称、自由输入或设备标识字段。
- [x] 1536×1024 与 390×844 无横向溢出，终章操作仍在首屏内。
- [ ] 至少 5 名真实新玩家提交完整证据，并验证中位活跃时长达到 28–38 分钟。
- [ ] 至少 70% 玩家能在访谈中说出一个角色如何因自己而改变。
